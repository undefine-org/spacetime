Section 2

Your First Animation

Scroll-driven animations reveal content as you navigate the page.

Each paragraph in this section reveals itself as you scroll. This is achieved with @scroll - scroll-linked animation timelines.

// Reveal elements as they enter the viewport
.reveal-item {
    @scroll reveal(600ms) {
        opacity: 0 -> 1;
        translateY: 40px -> 0;
        stagger: 0.1 first;  // Each item delayed by 0.1s
    }
}

The stagger property creates a cascading effect - each element animates slightly after the previous one.

Section 4

State Machines

Manage complex UI states with @state_machine.

Click the button to toggle between states:

Current state: off 
// State machine with transitions
.toggle-button {
    @state_machine(initial: "off");

    @state(when: "off") {
        background: var(--bg-card);
    }

    @state(when: "on") {
        background: var(--success);
    }

    @transition(from: "off", to: "on", on: click);
    @transition(from: "on", to: "off", on: click);
}
Section 5

Data Binding

Reactive signals with $variables keep your UI in sync.

A live counter demonstrates reactive data binding:

0
// Define a reactive signal
@local $count: 0;

// Bind to DOM
.counter-value {
    @bind {
        text: $count;
    }
}

// Update on events
.increment {
    @on click { $count = $count + 1; }
}

.decrement {
    @on click { $count = $count - 1; }
}
Section 6

Composition

Combine multiple animation techniques for rich experiences.

This final demo combines everything: scroll reveal, hover effects, continuous animation, and state.

Everything Together

Scroll to reveal. Hover for effects. Click to interact. All powered by Spacetime.

// Composition: layering multiple behaviors
.composition-demo {
    // Reveal on scroll
    @scroll reveal { ... }

    // Hover interaction
    @on hover lift { ... }

    .floating-orb {
        // Continuous looping animation
        @loop float(8s, direction: alternate) {
            translateY: 0 -> 20px;
            opacity: 0.2 -> 0.4;
        }
    }
}
