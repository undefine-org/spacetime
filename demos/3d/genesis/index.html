A bronze medallion — carved, engraved, and sealed by real geometry operations, run entirely inside a headless Blender process an agent drove one tool call at a time. Scroll.

The pipeline

Agent → Blender → glTF → here.

No GUI ever opened. A single headless blender --background process runs an MCP stdio server — the same shape as any other MCP tool — exposing extrude_polygon, boolean_op, assign_material, export_glb. Seven tool calls built the object you're looking at.

The craft

Carved, not modeled.

A 96-point disc. A logarithmic spiral, extruded and cut away by boolean difference. A rim groove, cut the same way. A raised seal, fused by boolean union. Real CSG — the one thing no declarative shape macro can express, and the reason this pipeline exists at all.

The render

Zero JavaScript. One conversation.

Everything above the fold — the lighting, the studio reflections, the scroll-driven camera, this very fade — is declarative Spacetime. @stage · @gltf · @scroll-3d · @orbit. The engine renders whatever asset you hand it — hand-modeled, procedurally generated, or, as here, agent-carved.
