** Intent

The user's cousin runs LITH MANAGEMENT (assistance à maîtrise d'ouvrage,
maîtrise d'ouvrage déléguée, maîtrise d'œuvre — Casablanca). His Astro site
(https://lith-site.ismail-lithmanagement.workers.dev/) has well-written French
copy but "manque un peu de ✨". Brief from WhatsApp: keep every word; make the
hero bigger and photographic (royalty-free photos); make the competency cards
larger; add a promo video.

Deliverable: the whole site in Spacetime (home + 25 inner pages), a literate
brand book, a 26 s film rendered to mp4 by =spacetime render=, behaviour gates
under real Chromium, and the toolchain fixes the work surfaced.

** Toolchain fixes surfaced by this project (committed in the main repo)

1. =check= merged the =_prelude.st= form matches before =validate_form_refs=
   (E0947 "unknown form" for prelude forms while build passed) — =src/main.rs=.
2. Project root = nearest ancestor with =_prelude.st= (=compiler::project_root_for=)
   for =check= (dir or file), =build <file>=, =serve= (nested routes lost every
   =--lm-*= splice in served CSS while dist had them), =render=, and the test
   runner (project tests see their prelude).
3. =render= of a =file://=-staged page rebases root-relative asset URLs onto the
   site dir (=rebase_root_urls=) — photographs rendered as nothing before.
4. Literate prose is rendered at BUILD time (=ssg_unroll::unroll_static_docs=
   via the vendored snarkdown in V8) — =.st.md= pages are no longer empty
   =display:contents= spans in dist.
5. =SelectorMatch= parses =[attr="v"]= selectors for SSG injection.
6. Char-boundary panics on multibyte values: =collect_st_var_deps=,
   =collect_st_var_refs_in_expr=, =collect_signal_refs_in_expr=, and the dev
   server's diagnostic line/column projection (=floor_char_boundary=) — the
   latter took the whole server down ("Service panicked") on any page whose
   description held a =’=.
7. =SPACETIME_JS_DUMP=<path>= writes the bundle on E0952 so the reported
   line:col can be read.
