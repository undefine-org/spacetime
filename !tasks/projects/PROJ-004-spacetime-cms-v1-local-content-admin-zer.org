** Thesis (one paragraph)

The admin is GENERATED from the project's own =@type=/=@data= definitions: zero
config, zero schema registration. It is itself a Spacetime site (primitives +
metasystem, no custom JS), served full-window at =/__spacetime/admin/=, distinct
from the =__dev__= debug overlay, sharing the existing WebSocket edit protocol.
V1 manages =projects/unkn/data/*.json= (6 types, 6 sources). It uses the
EXISTING client-side =@each= re-render for preview feedback; compile-time
hydration is explicitly deferred.

** Locked decisions (do not relitigate)

1. Surface: separate full-window route =/__spacetime/admin/=; shares WS protocol.
2. Display: optional =@cms= hint macro with convention fallback (works on unkn untouched).
3. Hydration: keep client-side =@each= re-render (=DataUpdate= -> =ST.setData=); defer compile-time hydration.
4. Stdlib placement: admin lives in its OWN folder =stdlib/__admin__/= (sibling to =__dev__=), NOT under macros/ or primitives/.

** What already exists (reuse, do not rebuild) — verify each path

- =/__spacetime/dev/types.json= (=src/server.rs::dev_types_handler=) — @type -> JSON-schema.
- =/__spacetime/dev/site.json= (=src/server.rs::dev_site_handler=) — pages/data/locales.
- =EditJson= / =EditJsonArray= (Insert/Delete/Reorder) — =src/sync/handlers.rs= + =protocol.rs=.
- =/__spacetime/dev/upload= (=upload_handler=) + =dev-media-picker.st=.
- =dev-save.st= (=window.__stDevSave=, op_id/ack/reject/optimistic) — the save orchestration.
- =ST.setData(source, data)= on =DataUpdate= — reactive @each re-render.
- =src/type_system/= (=TypeRegistry::from_form_matches=, =generate_json_schema=).

** KNOWN HAZARDS (from audit AUD-002 — must address or route around in V1)

1. =dev_types_handler= keys schemas by =@type= NAME but data editor looked up by
   SOURCE filename — they never match. V1 MUST resolve =@data <name>: <Type>= ->
   Type, so a source (=talent=) maps to its type (=Talent=). (AUD-002 #8)
2. =dev_types_handler= parses only =index.st=, NOT =@import=-ed files, so types in
   modules are invisible. unkn defines types in =index.st= (OK for V1) but the
   handler should move to the full compile pipeline to resolve imports. (AUD-002 #12)
3. Every =EditJson= MUST carry =op_id= or serde rejects it server-side. Reuse
   =dev-save.st='s op_id generation; do NOT hand-roll EditJson in the admin. (AUD-002 #2,3,4)
4. =dev_types_handler= re-parses on each request — fine for V1, note for later. (AUD-002 #11)

** Out of scope (later layers — see spec §8)

auth/identity, multi-editor/CRDT, draft/publish, hosting/CI-CD, remote upload.
Forward-compat hygiene: admin writes through the same verbs a server would expose
(GET types · GET/PUT data/* · POST build); the EditJson/op_id/ack protocol already
has this transport-agnostic shape.

** Definition of Done

Open =/__spacetime/admin/= while serving =unkn= with =--debug= ->
Talents/Services/Work/Reasons/Stats/Strip auto-listed with counts -> click a talent
-> edit name/headline/image/categories in a GENERATED form -> add/delete/reorder
talents -> live page reflects every change. No =.st= edits required; =@cms= available
to refine display roles.
