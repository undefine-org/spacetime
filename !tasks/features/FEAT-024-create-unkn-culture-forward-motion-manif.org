Design and implement the approved UNKN motion language: culture-forward editorial, kinetic but premium. Motion should make the PDF-derived site feel alive without changing its layout truth. All behavior must be built through Spacetime stdlib/project macros and, only if justified, small documented project-specific primitives under `projects/unkn/primitives/`.

* Context & Narrative
User-approved motion manifest direction: kinetic word/character reveals for hero and section headings; magnetic CTAs; scroll line-wipes; subtle monochrome parallax blocks; custom difference cursor. Motion can be bolder than the PDF because creative latitude is explicitly granted for motion and interaction, but it must not add brand colors, fake content, or JavaScript event handlers. Stdlib reference includes `@reveal`, `@cursor`, `@magnetic`, `@on`, `@scroll`/`@load` in `timeline.st`, `@reduced-motion`, and driver primitives. Current evidence also shows `@fade-in` has TODO no-op internals, so prefer timeline/on-event/reveal macros over relying on fade-in.

* Existing Patterns
- `stdlib/macros/reveal.st`: `@reveal(split: "words"|"chars"|"lines", stagger, duration, threshold, from, once)`.
- `stdlib/macros/timeline.st`: `@load name(...)`, `@scroll name(...)`, `@hover/@click` timeline macros.
- `stdlib/macros/on-event.st`: `@on hover name(duration) { ... }`, `@on visible name(...) { ... }`.
- `stdlib/macros/cursor.st`: `@cursor(size, color, blend, hoverScale, hoverElements)`.
- `stdlib/macros/magnetic.st`: `@magnetic(strength, radius, axis, lerp)`.
- `stdlib/macros/responsive.st`: `@reduced-motion { ... }`.
- `projects/undefine.org/primitives/_ripple-webgl.st`: example of project primitive placement, but do not copy unless justified.

* Tests

- Custom cursor with `mix-blend-mode: difference` can disappear over mid-gray; verify contrast on all sections.
- Touch devices should use normal cursor/no magnetic hover.
