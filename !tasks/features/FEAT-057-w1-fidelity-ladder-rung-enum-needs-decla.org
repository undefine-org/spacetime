* The ladder
| rung   | world                        | backend           |
| pure   | no DOM, no time              | V8                |
| logic  | LinkeDOM + fake rAF          | V8 + LinkeDOM     |
| layout | real CSSOM/getComputedStyle  | CDP (W2)          |
| timing | real/seekable clock          | CDP (W2/W5)       |
| paint  | pixels                       | CDP + screenshot  |
build-js = pure/logic at build time (same V8 embed). Document this equivalence.

* Syntax
- =@test "name" needs <rung> { … }=. Optional; default rung = INFERRED floor.
- Inference: each assertion/probe declares its MIN rung (e.g. =computed(<css>)= ⇒
  layout; =@clock=/timeline ⇒ timing; =@capture screenshot= ⇒ paint; pure value
  asserts ⇒ pure/logic). The test's effective rung = max(inferred floor, declared).
- =needs= can only RAISE above the inferred floor, never lower it (lowering = error).

* Refuse-to-fake gate
- Each backend advertises its max rung. Running a test whose effective rung exceeds
  the selected backend's max is a HARD ERROR (compile-time where possible; else a
  runner-refusal that reports FAILED with a clear message), NEVER a silent pass.
- Concretely: a =layout=/=timing= assertion on the V8/LinkeDOM backend errors with
  "needs layout; run via CDP backend" — it must not execute against the fake
  getComputedStyle (=el.style||{}=) or synchronous rAF.

- Backend selection: =cargo run -- test … --rung <max>= or auto (logic locally,
