* The Law (mechanism — no mountains in it)

An ENTITY is a named selector-scope. COMPONENTS (`@directives`) attach data/behavior/
per-frame ticks. Every entity exposes its transform as FACETS. Page-frame and world-frame
are two coordinate spaces for the same entity model; the camera is the component mapping
world→page. "DOM on a 3D point" = one entity whose page-transform reads another entity's
world-projection facet.

This is NOT new — it is the existing `@scroll-spy` pattern pointed at the world frame:
  .work-section {            // ENTITY (selector-scope)
    @scroll-spy              // COMPONENT (directive binding a primitive)
    @when &self.scrollSpy.isActive { … }   // READ component state back as a FACET
  }
Verified mechanism (repo facts):
- `nested_scope: seq(choice(selector_list, element_ref), block)` — tree-sitter-spacetime/grammar.js:429.
  `&name { }` ALREADY parses as a scoped block and lowers via the same NestedScope path as
  `.selector { }` (src/parser/mod.rs:596-604). Entity blocks need NO grammar change.
- `Value::ElementRef { name, facet: String, property: String }` — src/parser/ast.rs:611.
  Facet is a STRING; facet→signal table is DATA (src/analysis/signals.rs:319), not Rust arms.
- A directive that binds a primitive exporting signals makes them readable as
  `&ref.<directive>.<signal>` (scroll-spy.st macro → primitive yields `$isActive` →
  `&self.scrollSpy.isActive`). This is ECS state read-back, CSS-native.

Lineage that confirms the altitude:
- A-Frame (aframe.io): `<a-entity>` + component attributes (`position`/`rotation`), built-in
  transform, `tick()`, query-selector references. Our entity = selector; components = directives;
  every entity inherently exposes `.world/.screen/.depth/.visible` (their built-in transform).
- KAPLAY: `add([pos(), text()])` composition; `@anchor(&x)` is `pos()` reading another object
  (a constraint component). Composition over inheritance.

* REVISED CANONICAL SURFACE (2026-06-30) -- supersedes "Author surface (LOCKED)" above

  Two oracles (game-engine ECS: Godot/Unity/Bevy/A-Frame; declarative formats:
  QML/USD/glTF/SVG) converged INDEPENDENTLY on this surface. Primary precedent:
  A-Frame <a-entity> expressed in Spacetime sigils, backed by QML id:+property-binding
  and USD relationship semantics. It DELETES the 3 hacks (stringly FK, name-interp,
  data-in-strings) rather than adding mechanism. Net complexity: negative.

** The entity is its &name. Nothing else.
   - Identity  = the &name{} scope. NO kind-word (@entity peak REJECTED -- adds a slot,
     deletes nothing; @peak stacked inside already says "peak"). NO type slot on the entity.
   - Behavior  = the components stacked inside (Bevy implicit archetype; A-Frame composition).
   - A "type" in @data's sense (@type Peak{}) belongs to the DATA driving the entity,
     annotated on the row var (@each($peaks as $p Peak)), NEVER on the &entity.
   - kind (the @data inline/fetch %macro discriminator) is ORTHOGONAL to type and is
     simply not used for entities.

** Facet paths: "." is member-access all the way down (4 layers)
   &evernet . peak . summit . y
   |ENTITY |  |COMP| |FACET | |VAL|
   - ENTITY   &evernet   -> world registry _stWorld.byName   (precedent: element-ref.st
              &name selector; + current three-anchor _stWorld.byName)
   - COMPONENT .peak      -> which stacked @component published it. LAW: component namespace
              = the directive name (@peak -> .peak.*). Promotes scroll-spy's "scrollSpy."
              doc-prefix (when-guard.st) to a resolution law. Collision-proof.
   - FACET    .summit     -> a published signal declared via %exports { $summit: worldpos }
              (precedent: element-ref.st %exports { $width: length }). TYPED.
   - VALUE    .y          -> runtime member access on the facet's value (vec3 -> scalar).
   STRUCTURAL vs VALUE split: the ENTITY.COMPONENT.FACET prefix is resolved at COMPILE time
   against the registry+%exports (this is where a typo/type-mismatch becomes a compile error);
   any further .segment is RUNTIME reactive value access. Same syntax, two phases; the type
   of each segment decides which.

** Base vs derived facets (where the reactivity lives)
   - .peak.summit  BASE    worldpos, from the terrain height field.
   - .peak.screen  DERIVED screenpos = project(summit, camera). depends on summit + camera.
   - .peak.visible DERIVED bool = inFrustum(summit, camera).
   @anchor(to:&e) reads derived .screen/.visible, which reactively depend on base .summit +
   the camera signal. Terrain displaces -> summit updates -> screen recomputes -> DOM moves.
   Precedent: scroll-spy already publishes derived signals via %yields/%derives -- same machinery.

** Facets are TYPED; the type drives resolution (this is what REALLY kills the string hack)

NOTE [2026-07-02]: Text-selection fix + anchor interactivity made a proper facet (2026-07-02).

SYMPTOM: user couldn't select the .peak-copy text in everswap-clone. ROOT CAUSE: three-anchor
(lib/three-anchor.st) wrote `el.style.pointerEvents='none'` STATICALLY in setup so the anchored
block never intercepted scroll/clicks meant for the 3D canvas. Side effect: text unselectable.
index.st fought back with a hand-maintained child carve-out (`.peak-copy a,.kicker,h2,p {pointer-events:auto}`)
— which (a) rots when markup changes and (b) is wrong: a faded (opacity 0) block still stole
pointer/selection from siblings/canvas beneath it.

FIX (the Spacetime-native design): pointer-events is a PROJECTION FACET, not setup. three-anchor
now derives it per-frame from the SAME `visible` signal it already computes for opacity:
`el.style.pointerEvents = visible ? 'auto' : 'none'`. A revealed block is interactive (text
selectable, links clickable — WHOLE block, pointer-events inherits so no child enumeration); a
faded/out-of-frustum block is inert (never blocks canvas scroll or a sibling beneath). ONE reactive
rule replaces BOTH the static none AND the project's per-child CSS carve-out (deleted from index.st).
Meets elegance bar: derived from an existing signal, deletes a special-case, no new subsystem.
Verified live via puppeteer: summit block at scroll 0.92 → pointer-events:auto, real
window.getSelection() returns "One Pool, Everyone"; everblade (faded) → none, opacity 0.
