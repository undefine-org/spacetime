* Goal
A live playground: type a Spacetime call (e.g. ~@data fetch $api : "/users"~) and
watch the dispatch machine resolve it keystroke-by-keystroke — the scored candidate
table, winner highlit, losers showing WHY they lost (−100 literal-miss, missing
required, type mismatch).

* Target files

  ~create_router_raw~ at server.rs:131 alongside the other /__spacetime/* routes) +
  ~dispatch_handler~ (mirror ~runtime_js_handler~ at server.rs:1337). Runs FEAT-087's
  ~parse_matches~ + explainer over the live registry, returns the resolution JSON.

* Contract — endpoint
~GET /__spacetime/dispatch?call=@data%20fetch%20%24api%20%3A%20%22%2Furl%22~
→ 200 application/json, body = FEAT-087's probe JSON:
~{ "call":"…", "directive":"@data", "candidates":[ {macro,total,winner,terms[]} … ],
   "ambiguous":bool, "margin":int }~.
Empty/invalid call → ~{ "call":"…", "directive":null, "candidates":[], "error":"no directive" }~
(200 with error field, not a 500 — the UI renders the error inline).
Dev-mode only (like the other /__spacetime/dev/* routes); guard accordingly.

* Contract — primitive (%emit js, the sanctioned escape hatch)
~%primitive dispatch-probe(&el, endpoint: string)~:
- find the associated <input> (convention: ~&el~ contains or is preceded by
  ~[data-probe-input]~; or take an ~input: selector~ param).
- on input (debounced ~120ms): ~fetch(endpoint + "?call=" + encodeURIComponent(value))~
  → render ~json.candidates~ into &el: one row per candidate, sorted total desc
  (nulls last), winner row class ~probe__row--win~, rejected rows ~probe__row--out~,
  each term as ~<span class="probe__term probe__term--{verdict}">label +points</span>~.
- NO snarkdown/other deps; pure DOM. Cleanup the listener on teardown (%cleanup).

* UX (the cool part)
- Type ~@on cdick~ → every candidate red, "no winner — literal 'cdick' matches
  nothing". Fix to ~@on click~ → the @on-click form jumps to ~+3 ✓~ and glows.
- Show the margin ("won by +3") and an ambiguity banner when ~ambiguous~.
- Seed each card's probe with that macro's canonical example call so it's live on
  expand.

* Edge cases
- Endpoint runs the SAME explainer as ~inspect --layer dispatch --probe~ (FEAT-087)
  — share the function, do not reimplement scoring in the handler.
- ~parse_matches~ on a partial/garbage call must not panic — wrap and return the
  error JSON.
- Production build (no dev server) → the probe degrades gracefully: the primitive
  shows "live probe needs the dev server" if the fetch fails. The static reference
  (FEAT-090 cards) still works without it.
- Rate: debounce in the primitive; the handler is cheap (in-memory registry).

* Acceptance
- ~curl '/__spacetime/dispatch?call=@data fetch $x : "/u"'~ (dev server) → JSON with
  data-fetch winner total 6 + breakdown (matches FEAT-087's CLI probe byte-for-byte
  on the candidates).
- In the reference (CDP): type a call into a probe input → the scored table renders;
  changing the keyword changes the winner live.
- Garbage input → inline error, no 500, no console throw.
- Full lib + integration green; a server test for the endpoint (mirror an existing
  /__spacetime/* handler test).
