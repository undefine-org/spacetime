#+TITLE: [:st/html] reactive markup node
#+STATE: DONE
#+CUSTOM_ID: FEAT-174-st-html-reactive-markup-node

* Intent

EDN-produced markup needs a reactive dual to =[:st/raw "…"]=. Raw HTML is
trusted opaque content: interpolations remain text and behavior inside it is not
lowered. =[:st/html "…"]= instead parses the supplied string through the same
HTML-expression normalization and DOM-builder lowering used by component bodies,
so backtick holes bind and authored elements participate in selector behavior.

* Contract

- In an EDN document's =:st/html= sequence, =[:st/html source]= inserts the
  parsed source at that exact position.
- Backtick holes such as =`$count`= become signal-bound text holes.
- Bare =$count= remains literal, matching FUP-041.
- =[:st/raw source]= remains verbatim trusted markup with no hole scanning.
- Parsed nodes are appended as children at the insertion position; no extra
  template root becomes user-visible.

* Proof required

A focused integration test compiles EDN containing both node forms and asserts
that reactive HTML creates its elements and watch binding while raw HTML remains
an =innerHTML= assignment containing the authored backticks. A bare-dollar case
must emit literal text. The library suite must remain green, followed by a
locked release build and install.

* As built

- =HtmlExpr::Html(String)= recursively parses through
  =component_html_to_exprs= and emits each resulting node through the existing
  child builder, returning a fragment only for multiple siblings.
- =HtmlInjection= preserves Parsed/Raw/Reactive semantics through the parser AST
  and EDN document codec. EDN ingress accepts both inline node tags.
- File-level reactive injections emit a stable insertion marker and replace it
  with the global-signal builder result at startup. Raw injections remain authored
  HTML with no scanning.

* Proof

- =cargo test --lib=: 3228 passed, 5 failed, 1 ignored. All five failures are
  existing bundle snapshot deltas from the concurrently dirty =$$= runtime
  escape change; none involves this feature.
- =cargo build --release= succeeded; =cargo install --path . --force --locked=
  replaced =~/.cargo/bin/spacetime= and the companion executables.
