* Goal
Inline-HTML ~@each($src as $i) { <html> }~ has NO ~when $filter~ form (only the
template-invocation each-filtered does, stdlib/macros/each.st:103). So a reactive
search/filter over an inline-HTML list silently drops the filter \u2014 the ~when~
clause is absorbed and the list is unfiltered. Add filter support to each-inline,
mirroring each-with-templates' machinery (evaluateFilter/applyFilter/
getFilterStateVars + per-dep local:<var>:updated subscription).

* Target
- stdlib/macros/each.st ~each-inline~: add a SECOND %form
  ~@each($source as $item, when $filter:expr) { $body:html_block }~ binding
  ~each-inline(&self, source, item, html, filter: $filter)~. Keep the existing
  unfiltered form.
- stdlib/primitives/data/each-inline.st: add ~filter: string? = null~ param; port
  evaluateFilter (resolve $item.field via itemData, $stateVar via SpacetimeLocal/
  ST.get), applyFilter (toggle el.style.display per row), getFilterStateVars +
  subscribe ~local:<var>:updated -> applyFilter~. Apply filter after each render.

* Edge
- Filter must run AFTER nested-each expansion (BUG-081) \u2014 rows exist before
  filtering. Item-var resolution in the filter expr must use the OUTER item var.
- SSG: a filtered inline-each is reactive (depends on runtime signals), so the SSG
  unroll should render ALL rows (no filter at build time) and the runtime hides
  non-matches on first paint \u2014 matches each-with-templates (renders all, then
  applyFilter). Acceptable: initial HTML shows all, hydrate filters.

* Acceptance
- demos/spacetime-docs/reference.st: typing in the search box live-hides
  non-matching cards; clicking a kind chip filters by kind (CDP: visible-card
  count drops). 
- A headless/unit check that each-inline with a when-form binds filter.
- Full lib + integration green.
