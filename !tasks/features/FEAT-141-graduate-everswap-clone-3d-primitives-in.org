* Goal
The everswap-clone project (projects/everswap-clone) prototyped a motion-design
language as project-local %macro/%primitive pairs. Several are general enough to
graduate into stdlib/3d so any Spacetime site can use them.

* Candidates (proven in the clone)
- @terrain  — real 3D heightfield relief: procedural value-noise fbm OR
  image-heightmap (luminance -> displacement) mode. Strongest candidate; fills a
  real gap (stdlib/3d has no displaced-geometry primitive).
- @layer    — textured parallax plane (billboard): additive blending +
  scroll/camera parallax + fade-in.
- @flightpath/@waypoint — scroll-driven multi-keyframe camera path
  (smoothstep pos+lookAt). Generalizes stdlib's single-drive @scroll-3d.
- @flow     — animated UV-scroll additive glow plane.
- @text3d/@ripple — canvas-texture wordmark on a subdivided plane with a
  travelling-wave vertex shader (data-tuned ripple). Depends on a DOM font;
  consider a stdlib/text glyph-atlas path instead of FontFace-from-URL.
- @reveal   — DOM blur-in text motion (line/word/char split + stagger). Likely a
  stdlib/text or stdlib/motion concern, not stdlib/3d.

* Why this is a follow-up, not done inline
Graduation must clear the elegance bar + fidelity ladder:
1. CDP paint-rung tests (stdlib/3d tests refuse on headless V8 — see
   docs/testing/CDP_BACKEND.md). Each primitive needs a screenshot/state test
   under --cdp, like stdlib/3d/tests/*.test.st.
2. API review: param names, defaults, and which belong in stdlib/3d vs a new
   stdlib/motion. @reveal likely lives outside 3d.
3. Naming: the clone renamed @timeline->@flightpath to avoid colliding with
   stdlib/testing's @timeline. Decide the canonical stdlib name.
4. The %emit gotchas found (quoted-literal-with-paren mis-capture; FontFace
   timing) should be encoded as primitive-author guidance or fixed in tokenizer.

* Acceptance
Each graduated primitive lives in stdlib/3d (or stdlib/motion) with a MODULE-
style doc, has a --cdp test that passes, and everswap-clone imports it from
stdlib instead of lib/ with no visual regression.
