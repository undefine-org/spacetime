* Scope
- Behavior directives: =@on <event> [selector] { $x <- expr | toggle | inc | dec }=
  inside a template body lower to =addEventListener= on the scoped element, mutating
  =ST.set(rootEl, 'x', …)=. The =selector= scopes to a descendant; absent selector =
  root element.
- Class toggles: =.cls: $flag;= lower to =ST.watch(rootEl,'flag', v => el.classList.toggle('cls', v))=.
- Custom props: =--accent: $c;= lower to =ST.watch(… style.setProperty('--accent', v))=.
- Content injection: =text <- $x;= → =el.textContent=; =[slot="v"] <- $x;= →
  =el.querySelector('[slot=v]').textContent=; =attr <- $.field;= → =setAttribute=.
- Scope resolution: =$x= inside a template resolves to that instance (=ST.get/set(rootEl)=);
  =$x= in =body {}= resolves global (=SpacetimeLocal=); inner template reads outer's
  =$x= via compile-time parent-scope ref (per template-component-model.org). Verify the
  EMITTED JS matches the design's transpilation map, do not trust the design doc.
- =@exports { $x, $y: mut }=, named refs =&n &c()=, cross-ref =&n.$x=, collection refs
  =&cards[]= + aggregates: AUDIT their emitted JS (FUP-037) and fix any that no-op.
