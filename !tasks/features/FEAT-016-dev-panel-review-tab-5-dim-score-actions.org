* Scope

In-scope:
- New "Review" tab in the existing dev panel (=stdlib/__dev__/macros/panel.st=, see also =stdlib/__dev__/primitives/dev-panel.st=).
- Tab UI elements:
  - Top-level *score* (0-10) rendered as a single big number with semantic color (>=8 green, 5-7 yellow, <5 red — Catppuccin palette already used by `timelines-errors`).
  - Five *dim rows*, each with name, dim score badge, expand toggle.
  - Expanded row shows findings list: severity icon, message, selector (clickable → DOM highlight via existing inspect machinery in =dev-inspect.st=), value where applicable.
  - "Refresh" button that calls `window.__stDevReview()` immediately; auto-poll every 2000ms while tab is visible.
- Reuse Catppuccin theme + style conventions from =timelines-errors.st= (badge classes, colors, list shapes).

Out-of-scope:
- Auto-fix actions (only a "Copy report" button that puts the JSON on clipboard for hand-off to `doctor` or to share with an agent).
- Persistent settings (audit thresholds, ignore lists) — single-shot for now.

* Existing Patterns

- Tab system: =stdlib/__dev__/primitives/dev-panel.st= exposes `window.__stDevPanel.getPane('id')` returning a shadow-DOM container; tabs are pre-declared in =stdlib/__dev__/macros/panel.st=. New tab requires both (a) declaring pane id "review" in panel.st and (b) populating it in a primitive.
- Polling pattern: =stdlib/__dev__/macros/timelines-errors.st= sets `setInterval(render, 500)` while the tab is visible; copy that pattern but at 2000ms (review walker is heavier).
- Style injection into shadow DOM: same primitive shows the canonical pattern (build `style.textContent` from a string array, append to `panel.shadow`).
- Selector → DOM highlight: =stdlib/__dev__/primitives/dev-selector.st= already exposes a hover-highlight overlay. Reuse it for clickable findings.

* Edge Cases

- Tab opened before dev-review primitive loaded: render placeholder "Review pending..." instead of erroring.
- Review walker throws: catch, show single error finding with `{ severity: 'error', message: 'review failed: <text>' }` so the tab never blanks.
- Visibility detection MUST use a MutationObserver on the pane's class list (existing pattern in panel.st), not naive document.visibilityState.
- 0 findings across all dims: render "All clear ✓" empty state.
