* Summary
Restyle the workbench chrome to the *organic interface birthplace* design language ([[file:../../@research/mcp-design-language-organic-birthplace.org][design-language doc]]): warm-dark espresso/ember palette, humanist serif + Inter, stage-dominant topology with chrome receded into extensible button-drawers. The chrome IS a function (fn-host, origin=Stdlib), inspectable like any other, but it is the persistent host page (Fork 2-A). Region topology: =stage= (dominant, ~70%), =nav-drawer=, =inspector-drawer=, =origin-drawer=, =comms-drawer= (summon glyphs at edges; overlay when open). Mockups m1-m6 are the visual contract.

* Why
The MCP is not a dev tool — it is an organic interface birthplace. The live content is the organism; chrome recedes into warm drawers that orbit the stage. Current workbench is cold-dark columns; this FEAT delivers the warm-dark studio with the stage-dominant + drawer topology that makes the three concerns (C1/C2/C3) nest beautifully.

* Target
- =stdlib/__mcp__/env.st= — rewrite as the host chrome: stage + 4 drawer-regions + slim topbar.
- =stdlib/__mcp__/workbench/= — restyle (styles.st to warm-dark tokens; cards/lists/templates for origin drawer (m3), comms+kit drawer (m4), inspector (m6)).
- New drawer primitives/macros: =@drawer= summon + overlay model (extensible: a drawer is a region with data-st-drawer; summon glyph; slide-over with warm shadow).
- Empty state (m1): stage ghost affordances + receded glyphs + pulsing ember.
- Hot-swap visual (m5): departing fade + arriving shimmer skeleton.
- Error state (m6): warm error card + last-good ghost + inspector-summon glow.

* Change
Pure Spacetime (no custom JS outside %primitive). Reuses @view/region-mount (FEAT-126), @scope css (FEAT-129), per-region identity (FEAT-127), origin (FEAT-128). Drawers are themselves bundles (extensible: agent can contribute a drawer — principle 5).

* Edge
- Drawer open over stage -> stage scales/dims behind (mock m3/m4); dismiss restores.
- Multiple drawers -> stack of summon chips; one open at a time (or pinnable).
- Empty/error/hot-swap states -> on-brand warm affordances (m1/m5/m6).

* Acceptance
- Visual parity with mockups m1-m6 (headless layout assertions where feasible; puppeteer visual check).
- Chrome is origin=Stdlib, inspectable in the origin drawer.
- Drawer summon/overlay/dismiss works; stage recedes when a drawer opens.
- =cargo run -- serve= on the MCP host page; reviewer-swarm on the chrome.
- =cargo test= + headless green.
