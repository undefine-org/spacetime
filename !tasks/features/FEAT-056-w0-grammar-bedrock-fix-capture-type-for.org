   into the inline token stream for forms with inline captures + NO params, so the
   inline `$condition:expr` consumes `(cond)`; trailing string → `$message`. Both
   `@assert (c) "m"` and bare `@assert c "m"` work. (Form-matcher fix, not stdlib.)
3. RC2 @then/@when greedy selector: SelectorExtractor ate `.x should exist` whole;
   match_capture now bounds greedy extractors at the next Literal AND next String
   capture. @then now matches + emits.
4. @then assertion ident double-quoted (`'%$assertion'` → `'"exist"'`): use
   `%$assertion` raw since captured_to_js already quotes idents.
