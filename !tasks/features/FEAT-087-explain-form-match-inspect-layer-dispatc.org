Probe parsing: feed the call string through ~crate::syntax::events::parse_matches(call, &registry)~
to get the directive + captures; build a ~CaptureMapInput~ (form_scoring.rs:341);
score every ~get_all_macros_by_form_directive(directive)~ candidate via the
explainer. ~margin~ = winner.total − best-viable-runner-up.total. ~ambiguous~ =
two viable candidates share the top total.

* Edge cases
- Call with no directive match → ~candidates:[]~, ~probe.directive~ still echoed.
- Selector-scoped forms: pass ~--selector~ (existing InspectFilter field) so
  ~macro_scope_matches~ participates (mirror find_macro_for_match's selector arg).
- Literal-match tracking: the explainer needs ~literal_matched(idx)~ from the
  input; ~CaptureMapInput~ may default-true. If positional literal tracking is
  unavailable from a bare call parse, record verdict "literal-untracked" with the
  form's declared points and NOTE it (don't fake a −100). File a BUG if this makes
  the probe lie about a real call; otherwise acceptable for v1.
