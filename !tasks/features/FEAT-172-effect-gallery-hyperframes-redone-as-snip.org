** Root / intention
The HyperFrames registry (scratch/hyperframes/registry/registry.json: 142 items,
117 real motion pieces after dropping 25 code-snippet themes) is a React/Remotion
video-effect catalog. FEAT-171 (score-launch) redid ~12 techniques as ONE long
page. The user wants the backdesk-new "process" pattern instead: one page that
calls upon many small .st.md snippet files, each redoing one registry effect in
the Spacetime style — super simple.

** Mechanism (proven 2026-08-04 in scratch/galtest)
A .st/.st.md page can @import a .st.md snippet (docs/language/literate.md: imports
work both directions). Imported elements+prose append after the host's own, in
import order. Prose renders via the synthesized stdlib/md import. Verified live:
host h1, then snippet prose, then the live animating snippet.

** Design
- demos/effect-gallery/index.st.md — literate host: intro prose (lineage,
  honesty), theme CSS, one @import per snippet in gallery order.
- demos/effect-gallery/snippets/<name>.st.md — 15 self-contained snippets:
  family header (# Captions / # Lower thirds / # Effects on the first of each
  family), ## title, 1-3 sentences naming the registry entry redone, one
  ```st src fence (source shown AND live). Scoped classes .gx g-<name>;
  literal colors (copy-pasteable, no host dependency).
- Tests: tests/gallery/effect-gallery.test.st — 4 sampled CDP probes
  (karaoke, pixelate stagger, ticker translate, morph crossfade), fences
  inline-mirrored, 30s/file budget respected.

** Contracts discovered (from FEAT-171 debugging — reuse, don't rediscover)
- Clip-consumer name matching: placement &w1 ↔ consumer class .w1. Multiple
  consumers MAY share one clip (cover transition in score-launch).
- Container-level stagger: .grid consumes its own window, nested .cell scope
  with `stagger: 45ms`.
- background gradients → background-image LONGHAND (BUG-279: reactive
  shorthand resets static longhands).
- Single-line CSS values when $refs involved (E0952); gallery uses literals.
- Loop mode restart is now correct for &.loop scores (BUG-277).
