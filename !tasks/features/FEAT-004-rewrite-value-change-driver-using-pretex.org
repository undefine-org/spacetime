** Rationale
The current driver forces 4+ layout reflows per animation cycle via DOM reads (cloneNode, getBoundingClientRect), has Firefox-specific compositing flash bugs from box-model mutation, and uses font-kerning/letter-spacing hacks for cross-browser consistency. Pretext's canvas-based measurement eliminates all of these.

Using =%emit prelude-js= instead of adding pretext to the runtime module chain means: (a) zero Rust changes, (b) pretext is tree-shaken — only included when =@value-change= is used, (c) follows the established pattern (scroll-driver already uses =%emit prelude-js= at line 37).

** Step 0: Build and embed pretext into =%emit prelude-js=

*** Build pretext IIFE (one-time, outside cargo build)

CRITICAL BUILD CONSTRAINTS (from Momus review):
1. *No backtick template literals*: Spacetime's CST lexer (=src/syntax/cst/lexer.rs=) has no backtick token. =parse_emit_body()= tracks brace depth via L_BRACE/R_BRACE — backticks containing ={= / =}= corrupt depth tracking. Use =--target=es2015= to downlevel template literals.
2. *Escape =%= and =$= patterns*: The emit tokenizer (=src/emit/emit_tokenizer.rs=:305-335) treats =%identifier= as Spacetime param placeholders and =$identifier= as signal references. Vendored JS with modulo operators (=width%total=) or dollar signs will be misinterpreted. Post-process the IIFE to escape these.

%primitive value-change-driver(...) {
  %emit prelude-js {
    // Pretext v0.0.3 — canvas-based text measurement
    // Vendored from @chenglou/pretext (MIT license).
    // Build: esbuild layout.ts --bundle --format=iife --target=es2015
    // Post-process: escape %id -> %%id for Spacetime emit tokenizer
    // CONSTRAINT: No backtick template literals (CST lexer limitation)
    (function() {
      /* ... escaped pretext IIFE content ... */
    })();

    // Expose via ST namespace using pretext's corrected measurement
    // (NOT raw canvas.measureText — pretext applies emoji width correction)
    (function() {
      var P = typeof __PretextInternal !== 'undefined' ? __PretextInternal : null;
      if (!P) return;
      ST.text = {
        prepare: P.prepare,
        layout: P.layout,
        prepareWithSegments: P.prepareWithSegments,
        layoutWithLines: P.layoutWithLines,
        clearCache: P.clearCache,
        setLocale: P.setLocale,
        // Corrected word width measurement using pretext's internal pipeline.
        // This applies emoji correction (Chrome/Firefox macOS canvas measures emoji
        // wider than DOM). Raw ctx.measureText() would give wrong widths for emoji.
        measureCorrected: function(word, font) {
          var prepared = P.prepare(word, font);
          // For a single-segment word, layout width == segment width
          var result = P.layout(prepared, Infinity, 0);
          // layout with infinite width = single line, height is meaningless,
          // but we can get width from layoutWithLines
          var lines = P.layoutWithLines(prepared, Infinity, 0);
          return lines.lines.length > 0 ? lines.lines[0].width : 0;
        }
      };
    })();
  }

  %emit js {
    // ... per-element value-change code using ST.text ...
  }
}
#+end_src

Note: =ST.text.measureCorrected()= uses pretext's full measurement pipeline (including emoji correction from =getCorrectedSegmentWidth()=) instead of raw =ctx.measureText()=. This ensures per-word widths in the animation match the widths used for height calculation. Pretext internally uses a single shared canvas context — no duplicate contexts.

* Edge Cases
- *Empty text*: =oldText= or =newText= is empty → handle as full enter/exit of entire text
- *Same text*: Already handled by existing =newText !== currentText= guard
- *Emoji*: =Intl.Segmenter= correctly handles multi-codepoint graphemes (ZWJ sequences, flag emoji)
- *RTL text*: Word containers use =inline-block= which respects bidi. Exit layer =left: 0= works for LTR; RTL would need =right: 0=. Current implementation is LTR-only (same as before).
- *Rapid mutations during animation*: =isChanging= guard prevents re-entry. Mutation during animation is dropped (same as before).
- *Font not loaded*: Canvas measures with fallback font, same as DOM would. Widths match.
- *system-ui font*: Pretext warns this is unsafe on macOS. ora-ventures uses named fonts (Inter). Document the limitation.
- *Multi-line text*: Pretext =layout()= correctly handles line-breaking and returns accurate height.
- *V8 headless tests*: =ST.text.prepare()= will throw without canvas. Value-change headless tests (=value-change.test.st=) run in real browser, not V8. Codegen tests (=value_change_test.rs=) only check string presence in compiled JS, not execution.
