* Context & Narrative

The huashu-design analysis (this session) showed that "3 different schools" is the load-bearing rule: if you recommend three minimal-leaning takes, the user can't actually compare directions. The 5-school taxonomy gives the agent a structured palette:

| School                  | Anchor designers/studios                | Visual signature                            |
|-------------------------+-----------------------------------------+---------------------------------------------|
| information-architecture| Pentagram, Massimo Vignelli, Bruno Munari| Grid-driven, data-forward, restrained       |
| motion-poetics          | Field.io, Active Theory, Resn          | Dynamic, immersive, technical aesthetic     |
| minimalism              | Kenya Hara, Jasper Morrison, Apple      | Order, white space, precision               |
| experimental            | Stefan Sagmeister, David Carson        | Avant-garde, generative, visual disruption  |
| eastern-philosophy      | Kenya Hara (lens), Issey Miyake         | Warm, poetic, contemplative                 |

The 8-phase procedure (huashu, translated to Spacetime DSL):
1. Phase 1 — Deep needs probe (1-3 questions max).
2. Phase 2 — Restate the brief (100-200 words; close with "I prepared 3 directions").
3. Phase 3 — Recommend 3 schools (must come from different rows).
4. Phase 4 — Show prebuilt showcase gallery (depends on FEAT-030).
5. Phase 5 — Render 3 demos (parallel via subagent fan-out where possible; sequential fallback).
6. Phase 6 — User picks / mixes / refines.
7. Phase 7 — Generate authoring prompt structure.
8. Phase 8 — Hand off to junior-designer workflow.
