* Edge Cases

- *Server boot timeout*: =serve()= takes 1-3s. Wait for HTTP 200 on root before navigating; max 10s.
- *Playwright not available in CI*: tests gated behind =browser= feature flag.
- *Concurrent doctor invocations on same port*: =serve()= binds fixed port; concurrent runs collide. Use =port: 0= for ephemeral binding.
- *Long-running runtime.js (dataiku 1.2 MB) hangs eval thread*: PLAN-018 substituted =adovasio=. Document limitation; add =--route-timeout <secs>= flag (default 30) for tunability.
- *Routes containing query strings or fragments*: =route_slug= already strips slashes; verify =?= and =#= handling.
- *Memory leak across many routes*: tear down page/context per route; reuse browser.
- *Skipped route after FEAT-033 ships*: rare; doctor exits non-zero AND prints clear actionable message.
- *=Spacetime.review()= returns 7 dims after FEAT-032*: deserialization opaque; T2.1 confirms 7-key passes through.
- *Brand-asset-missing finding from FEAT-028 also surfaces*: orthogonal — FEAT-028 in =run_check_phase=, FEAT-033 in headless. Both contribute to report.
