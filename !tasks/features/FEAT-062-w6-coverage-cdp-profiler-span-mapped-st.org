Wave 6 of [[id:PLAN-027-spacetime-testautomation-infra-fidelity]]. Coverage as a
READ of structures we already own — JS coverage mapped back to .st source via
source-spans, plus directive/macro-expansion coverage (a genuine moat no other web
framework can offer).

* Two layers
** JS line coverage → .st source coverage
- CDP exposes =Profiler.takePreciseCoverage= natively (W2 client). Collect per-test.
- Map emitted-JS ranges → .st source via the source-spans the kernel already
  threads through emit (SourceSpan on every AST/IR node). Produce per-.st-file and
  per-primitive line coverage.
** Macro / primitive expansion coverage (the moat)
- Instrument the expander (src/pipeline/expand.rs) to record which macro FORMS and
  which form BRANCHES (alternations in %form / %capture_type) were exercised by the
  suite, and which primitives emitted.
- Report gaps: "@when … drag never tested", "claim op =matches= never exercised",
  "primitive X never mounted". Requires owning the macro layer — unique to Spacetime.

* Surface
- =cargo run -- test … --coverage= → summary (source % + directive %) + a detailed
  report artifact (json + human). Optional lcov export for CI tooling.
- Thresholds: =--coverage --min-source 70 --min-directive 60= fails under target.

* Implementation
- Coverage is additive/read-only: no change to emitted code (precise coverage works
  on unmodified JS). Span map already exists; add the range→span resolver.
- Expansion coverage = a counter keyed by (macro, form-branch) flushed per run.

* Tests
- A file with an untested branch shows < 100% and names the branch.
- Source coverage attributes executed lines to the correct .st file+line (spot-check
  a primitive: mount it, assert its lines covered; don't mount it, assert uncovered).
- Directive coverage flags a deliberately-unexercised macro form.
