* Findings
1. [P2] merge_group_captures drops non-Named group values (form_compiler.rs ~3965).
   A repeat group `( ... )*` yields CapturedValue::Array; a single-capture group
   `( $s:string )?` yields a scalar String (name\u2192Named threading lives only in
   Sequence/Choice extractors). Both have tokens CONSUMED + body boundary advanced,
   but captures silently dropped. Fix: bind non-Named values under capture_name_of.
2. [P2] Boundary scan is string-literal-blind (mod.rs find_matching_delimiter).
   A group with a paren literal `( "(" ")" )?` or unbalanced paren mis-bounds \u2192
   parse_capture_pattern None \u2192 group text silently leaks into body_capture with NO
   diagnostic. Fix: quote/char-class-aware extent scan; diagnostic on unresolved
   leading `(`.
3. [P2] Whitespace before modifier flips optional\u2192required (mod.rs ~4009).
   `( ... ) ?` (space before `?`) \u2192 modifier read as None (Required), stray `?`
   leaks into body_capture. Asymmetric with the inner PEG (which skip_whitespace
   before modifier). Fix: trim_start after_close, advance consumed past ws.
4. [P2] Non-literal-led optional body group steals body tokens (mod.rs ~4016).
   `( $x:ident )? $body:component_body` \u2014 no anchor sentinel \u2192 the optional group
   greedily binds the first body token. Fix: parse-time validation \u2014 an optional/
   zero-or-more body group ahead of a greedy body capture MUST be literal-led.
