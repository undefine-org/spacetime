11. *Generic display fonts (Inter / Roboto / Arial as headlines)* — Bad: =h1 { font-family: Inter, sans-serif }= at 4rem display. Good: =font-family: var(--brand-display)=. Rationale: agnostic-system default. Exception: project tokens.st specifies Inter/Roboto.

12. *SVG-drawn imagery* — Bad: =background: url("data:image/svg+xml;...drawn-face.svg")=. Good: real photography (assets/ per project-style protocol Step 0) or honest placeholder. Rationale: AI-drawn faces have wrong proportions. Exception: brand IS illustrated.

13. *GitHub-dark-mode aesthetic* — Bad: =:root { --bg: #0D1117; --accent: #58a6ff; --neon: #39d353 }=. Good: tokens from actual brand spec. Rationale: GitHub's signature; using elsewhere makes product look like GitHub clone. Exception: developer tool with brand spec authorizing palette.

14. *Rounded card + colored left-border accent* — Bad: =.alert { border-radius: 8px; border-left: 4px solid #2563eb }=. Good: simpler boundaries. Rationale: 2020-2024 Material/Tailwind tic, corpus-saturated. Exception: design system explicitly declares pattern.
