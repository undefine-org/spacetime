* Scope

In-scope:
- New runtime API: `window.Spacetime.review()` returning a 5-dim audit object (synchronous, idempotent).
- Five dimensions, each scored 0-10 with structured findings:
  1. *idiomatic*: scans DOM for inline event handlers (`onclick=`, `onmouseover=`, ...), `<script>` tags whose source isn't `__spacetime/`, and `style="..."` attributes containing properties that should be Spacetime-driven.
  2. *animation*: walks `__ST_DEBUG__.getTimelines()`; flags timelines where `elementCount === 0`, `state.started === false` after `readyState === 'complete'` + 500ms grace, or `state.destroyed === true` while `state.completed === false`.
  3. *brand*: walks computed CSS for the document; collects inline hex literals (regex `#[0-9a-f]{3,8}`) appearing in `style` attributes or unbound via `var(--*)`; reports unbound count and top offenders.
  4. *a11y*: counts `<img>` without `alt`, `<a>` without accessible name, `<button>` without label, headings out of order (h1 → h3 skip).
  5. *compile*: reads `window.__ST_DEBUG__.errors` (existing) for compile/runtime errors collected by the dev runtime.
- Each finding shape: `{ dim, severity: 'error'|'warn'|'info', message, selector?, value? }`.
- Score formula per dim: `clamp(10 - errorCount*2 - warnCount, 0, 10)`.
- Top-level shape: `{ score: 0..10, dims: { idiomatic, animation, brand, a11y, compile }, findings: [...], generatedAt }`.

Out-of-scope:
- Production-mode exposure (review must be guarded behind `window.__ST_DEV__ === true`, set by `stdlib/__dev__/index.st:dev-flag()`).
- Auto-fix actions (review reports only; fixes happen via doctor or dev panel tabs).
- Historical snapshots / diffing.

* Edge Cases

- Primitive evaluates inside Shadow DOM (dev panel) but audits the host document; selectors must use `document.querySelectorAll`, not the panel's shadow root.
- Walker MUST tolerate `__ST_DEBUG__` being undefined (production users never see this, but guards prevent dev-mode fragility while page is loading).
- Inline-handler regex MUST NOT flag SVG presentation attrs that begin with `on` but aren't events (`onclick` is real; `oninput` is real; nothing else common). Whitelist event-handler attrs only.
- Hex literal scan MUST ignore values inside `:root { --x: #aaa }` declarations (those are vars; that's the good case).
- Multiple invocations of `Spacetime.review()` per second: walker MUST debounce-cache for 250ms to keep the dev panel poll cheap.
