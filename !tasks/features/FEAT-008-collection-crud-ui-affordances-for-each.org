* Implementation

** Step 1: Collection CRUD primitive (~stdlib/__dev__/primitives/dev-collection-crud.st~)
- New %primitive that detects @each containers via ~data-st-source~ attribute
- For each @each container:
  - Inject "+" add button after last child (or as empty-state prompt if no items)
  - Inject overlay on each item with "x" remove button and up/down arrows
  - Overlays visible only on hover (dev-mode CSS)

** Step 2: Add item logic
- Click "+" -> construct default item from @type schema (fetch from /__spacetime/dev/types.json)
- For each required field: use type-appropriate default (string: "", number: 0, bool: false, url: "")
- Send ~EditJsonArray { op: Insert { item, index: None } }~ via dev-ws
- On Ack: @each re-renders with new item (via DataUpdate -> ST.setData)
- :entering animation plays on new item

** Step 3: Remove item logic
- Click "x" -> determine item index from ~data-st-index~ attribute
- Send ~EditJsonArray { op: Delete { index } }~
- On Ack: :exiting animation plays, then item removed from DOM

** Step 4: Reorder logic
- Click up arrow -> swap with previous item (from_index = current, to_index = current - 1)
- Click down arrow -> swap with next item (from_index = current, to_index = current + 1)
- Send ~EditJsonArray { op: Reorder { from_index, to_index } }~
- On Ack: @each re-renders in new order (via DataUpdate)
- :move animation plays if defined

** Step 5: CSS and affordance styling

- Overlay appears on hover with slight opacity
- Buttons use consistent dev-tools styling (matches existing dev-panel aesthetic)
- Affordances injected as absolute-positioned overlays, not modifying DOM structure

- Empty collection: show "+" button as empty-state prompt
- Single item collection: disable up arrow, disable down arrow; show "x" with confirmation

- Rapid clicks: debounce add/remove to prevent duplicate operations
- Reorder at boundaries: first item up = no-op, last item down = no-op
- Animation during CRUD: ensure :entering/:exiting don't conflict with dev affordance injection
