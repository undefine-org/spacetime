Tag every loaded Spacetime with WHERE it came from (Stdlib | Env(env_id) | Agent(agent_id) | Kit). One field on two existing rails (no new mechanism):
- =MacroRecord.origin= (src/metasystem/registry.rs) — compiler knows source path at %register.

Surfaced via the existing =@data dispatch $macros= rail ([[id:FEAT-084-data-registry-the-self-documenting-galle][FEAT-084]]) + input.json functions[]. The origin drawer (mock m3) renders it.

* Why
The user's "tiny example": see every loaded Spacetime + its origin (stdlib / env / sent by agent). Origin tracking today is NONE (recon-verified). Fork 3-B: FLAT registry + origin as metadata (NOT namespaced); collisions = LOUD error at registration.

* Target
- =src/metasystem/registry.rs= — add =origin: Origin= to MacroRecord; populate at register (derive: under stdlib/ -> Stdlib; else Env).
- =src/mcp/state.rs= — add =origin: Origin= to FunctionRecord; =st_fn_put= sets Agent for inline source, Env(env_id) when env bound, Stdlib for the MCP's own functions.
- =Origin= enum: Stdlib | Env(env_id) | Agent(agent_id) | Kit.
- =stdlib/__mcp__/workbench/= — origin drawer (cards/lists/templates) per mock m3: filter by origin; search; each row name + kind + origin chip + source path + mount-status.

- Collision: two bundles same template name, different origins -> registration error (loud), surfaced to agent/user.
- Origin drawer empty filter -> graceful empty state.
