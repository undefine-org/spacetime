* Contract — format_form_signature
Walk ~form.inline_elements~ → ~form.params~ (parens) → ~form.post_arg_inline~ →
body. Map each ~FormInlineElement~:
- Literal(s)            → s            (role: literal)        e.g. "fetch"
- Capture(FormCapture)  → "$"+var+":"+type+modifier          (binding/type/optional)
  modifier: Optional→"?", ZeroOrMore→"*", OneOrMore→"+", Required→""
  type via ~CaptureType~ → short name (Binding→"binding", Expr→"expr", Typeref→"typeref",
  Union(v)→"("+join("|")+")", Balanced(c)→"balanced('c')", Custom(s)→s, …; full enum at meta_ast.rs:409)
  alias_capture present → " as $alias:type"
- Comparison{op,cap}    → op+" "+sig(cap)
- KeywordBlock/PseudoSelector/PseudoClass → name+" { … }"+modifier
Params: "(" + join(", ", name+": "+sig(elements) [+ " = "+default]) + ")".
Prefix the whole thing with ~"@"+directive_name~ (directive_name already carries no @).
Example target: ~@data fetch $name:binding $type:typeref? : $src:expr ;~

* Contract — @data dispatch JSON rows
~build_dispatch_json~ emits an array of:
~{ "directive":"@data", "name":"data-fetch", "signature":"@data fetch …",
   "tokens":[{ "text":"fetch","role":"literal"}, …], "doc":"…", "kind":"data",
   "scopes":["file","selector"], "binds":["fetch-source"],
   "overloads":["data-inline","data-fetch","data-derive","data-query"] }~
Only macros with a ~%form~ are included (dispatchable). ~kind~ via the same
~kind_of(source_file)~ helper build_registry_json uses. Optional ~from KEY VAL~
filter (e.g. ~from kind "data"~) reuses the registry-filter retain logic.
Flows through the IDENTICAL inline path: ~inject_dispatch_data~ rewrites the
FormMatch into ~@data inline $macros : <json>~ → @each SSG-unroll + hydration.

* Edge cases
- A directive with one overload still emits ~overloads:["self"]~ (UI shows "1 form").
- Multi-word directive_name ("on hover") → signature "@on hover …"; split on first
  space for the directive chip vs the rest.
- Forms with body_capture / body_params → append " { … }" so the signature reads as
  block-taking. Don't dump the whole body grammar.
- Keep tokens + signature CONSISTENT (signature == tokens.map(text).join with spacing).
