* Scope

In-scope:
- New CLI subcommand: =cargo run -- doctor <project-path> [--routes /,/about,/contact] [--format pretty|json] [--screenshot-dir <path>] [--port 4444]=.
- Sequence:
  1. =cargo run -- check= over the project; collect diagnostics.
  2. Boot a headless server on `--port` (default `4444`, fallback +1 on collision).
  3. For each route (default = `/`, plus auto-discovered locale / sub-routes from project's `site.json` if present):
     a. Navigate via Playwright (existing harness in =cargo run --features headless -- test=).
     b. Wait for `document.readyState === 'complete'` + 500ms.
     c. Run `Spacetime.review()` (FEAT-015).
     d. Save screenshot to `<screenshot-dir>/<route-slug>.png`.
     e. Capture console errors and unhandled promise rejections.
- Aggregate into a single `DoctorReport` JSON with: project path, started/finished timestamps, per-route block, top-level pass/fail.
- Pass/fail thresholds (failing if ANY of):
  - check produced any error-severity diagnostic;
  - any route's review `score < 6`;
  - any route had console errors during navigation.
- Pretty mode prints colored summary + per-route table; JSON mode dumps full report (one stdout line is `===JSON===` separator before payload, for skill scripting).
- Each finding includes a `skillRef` field pointing to the relevant section/anchor in the spacetime-design skill (e.g. `"spacetime-design#anti-slop-inline-handlers"`).

Out-of-scope:
- Snapshot/regression diffing (deferred — selected as out-of-scope in plan answer).
- CI integration template (will be a follow-up doc once doctor is stable).

* Edge Cases

- Project has no routes (empty `site.json`): default to `/` only.
- Server boot fails (port conflict): increment port and retry up to 5 times before erroring.
- `Spacetime.review()` returns `{ status: 'pending' }` (dev primitive not loaded — doctor MUST run with dev runtime injected): doctor MUST force-inject the dev runtime via the same mechanism `cargo run -- serve` uses, asserting status != pending; if still pending, mark route as Fail with reason "dev runtime did not initialize".
- Network slow / page hangs: per-route 30s timeout; on timeout report Fail with reason and skip to next route.
- Locale routes: respect existing `try_serve_locale` behavior; doctor's auto-discovery walks `site.json` `locales` array.
