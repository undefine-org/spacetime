** Design: the primitives (projects/zellijist/lib/)
*** three-zellij (primitive) — the tile field factory
- Builds N triangular prism tiles from THREE.Shape → ExtrudeGeometry (right-triangle, bevelled
  edge for the soft ceramic chamfer). Two materials via geometry groups: MeshPhysicalMaterial
  glaze (low rough + clearcoat, warm cream, subtle per-tile hue jitter) on the top cap; matte
  clay MeshStandardMaterial (high rough, bone) on the extrude walls + bottom cap.
- Deterministic layout: builds the zigzag strip as (row, up/down) triangles → each tile gets a
  packed "home" transform (tessellated) AND an "exploded" transform (scattered pos+rotation,
  seeded RNG) AND a "logo" transform (positions that trace a capital Z). Stored per tile so a
  choreographer can interpolate between the three states.
- Registers tiles on canvas._stZellij = { tiles:[{mesh, home, explode, logo}], ... } for the
  choreographer, mirroring stdlib's canvas._stObject contract.
*** zellij-scroll (primitive) — the choreographer
- Reads page scroll progress 0..1 (same sampler as three-scroll), eased. Maps sub-ranges to the
  three-act arc: [0,0.33] home→explode (tessellated → tumble), [0.33,0.66] free tumble drift,
  [0.66,1] explode→logo (converge into the Z). Per-tile smootherstep + easing; camera gentle dolly.
- One rAF via ctx.registerFrame; no page JS, no second engine.
