* Design — the renderer
A compile-time lowering HtmlExpr → a JS DOM-builder function that, given a scope element
(__el = the instance root, or document for file-scope), constructs the live subtree and wires
each Hole reactively:
- Element{tag,attrs,children} → document.createElement(tag); for each attr: if all Lit →
  setAttribute once; if any Hole → an apply()+deps+ST.watch arc (mirror emit_reactive_binding_js
  but element-scoped) that recomputes the attr value string; recurse children.
- Text(s) → document.createTextNode(s).
- Hole(JsExpr::Raw(src)) → a text node whose content is render()=transpiled(src); deps =
  collect_signal_deps(src); ST.watch(__el, dep, render) for each dep (Element scope inside a
  template; Global scope for file-scope HTML). Escaping: textContent (auto-safe) for text holes;
  for attr holes, string-built value via setAttribute (escapeAttr semantics preserved).
- Raw(s) → trusted innerHTML fragment (for &param element substitution).
- Scope: SignalScope::Element when rendering a @template body (deps read ST.get(__el,...));
  SignalScope::Global for file-scope HTML (SpacetimeLocal + local:<dep>:updated listeners).
- bare $x desugaring: the skeletonizer (B-Wave 2) normalizes bare $x/$x.path/&param in
  component HTML into holes so authoring is unchanged.
