* Edge Cases
- Site with no pages/ directory: fall back to single-page export (index.html + index.st)
- Missing paired .st file for a .html page: copy HTML as-is, warn
- Build errors in .st compilation: report error, skip page, continue with others
- Output directory exists: overwrite contents (with --clean flag?)
- Relative paths in HTML (../../spacetime.js): rewrite to correct output-relative paths
- @import chains in .st files: compiler already resolves these; export uses compiled output
- Large sites (50+ pages): parallel compilation for performance
