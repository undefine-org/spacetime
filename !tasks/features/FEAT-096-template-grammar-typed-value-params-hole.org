* Change
1. TYPED VALUE PARAMS — author convention = signal-decl SPACE form. Grammar:
   `( ( $binding:binding | $element:element ) $ptype:ident? $optional:optmark? ( "=" $default:expr )? ","? )*`
   $ptype OPTIONAL (existing untyped templates unchanged). NOT `$href: url`.
   reify reads `ptype`/`default` keys → TemplateParamDef.type_ref/default.
2. BACKTICK HOLES IN COMPONENT BODIES (additive) — normalize_bare_holes scans
   `` ` `` … `` ` `` runs as holes (same HOLE_OPEN/idx/HOLE_CLOSE sentinel feed
   into treesink). Inside a backtick run:
   - `` `$x` `` / `` `expr` `` → single Hole (reactive, like bare today)
   - `` `&name` `` where name ∈ element_params → element-substitution Hole
   - `` `...&name` `` → SPREAD hole: inner expr literal `...&name`. Lowering
     flattens the array/fragment arg into the children list at that position
     (vs single-node insert). Marker carried in the hole source string;
     html_reactive emits a spread-append (loop appendChild over arg array).
   Bare `$x`/`&param` STILL recognized (legacy). Backtick takes precedence when
   a `` ` `` opens.
3. SPREAD SEMANTICS — `...&name` only valid in TEXT/children position; in attr
   value → compile error ("spread is children-only").
4. Registry retention: %registers template entries already retain body
   (ComponentBody) + params; ensure new type_ref/default survive into
   RegistersClause for FEAT-097 schema walk.
