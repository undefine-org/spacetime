* Summary
The vertical slice that makes the unified env real. Three pieces:
1. *Extend =view-mount=* (stdlib/primitives/view.st) to resolve =$=-dynamic template names (Fork 1-A) — align with @each/@match; lets a region mount a template named by a runtime signal (the bundle's arrival sets the signal).
2. *=registerBundle(templates, css, origin, regionId)= runtime helper* — wraps css in =@scope ([data-st-region])= ([[id:FEAT-129-mcp-css-scope-isolation-registration-tim][FEAT-129]]), calls existing register-template logic per template, sets the region's tpl signal.
3. *Bundle transport* — new endpoint =GET /__mcp/instance/{host}/bundles= returns the desired bundle set; page polls (Transport A, alongside input.json); page diffs vs registered set (content-hash idempotency), registers new, disposes removed. =st_mount(fn, region?, input?) -> {region_id, instance_id}= injects.

* Why
=Spacetime.templates= is already a runtime Map (recon-verified); factories are decoupled; dynamic dispatch already shipped in @each/@match. This FEAT wires bundle arrival -> registration -> region mount over those existing mechanisms. @view was the only dispatch primitive missing =$=-resolution — extending it deletes the asymmetry (Fork 1-A) and makes regions == @view wildcard arm with a dynamic name.

* Target
- =stdlib/primitives/view.st= — view-mount: add =$=-resolution to =ref.name= (mirror @each/@match dynamic dispatch).
- =stdlib/__mcp__/primitives/= (host.st or new bundle.st) — =registerBundle= primitive + bundle-poll wiring (extend @mcp-input model or add @mcp-bundles).
- =src/mcp/live.rs= — =GET /__mcp/instance/{host}/bundles= route.
- =src/mcp/tools.rs= — =st_mount= signature change (region param); bundle-set assembly.

* Edge
- Bundle whose template invokes a template not in any registered bundle -> runtime warn (existing invoke-template behavior); region shows partial.
- Bundle arrives while region mid-render -> serialize via poll handler (next poll picks up).
- Hot-swap state -> discarded (keep-alive is follow-up; locked decision).
- Factory throws -> catch in region-mount, log, leave region in last-good state (mock m6; do NOT blank).
