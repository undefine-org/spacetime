* Summary
The orchestration layer that turns "a page with reactive bits" into "an app with
panes, modals, and side-effects." Three constructs, each absent today.

** @view — named view signal + conditional mount
The admin swaps panes (list | graph | theme | palette | motion). Today that is ad-hoc
JS; =tests/fixtures/multi_route_site= is multi-PAGE (separate index.st), not in-app
views. Provide an in-app view signal:
#+begin_src spacetime
@view $pane : "list";              // declares a view signal, initial "list"
.center { @show(when: $pane == "graph") { &graph(); } }
.rail__item { @on click { $pane <- "graph"; } }
#+end_src
Lowers to a signal + reactive mount/unmount (model on bind-if / @match-render). OPTIONAL
stretch: a =@router= binding history/hash to the signal (deep-linkable views) — gate
behind a follow-up if it expands scope.

** @portal — render a subtree at document.body, escaping the layout tree
Drawer (position:fixed), media modal, preview iframe must escape =#admin-root='s grid
and stacking context. Today JS appendChild(body). Provide:
#+begin_src spacetime
@portal {
  .modal { ... }
}
#+end_src
Lowers to a primitive that mounts the subtree at =document.body= (or a named portal
root), and ships modal-correctness: focus-trap, scroll-lock on open, Esc-to-close,
restore focus on close, =aria-modal=. These are the recurring "modal tax" — bake them in.

** @effect — run a side-effect when a signal changes
=refreshPreview()= (debounced iframe reload after save-ack) has no declarative home;
only animation drivers currently react to signals. Provide:
#+begin_src spacetime
@effect(on: $rows, debounce: 600ms) {
  // side-effect body (e.g. reload preview)
}
#+end_src
Lowers to an =ST.watch= on the named signal with optional debounce, running the body.
The body is a mutation/effect block (same grammar as =@on= bodies), NOT a render.

* Edge cases
- @view: switching panes mounts/unmounts; unmounted pane's scoped state is cleaned up
  (or preserved? — DECIDE and document; default: cleaned, with an opt-in keep-alive).
- @portal: multiple portals stack (z-index/focus order); Esc closes topmost only;
  scroll-lock refcounts (two modals → one unlock when both closed).
- @portal: focus-trap restores to the previously focused element on close.
- @effect: debounce coalesces bursts; effect does NOT run on initial mount unless
  =immediate: true= (document the default; default = do not run on mount).
- @effect: multiple effects on the same signal run in declaration order.
