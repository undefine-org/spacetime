- Calling =spacetime init= from =inside= =projects/= (e.g., =cd projects && spacetime init foo=): cwd has no nested =projects/=, so it correctly resolves to =./foo= → =projects/foo=. ✓

- =name= containing path separators (=foo/bar=): unchanged from current behavior; the helper still concatenates and the caller is responsible. Note this is unusual for =init= and does not need special handling.
