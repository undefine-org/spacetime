In-scope:
- New "Brand" tab in dev panel (=stdlib/__dev__/macros/panel.st=).
- Two sections:
  1. *Custom properties*: lists all `--*` defined on `:root` and on the document's first stylesheet, with computed value swatch + name + occurrence count.

* Edge Cases

- Cross-origin `<style>` and `<link rel="stylesheet" href="cdn">`: enumeration MUST `try { read cssRules } catch (_) { skip }`.
- `var(--x, #aaa)` (var with hex fallback): the fallback is a literal but is intentionally a fallback. Treat as bound; do NOT flag.
- `linear-gradient(#aaa, #bbb)`: each hex inside a value still counts as inline. Show the parent declaration as a single row but list both hex values.
- Promote round-trip with no server handler: WS will silently drop today (per AUD-002). Add a 2s timeout in this primitive so the user gets feedback (`'no response — handler may be missing'`).
