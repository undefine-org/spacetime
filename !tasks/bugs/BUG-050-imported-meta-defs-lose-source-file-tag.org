* Symptom
An imported =%vendor= declaration was registered, and its primitive emitted, but
the vendored IIFE (pretext) was NOT injected: =globalThis.pretext= absent from
output. =vendor_blob_path()= returned None because the vendor def's =source_file=
was None, so the on-disk blob (resolved relative to the declaring file's dir)
could not be located.

* Root cause
=merge_ast= did =target.meta_defs.extend_from_slice(&source.meta_defs)= — copying
imported meta_defs WITHOUT tagging them with the importing file path. Macros and
primitives don't need source_file to expand, so this was latent until =%vendor=
(which resolves its blob path relative to source_file) exposed it.

* Fix (commit e1076acf, PLAN-024 W3)
=src/parser/mod.rs=: =merge_ast= clones each imported meta_def and tags it via new
=set_meta_def_source_file= (covers Macro/Primitive/CaptureType/RuntimeRegistry/Vendor).
Also benefits incremental-cache invalidation, which keys on source_file.
