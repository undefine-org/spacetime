#+TITLE: [attr]: reactive bindings compile to style.setProperty no-ops
#+STATE: ITEM
#+CUSTOM_ID: BUG-290-attr-reactive-bindings-compile-to-style

* Symptom

An attribute reactive binding compiles to a `style.setProperty` call with
the ATTRIBUTE name — a no-op for real attributes:

#+begin_example
[hidden]: $pages_empty == false;
[data-active]: $tab == "pages";
  → style.setProperty("hidden", …) / style.setProperty("data-active", …)
#+end_example

Neither `hidden` nor `data-*` is a CSS property, so nothing ever happens
in the DOM. Found porting knowledger's screens to HEAD (2026-08-05):
every `[hidden]`/`[data-active]` binding had to become a `display:` /
style binding instead.

* Repro

#+begin_example
@data inline $open bool : true ;
.panel { [hidden]: $open == false; }
#+end_example

Compile and inspect the emitted binding: `style.setProperty("hidden", …)`.

* Workaround (in use)

Bind `display:` (or another real style) instead of the attribute.
