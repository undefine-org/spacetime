* Bugs
1. [P1] attr_initial_and_expr raw-concatenates literal text + signal src into the JS expr ->
   transpile_signal_expr_with("badge $kind") = `apply = () => (badge SpacetimeLocal['kind'])`,
   a SyntaxError that breaks the ENTIRE concatenated bundle. Mixed literal+hole attrs
   (class="btn `$variant`", href="/u/`$id`", style="width:`$w`px") are routine. FIX: build the
   expr like html_reactive::attr_value_expr (js_string-quote literals, transpile+paren holes,
   join with " + "); build the static initial separately from parts.
2. [P1] emit_html_blocks calls emit_hydrated once per HtmlBlockAst with a fresh next_id=0, but
   bindings address holes by document-wide querySelectorAll([data-st-hole="N"]). Two top-level
   blocks each with a hole both get id 0 -> cross-contaminated hydration. FIX: thread one
   monotonic id counter across all blocks (or run emit_hydrated once over all exprs).
3. [P2] emit_binding decides is_text via matches!(property,"text"|"content"); an attribute
   literally named `content` (<meta ... content="`$desc`">) is misrouted to textContent -> never
   updates. FIX: pass an explicit is_text flag from the caller (text-hole path = true,
   attr path = false), don't sniff the property string.
4. [P2] emit_text_hole always wraps in <span>, which corrupts RCDATA (<title>), table (<tr>),
   <select> contexts. FIX: context-aware text anchor (the reference reactive path uses a bare
   text node). Lower-priority; common flow content is fine.
