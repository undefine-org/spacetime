Root cause was deeper than the each-with-templates hypothesis: the FEAT-042 signal-channel writes (`window.SpacetimeLocal = window.SpacetimeLocal || {}`) CLOBBERED the reactive Proxy. When @data $products loaded before the $cart local-state decl, it created a PLAIN SpacetimeLocal object; local-state-impl's `if (!window.SpacetimeLocal)` then saw it truthy and SKIPPED installing the Proxy -> $cart written to _localState but unreachable via SpacetimeLocal -> add-to-cart threw 'undefined.concat'.
