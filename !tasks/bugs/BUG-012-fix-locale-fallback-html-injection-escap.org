* Problem

The locale fallback path in =try_serve_locale= (=src/server.rs=, the =if compiled.build_scripts.is_empty()= branch starting ~line 615) has three issues:

** Issue 1: Escaped quotes in raw strings produce broken HTML (Critical)

The =validation_inject=, =debugger_inject=, and =spacetime_inject= format strings use =r#"..."#= raw strings (correct), but contain =\"  inside them (wrong). In Rust raw strings, =\\\"= is literal — it emits a backslash followed by a quote. This produces broken HTML:

#+begin_example
<link rel=\"stylesheet\" href=\"/__spacetime/dev/styles.css\" />
#+end_example

instead of the correct:

#+begin_example
<link rel="stylesheet" href="/__spacetime/dev/styles.css" />
#+end_example

Affected lines (current offsets, may shift slightly):
- Line ~664: =<script src=\"/__spacetime/validation-ui.js\"></script>=
- Lines ~675-676: =<link rel=\"stylesheet\"...= and =<script src=\"...=
- Lines ~691-692: =<link rel=\"stylesheet\"...= and =<script src=\"...=

Every other injection path in the same file uses unescaped quotes in =r#"..."#= raw strings. See lines 781-797 for the correct pattern to copy.

** Issue 2: Double compilation of .st file

Line 605 calls =compile_from_site()= to get =compiled= and check =build_scripts.is_empty()=. Then line 642 calls =get_or_compile()= to get diagnostics. These are two separate compilations of the same .st file.

=get_or_compile()= returns =(CompiledSpacetime, Vec<ValidationDiagnostic>, bool)=. It should be used from the start, replacing =compile_from_site()=.

** Issue 3: No test coverage for locale fallback injection

The 19 server tests cover provenance injection, dev tools ordering, and debugger toggle — but none test the locale fallback injection path. The escaped-quotes bug would be caught by any basic test.

#[test]
fn test_locale_fallback_inject_no_escaped_quotes() {
    // Simulate the locale fallback injection (same format strings as try_serve_locale
    // when build_scripts is empty)
    let diagnostics_json = r#"[{"message":"test"}]"#;
    let validation_inject = format!(
        r#"
    <!-- Spacetime Validation -->
    <script>window.__SPACETIME_DIAGNOSTICS__ = {};</script>
    <script src="/__spacetime/validation-ui.js"></script>
"#,
        diagnostics_json
    );

    let debugger_inject = r#"
    <!-- Spacetime Dev Tools -->
    <link rel="stylesheet" href="/__spacetime/dev/styles.css" />
    <script src="/__spacetime/dev/runtime.js"></script>
"#
    .to_string();

    let entry_param = "index.st";
    let spacetime_inject = format!(
        r#"
    {}<!-- Spacetime Runtime -->
    <link rel="stylesheet" href="/__spacetime/styles.css?entry={}" />
    <script src="/__spacetime/runtime.js?entry={}"></script>
    {}{}
"#,
        debugger_inject, entry_param, entry_param, validation_inject, LIVE_RELOAD_SCRIPT
    );

    // No literal backslash-quote sequences in the output
    assert!(
        !spacetime_inject.contains(r#"\""#),
        "Output must not contain escaped quotes. Got: {}",
        spacetime_inject
    );
    // Valid HTML attribute quotes
    assert!(
        spacetime_inject.contains(r#"rel="stylesheet""#),
        "Must contain valid rel attribute"
    );
    assert!(
        spacetime_inject.contains("runtime.js"),
        "Must contain runtime script"
    );
    assert!(
        spacetime_inject.contains("validation-ui.js"),
        "Must contain validation script when diagnostics present"
    );
    assert!(
        spacetime_inject.contains("dev/runtime.js"),
        "Must contain dev tools when debug enabled"
    );
}
#+end_src
