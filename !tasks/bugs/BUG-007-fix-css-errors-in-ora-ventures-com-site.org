Two CSS authoring bugs in the ora-ventures.com site modules that break rendering.

* Bug 1: =_hero.st= line 88 — colon instead of semicolon
#+begin_src css
.ora-hero__sub {
    @dark {
      color: var(--st-text-light):   // ← WRONG: colon, should be semicolon
    }
}
#+end_src

Fix: change the trailing =:= to =;=.

Effect: dark mode hero subtitle text color is broken. The malformed property likely invalidates the =@dark= block.

* Bug 2: =_overrides.st= lines 58-73 — malformed nested hover rule
#+begin_src css
.ora-about__pillar {
    text-align: center;
    padding: var(--st-space-lg) var(--st-space-md);
    border: 1px solid var(--st-border);

.ora-about__pillar:hover {           // ← nested as a separate selector, not &:hover
    border-color: var(--st-border-strong);
    box-shadow: var(--st-shadow-md);
    transform: translateY(-4px);
}
    border-radius: var(--st-radius-lg);  // ← stranded after :hover close brace
    background: var(--st-bg-elevated);
    transition: ...;
}
#+end_src

Fix: Move the hover block outside =.ora-about__pillar=, and ensure =border-radius=, =background=, =transition= are inside the pillar block before the closing brace.
