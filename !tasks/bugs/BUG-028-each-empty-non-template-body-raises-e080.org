* Source

* Problem
`@each(...)` whose body is empty or has certain shapes fails with:
  error[E0804]: Missing required parameter 'invocations'
    in bind: each-with-templates
  hint: parser limitation
The each-with-templates macro requires an `invocations` capture (template-invoke calls in the body). An @each with an empty body, or a body that uses slot/property bindings instead of `&template(...)` invocations, fails to capture it.

* Repro
  .g { @each($products as $p) { } }            => E0804
  // works:
  .g { @each($items as $i) { &row($i); } }     => ok

* Expected
An @each with no template invocations is valid (renders nothing per item, or binds slots). The `invocations` capture should default to empty rather than being required. Surfaces in examples/cart-demo/index.st .cart-items.

Related macros: stdlib/macros/data.st (each-block), stdlib/macros/each.st. Capture/optionality fix likely in the form definition + form_compiler capture.
