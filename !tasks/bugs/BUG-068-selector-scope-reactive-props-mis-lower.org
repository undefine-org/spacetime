* Symptom (emitted-JS verified, 2026-06-06)
At SELECTOR scope (file-level `.box { ... }`), reactive `:` declarations mis-lower:
| author (selector scope)        | emits NOW                         | should emit                         |
|--------------------------------+-----------------------------------+-------------------------------------|
| `.active: $open;`              | `setAttribute("active", …)`       | `classList.toggle("active", !!v)`   |
| `.ora-faq__item--open: $x;`    | `setAttribute("ora-faq__…", …)`   | `classList.toggle("ora-faq__…", !!v)`|
| `--accent: $c;`                | `setAttribute("--accent", …)`     | `style.setProperty("--accent", v)`  |
| `text <- $v;`                  | textContent ✓ (separate `<-` path)| (ok)                                |
Template-BODY scope is correct (the `cb_toggle`/`cb_self_prop` grammar in
component-body.st → ClassToggle). Selector scope uses a DIFFERENT path
(CST css_property → CssDeclaration → emit_reactive_binding_js) that is a STUB:
it only branches text/content→textContent vs *→setAttribute. No class-toggle,
no custom-property branch. `setAttribute("--accent")` / `setAttribute("a--b")`
are also invalid DOM.

* Root cause (two chained defects)
1. PARSER (src/syntax/events/grammar/directives.rs `body_item` DOT arm): `.x: $v;`
   (no `{`) fails `is_scope_block` → "stray dot — consume", dropping the leading
   `.`. The CSS_PROPERTY name becomes bare `x`, losing the class-toggle marker.
2. EMIT (src/compiler.rs `emit_reactive_binding_js`): even with the name, the
   emitter has only text-vs-setAttribute; no `.`/`--` routing.

* Fix (FEAT-072-aligned, the `:` surface completed at selector scope)
- Parser: in the DOT arm, when NOT a scope block, parse `.<ident>: <value>;` as a
  CSS_PROPERTY whose name PRESERVES the leading `.` (class-toggle marker). Keeps the
  disambiguator the spec defines (leading `.` = reactive class; `--` already a token
  run in the value-less property name; bare ident = CSS passthrough/attr).
- Emit: `emit_reactive_binding_js` routes by property-name shape:
  * `.class`  → `classList.toggle('class', !!__v)` (strip dot; supports `!`/expr cond)
  * `--prop`  → `style.setProperty('--prop', __v)`
  * `text|content` → textContent (unchanged)
  * other attr → setAttribute (unchanged)
- Mirror the same routing in src/emit/html_hydrate.rs `emit_binding` (FEAT-078 hydrate
  path mirrors this fn) so SSG + hydration agree.
