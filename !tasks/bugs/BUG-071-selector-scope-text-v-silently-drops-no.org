* Symptom (emitted-JS verified, 2026-06-06)
At SELECTOR scope, a bare `name <- $expr;` produces ZERO binding JS and NO diagnostic:
| author (selector scope)         | emits NOW        | should emit                    |
|---------------------------------+------------------+--------------------------------|
| `.x { text <- $v; }`            | nothing (no-op)  | textContent binding on `.x`    |
| `.x { src <- $.url; }`          | nothing          | setAttribute('src', …) on `.x` |
| `.x { value <- $q; }`           | nothing          | setAttribute('value', …)       |
Contrast: `.x { [slot] <- $v; }` (ATTRIBUTE arrow) DOES emit (separate path), and
`.x { text: $v; }` (COLON form) DOES emit textContent. Only the BARE-ident arrow drops.

The cutover migrated examples/data-binding/styles.st (`text <- $cartTotal`,
`$cartCount`) + examples/tutorial/tutorial.st (`text <- $state`) onto this broken
form, and the E0910 migration hints recommend it → dead reactive bindings shipped.
This is the silent-swallow trap PLAN-030 forbids.

* Root cause (two layers)
1. PARSER (src/syntax/cst/parser.rs `parse_css_property_or_statement` ~2706): the
   is_property lookahead only matches `name (ws) (?) COLON`. A `LEFT_ARROW` is not
   recognized → the IDENT is `bump()`-ed, value dropped. No CssDeclaration, no
   FormMatch → even E0909 (scans FormMatch captures) never fires.
2. STALE CONSTRAINT (src/pipeline/mod.rs `check_injection_outside_template`, E0909):
   asserts `<-` is "only valid inside a @template body" — contradicts FEAT-072 spec
   lines 50-51 (must work at file/selector scope). Must be lifted for selector-scope.

* Fix (FEAT-072-aligned)
- Parser: extend `parse_css_property_or_statement` to also treat `name (ws) LEFT_ARROW`
  as a CSS_PROPERTY (parse via a `class_property`-style path that keeps the `<-` so the
  emitter sees the arrow). Mirror in events grammar if needed.
- Reify/emit: a selector-scope CssDeclaration whose value is `<- $expr` lowers via
  emit_reactive_binding_js → `text`/`content` ⇒ textContent; else ⇒ setAttribute(name).
  Route the arrow RHS through the same transpile + `local:<dep>:updated` arc the COLON
  form uses (incl. `| filter` pipes — spec line 68).
- E0909: do NOT fire for selector-scope `<-` (only for genuinely-invalid contexts, if
  any remain). Re-scope or remove check_injection_outside_template accordingly.
