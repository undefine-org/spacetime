* Intention & Purpose

=cargo run -- build projects/<name>/= MUST produce a =dist/= mirroring every route the site declares on disk. Today it only mirrors the root =index.html= plus anything under =pages/=. Sibling-route directories (=about/=, =contact/=, =talent/<person>/=, …) silently vanish from =dist/=, breaking deploys.

Goal: any =*.html= (with optional co-located =*.st=) anywhere under the site root participates in the export, with its relative path preserved in =dist/=.

* Reproduction

#+begin_src bash
cargo run -- build projects/unkn/
find projects/unkn/dist -name index.html
#+end_src

Expected: one =index.html= per route (=about/=, =contact/=, =expertise/=, =privacy/=, =talent/=, =talent/<person>/= ×9, =terms/=, =work/=, plus root).

Actual: only =projects/unkn/dist/index.html=. All sibling routes are absent.

Side observation: =projects/unkn/dist/talent/gabrielle-figueiredo/spacetime.{js,css}= exists without an =index.html=. That pair is a side-effect of =cargo run -- serve= having previously hit that route — proof that the dev server and the static exporter disagree on what "a route" is.

* Root Cause

=src/export.rs::export_site= (and =process_pages_dir=) only know two HTML sources:

#+begin_src rust
// src/export.rs:62–78
let index_html = site_dir.join("index.html");
if index_html.exists() { /* copy to dist/index.html */ }

let pages_dir = site_dir.join("pages");
if pages_dir.is_dir() {
    process_pages_dir(&pages_dir, site_dir, output_dir, &mut report)?;
}
#+end_src

Anything outside =site_dir/index.html= and =site_dir/pages/**/*.html= is invisible to the exporter. =projects/unkn/= uses a flat sibling-route layout (=about/index.html=, =talent/jessica-lee/index.html=, …), so 100% of its non-root routes are dropped.

Additionally, only the root =index.st= is compiled. Per-route =index.st= files (if a route wants its own bundle) are never compiled by =build=, even though =serve= compiles them on demand.

* Fix (this BUG, narrow scope)

Replace the =index.html + pages/= special case with a generic walker:

1. Walk =site_dir= recursively for every =*.html= file.
2. Skip a denylist of build/asset/source-control dirs: =dist=, =.git=, =node_modules=, =assets=, =data=, =locales=, =Fonts=, =Logos=, =Guide=, =Website_Content=, =_references=, =notes=, =tests= — and any dir starting with =.= or =_= (TBD: confirm against existing projects).
3. For each discovered =*.html=, process via =process_html= and emit at the same relative path under =output_dir=.
4. For each discovered =index.st= sibling of an emitted HTML (other than the root), compile it and emit per-route =spacetime.{js,css}= alongside — matching the layout =serve= already produces. (If we keep a single root bundle for v1, document it; root bundle currently includes everything via =@import=, so per-route compile may be unnecessary for unkn specifically.)
5. Preserve current =data/=, =assets/=, =locales/= copy behavior.
