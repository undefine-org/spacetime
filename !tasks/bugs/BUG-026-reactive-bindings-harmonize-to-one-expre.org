* Source
Discovered while building a reactive-bindings showcase demo. Verified by compiling + serving probes in a real browser (puppeteer), not docs.

* Root causes (compile-time extraction was the narrow link; runtime ST.signals/watch was already capable)
Three locally-coherent designs fought the general case:

1. **State actions were pattern-matched, not evaluated.** `parse_state_action` (src/syntax/events/form_compiler.rs ~L1893) only recognized Toggle(!$v) / Increment($v+N) / Decrement($v-N) / Set(literal); anything else became StateAction::Raw + an E0906 diagnostic, and the runtime Raw evaluator (stdlib/primitives/template.st) only handled !$x, $x, JSON.parse — no arithmetic/array ops. So `$count <- $count + 1` (non-literal), `$items <- $items.concat([...])`, `.map`, `.filter` all silently failed.

2. **Content/attr bindings were not extracted from selector blocks.** `parse_component_body` only scanned inner lines for `.class: $v` (toggle) and `&self.prop <- $expr`; `.sel { text: $expr }` fell through to dead css_rules → value DISPLAY silently no-op'd.

3. **@on event space-selector form unsupported.** `@on click .inc { }` parsed ".inc" INTO the event string; only the paren form `click(.inc)` split event/selector.

4. **@computed greedy capture.** `from: $sig` swallowed trailing clauses (`items; reduce:...; initial:0`) as the dependency name → false E0405. And validate_computed_dependencies (src/analysis/mod.rs) never included $-scoped signals in the lookup set.

* Fix (harmonization: "any binding or action is an expression over signals")
- R1: accept `@on click .inc` (space form) ≡ `click(.inc)` — parse_on_event_block.
- R2: state mutation RHS is a first-class expression; `$sig` transpiled at compile time to `ST.get(__el,'sig')` and emitted as a real `(__el) => (expr)` arrow (no runtime eval). Fast paths (Toggle/Increment/Decrement/Set) retained as codegen shortcuts. New helpers transpile_signal_expr + collect_signal_deps in src/syntax/form_match.rs.
- R3: `.sel { text|content|attr: $expr }` extracted to ContentBinding carrying a transpiled apply arrow + full dependency set; runtime re-evaluates on any dep change. Legacy `&self.x <- $a.b` dotted simple-ref preserved via allow_dotted_ref flag.
- R4: computed dependency reduced to its leading identifier (leading_source_ident); reactive source resolution unified (reactive_source_names) so @data + @computed + scoped $state + signals are one lookup set.

* Tests
- Unit (src/syntax/events/form_compiler.rs): transpile_signal_expr, @on space-selector, content-binding-expression-from-block; updated 2 tests that encoded the old E0906-for-expressions contract.
- Integration (tests/integration/reactive_properties.rs): space-selector compiles + wires selector, content-binding expression transpiles, @computed from $state with reduce/initial raises no false E0405.
