#+TITLE: "@each with key: plus :entering/:exiting motion fails E0946 (regression)"
#+STATE: ITEM
#+CUSTOM_ID: BUG-291-each-key-plus-motion-fails-e0946-regres

* Symptom

At HEAD, an `@each` that combines a `key:` with `:entering`/`:exiting`
motion fails compilation with E0946. Each half passes alone:

- `@each($rows as $r, key: $r.id) { … }` — passes
- `@each($rows as $r) :entering { … }` — passes
- `@each($rows as $r, key: $r.id) :entering(fade) :exiting(fade) { … }` — E0946

Found porting knowledger's library.st/reframes.st to HEAD (FEAT-017,
2026-08-05); probes in /tmp/stprobe p12/p13. The screens dropped motion
and kept `key:` (keyed diffing is load-bearing, motion was garnish).

* Expectation

Key and motion are orthogonal concerns; the grammar accepted the
combination before the SIP-001 port.
