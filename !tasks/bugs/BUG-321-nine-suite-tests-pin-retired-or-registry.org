* Triage (each verified, not assumed)

** 1. bare_ident_string_arg::bare_ident_named_arg_emits_nonempty_runtime — FIXTURE INVALID
The fixture declares `%macro mm { %form { @mm(mode: $mode:string) } }` with NO `%binds` and
NO `%emit`. It therefore names a primitive that does not exist, and W4/BUG-268's E0956
("unknown primitive: mm") is CORRECT. Before, the macro silently emitted nothing and the
test asserted `js.len() > 0` against unrelated runtime boilerplate.
FIX: give the fixture macro an `%emit`, or assert the diagnostic.

** 2. bare_ident_string_arg::stdlib_loop_mode_accepts_bare_ident — PINS A RETIRED MACRO
Uses `@loop spin (2s, mode: bounce)`. `@loop` was RETIRED by the on-cutover migration
(`stdlib/migrations/entries/2026-07-26-on-cutover.st:722`:
"@loop is now `@on &.loop(...)` — duration/mode/phase are driver params").
The test pins a spelling the language no longer has — same class as BUG-314.
FIX: rewrite to `@on &.loop(...)`; the bare-ident behavior under test is unrelated to the head.

** 3-5. wave1_primitives::reveal_{words,chars,lines}_type — REGISTRY-LESS HARNESS
`compile_js()` calls `parse()` + `compile()` directly with NO `@import "stdlib"`, so the
sibling `reveal-simple` form is not registered and a bodyless `@reveal(...)` can only be
scored against `reveal-with-keyframes`, which requires a body → E0946.
VERIFIED NOT A LIVE REGRESSION: through the real compiler both spellings pass —
`.a { @reveal(split: "words", stagger: 50) }` ✓ and the with-body form ✓ (`check` clean,
`build` complete).
FIX: the harness should load the stdlib registry (as `check`/`build` do), or the test should
declare both sibling forms.

** 6-7. data_kind_dispatch::{live_emit_ephemeral_selects_fire_and_forget_bridge, ordinary_live_emit_remains_correlated}
** 8. reactive_properties::test_killed_bind_e0910_and_hint_kind_compile_through
** 9. v8 per_instance_compiled_tests::editable_bind_is_per_instance_across_two_compiled_instances

* Why these were NOT "fixed" by editing them green

information. Making them pass by loosening the matcher would undo W3, and making them pass
by rewriting assertions without understanding would repeat exactly the BUG-309 vacuity
failure this arc was built to eliminate. They are filed with their diagnosis so the fix is a
decision, not a silencing.
