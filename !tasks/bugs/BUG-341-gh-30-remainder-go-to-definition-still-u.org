** Two real defects found while finishing this, both fixed here

1. **Clicking the FIRST character of a primitive name did nothing.** The `%binds` classifier
   derived the identifier only from text BEFORE the cursor, so an empty `trimmed` (cursor on the
   name's first char, nothing but whitespace behind it) took an early `return None`. Offsets 14+
   resolved; offset 13 — the natural click target — did not. Now falls through and lets the
   after-cursor text supply the name.

2. **`imported_binding_resolves_cross_file` was testing nothing.** It called `add_root` (which
   scans the workspace to build the index) BEFORE writing the two .st files, so the index was
   empty and the lookup could only ever return None. Cross-file resolution was already working;
   the test's ordering was the bug. Files are now written first.
