* Source
Discovered while building the FEAT-041 full-Spacetime showcase. Probed whether an inline @template (HTML body defined in .st) can back an @each list.

* Problem
An inline @template with an HTML body COMPILES CLEAN but renders NOTHING. @each over a source whose item template is an inline @template produces zero DOM nodes. Only EXTERNAL templates (separate files served as `<template data-component="name">`, as examples/cart-demo uses) are found by each-with-templates' findTemplate() (which does document.getElementById / querySelector / `template[data-component]`).

* Repro
  /tmp/tmpl/index.st:
    @template &chip($label) { <span class="chip">{$label}</span> }
    @data tags: string[] { src: inline; value: ["alpha","beta","gamma"]; }
    .tag-row { @each($tags as $t) { &chip($t); } }
  => `cargo run -- check` passes; serve + load => 0 .chip elements; served index.html is a ~261-byte empty shell with NO <template> tag emitted.

* Root cause (hypothesis)
The inline @template definition is not emitted into the page as a discoverable `<template data-component="chip">` node (nor registered in window.IK.templates / a runtime template registry). So each-with-templates findTemplate() returns null and render() bails ("template not found"). cart-demo works only because product-card/cart-item are EXTERNAL `<template data-component>` files.

* Impact
Blocks full-Spacetime (.st-only, no external component files) list rendering — a core FEAT-041 goal. Combined with BUG-028 (inline-HTML @each body => E0804) and FEAT-043 (.st-only page gen incomplete), there is currently NO working full-Spacetime path for @each lists; the only verified path is external `<template data-component>` + index.html (cart-demo).

* Acceptance
- An inline @template &name(...) { <html/> } is emitted as a discoverable template (e.g. `<template data-component="name">` injected into the document, or registered in the runtime template registry) so each-with-templates findTemplate() locates it.
- The /tmp/tmpl repro renders 3 .chip spans (alpha/beta/gamma) with {$t} interpolated.
- Regression test (codegen: inline @template emits a template node/registration; + live render).
