* Problem
`@data products: P[] { src: inline; value: [ {...} ]; }` fails with:
  error[E0504]: Data source file not found: inline; value: [ {...} ]
The `inline` keyword + `value:` clause is treated as a file path instead of an inline data source. Documented in DATA_BINDING_GUIDE.md and used by examples/cart-demo/index.st.

* Repro
  @type P { id: string; }
  @data products: P[] { src: inline; value: [ {"id":"p1"} ]; }
  .g { @each($products as $p) { } }
  => cargo run -- check  => E0504

* Expected
`src: inline` with a `value:` literal loads the array at compile time (no file read). DataSource analysis already has a Runtime/inline notion (src/analysis/mod.rs analyze_data_sources) — wire the `inline` source + `value:` capture through the data loader instead of resolving it as a path.
