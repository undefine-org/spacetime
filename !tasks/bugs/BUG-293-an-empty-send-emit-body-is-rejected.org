#+TITLE: An empty send emit body is rejected
#+STATE: ITEM
#+CUSTOM_ID: BUG-293-an-empty-send-emit-body-is-rejected

* Symptom

#+begin_example
@data signal $clear() to $view {
  send emit "clear" { }
  receive to ClearResult { _ => Cleared($.reply); }
}
#+end_example

A zero-param signal whose `send emit` carries an EMPTY body fails
compilation. The only working spellings are `send emit "clear"` (no body,
params sent by name — which is exactly right for zero params) or a
non-empty body. Found porting knowledger's reframes.st to HEAD
(FEAT-017, 2026-08-05).

* Expectation

`send emit "x" { }` ≡ `send emit "x"` — an empty map is the natural
spelling of "no payload".
