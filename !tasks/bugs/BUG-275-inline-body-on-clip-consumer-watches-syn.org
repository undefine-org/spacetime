* Initial Message

can you tell me which examples and demos use `@score`? I want to test drive the video creation. And create a catalog that lets us see the new opportunities provided to us by this new feature

* Symptom
`@on &.clip { opacity: 0 -> 1; }` — an INLINE keyframe body under a clip driver — compiled clean and never moved. The form-call spelling (`@on &.clip: --rise;`) worked.

* Root cause
Two lowering paths in src/pipeline/drivers.rs compute `drive_name`. The form-call path routes through `score::inherited_progress_name` (`__clip_<element>`, W5a/D1 — the name IS the address the score publishes). The inline-body path did not: it fell through to the synthetic `__drive_{member}_{counter}`, a signal no score publishes. score.rs's own comment says "Both call sites route through here so the rule cannot drift" — it had drifted.

* Evidence (silent-break shape, BUG-252 class)
Emission looked right everywhere: the score published `__clip_sc1` etc., the consumer registered watchers — but on `__drive_clip_10`, which appeared 9 times in the bundle, ALL inside the consumer's own init. A green build where nothing moves.

* Fix
src/pipeline/drivers.rs (inline-body `drive_name`): route through the same `driver_inherits_progress` + `inherited_progress_name` rule as the form-call path.

tests/score/score-launch-film.test.st (film scenes + cover transition + color + stagger) — written RED first (3 failures on the unfixed compiler), green after. Full suite: `cargo run --features cdp -- test tests/score/ --cdp` 28/28.
