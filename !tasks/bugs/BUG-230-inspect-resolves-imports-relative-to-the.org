* Symptom

The same file + same import string resolves under =check= but not under
=inspect=:

#+begin_src sh
# file: scratch/spike/use.st containing:  @import "scratch/spike/on_pat"
cargo run -- check   scratch/spike/use.st     # ✓ resolves
cargo run -- inspect scratch/spike/use.st --layer expansion
# ✗ Import resolution failed: Could not resolve import 'scratch/spike/on_pat'
#   Searched: ["scratch/spike/scratch/spike/on_pat"]     <-- path doubled
#+end_src

=inspect= joins the import against the FILE's directory; =check= joins it
against the workspace root. The doubled path in the error message shows
the mechanism.
