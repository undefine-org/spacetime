** Symptom
A page importing multiple .st.md files (the FEAT-172 gallery pattern) rendered
the LAST import's prose in EVERY prose section — and the host's own prose
vanished too. Fences and live elements were unaffected (correct order).

** Root cause
tangle() numbers each file's prose segments from 0 and emits
`[data-lit-seg="0"] { @doc(content: …) }` rules. Merged into one page, N files
produce N rules with the same selector and different content → CSS
last-writer-wins → one prose everywhere.

** Fix
`tangle_seeded(input, seed)`; read_source derives a deterministic per-file
seed (FNV-1a over the path, 16 hex) so segment ids become `<seed>-<n>`.
Unseeded tangle() keeps the historic bare ids (standalone pages unchanged).
