* Found via
Round-2 pressure test, same BUG-155-class audit as BUG-162. `@portal(when:
$ui.modalOpen)` never opened the portal — a common REAL shape (a UI-state
object with a modal-open flag as one field among several), not a contrived
edge case.

* Repro (isolated, RED confirmed on pre-fix code)
#+begin_src
@data inline $ui : { "modalOpen": false };
.modal { @portal(when: $ui.modalOpen) }
.toggle { @on click { $ui <- { "modalOpen": true }; } }
#+end_src
Clicking `.toggle` left the modal closed (`aria-modal` never set, never
relocated to `document.body`).

* Root cause
`stdlib/primitives/portal.st::portal-mount`'s `readValue()` checked `sig in
window.SpacetimeLocal` (a literal dotted string like `"ui.modalOpen"` is
never a real top-level property) and `ST.get(node, sig)` (same issue). The
reactive channels (`local:<sig>:updated`, `ST.watch`) were ALSO keyed by the
literal string. Same root cause as BUG-155/160/161/162.

Additionally (a wrinkle none of the OTHER fixes needed): `@portal`'s
`setClose()` WRITES a value back (`false`, on Escape/close) — for a dotted
`closeSignal`, a naive `window.SpacetimeLocal[closeSig] = false` can't work
at all (no such literal key), and even `window.SpacetimeLocal[head].field =
false` would NOT trigger the `SpacetimeLocal` Proxy's reactive dispatch
(the Proxy only traps a top-level assignment `SpacetimeLocal[head] = ...`,
not a nested property mutation on an object it already returned).

* Fix
- `readValue()`: derive `sigHead`/`sigTail`, resolve the head then walk the
  tail as property access (mirrors BUG-155/160/161's read-side fix exactly).
- `setClose()`: for a dotted `closeSignal`, read the CURRENT head object,
  shallow-clone it (and every intermediate nested level along the tail
  path), patch the final tail field to `false` on the clone, then reassign
  the WHOLE head (`window.SpacetimeLocal[closeSigHead] = clone`) so the
  Proxy's `set` trap fires and dispatches `local:<head>:updated` correctly —
  the write is OBSERVED, not silently swallowed.
- Both `local:<sig>:updated`/`ST.watch` registrations now key off `sigHead`.
