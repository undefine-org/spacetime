* Source
Found verifying BUG-031 live: cart-demo now renders 4 product cards, but clicking does nothing — there are zero [data-add-to-cart] elements in the DOM.

* Problem
examples/cart-demo/index.st defines `.product-grid { @on click [data-add-to-cart] { $cart <- $cart.concat([...]) } }` but the `@template &product-card` markup contains no element with `data-add-to-cart`. So the add-to-cart interaction can never fire.

* Fix
Add an add-to-cart button inside the &product-card template, e.g.:
  <button data-add-to-cart>Add to Cart</button>
Then verify in-browser: clicking adds the product to $cart, the cart-count, cart-items @each, and computed total update reactively.

* Acceptance
- Clicking a product's add-to-cart button appends to $cart.
- .cart-count, .cart-items, .total-amount update reactively.
- This makes cart-demo a fully working reactive showcase end-to-end.
