* Symptom
A binds-macro defined inline expanded fine (68KB JS), but the IDENTICAL macro
brought in via =@import= produced 0 bytes — the =@<macro>()= directive was never
matched/expanded.

* Root cause
=rematch_with_user_macros= re-parses the main source with an augmented registry,
then assigns the new matches only to scopes where =source_file.is_none()=. But
=resolve_imports= tags the MAIN file's scopes with its path (not None) — so after
import resolution, every main-file scope was EXCLUDED, and imported-macro matches
were never assigned to any scope.

* Fix (commit e1076acf, PLAN-024 W3)
Added =rematch_with_user_macros_in(ast, source, main_source_file)=; the scope
filter now accepts =source_file.is_none() || == main_source_file=. =Compiler::from_file=
passes the main path. Old 2-arg fn delegates with =None= (inline path unchanged).
File: =src/parser/mod.rs=.
