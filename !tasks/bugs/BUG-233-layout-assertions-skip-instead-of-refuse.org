Expected: =passed: 1, failed: 2= — the two layout-needing assertions REFUSED
(reported as failures naming the fidelity gap).
Actual: they are SKIPPED, and the run is green.

* Why it matters

This is the exact invariant FEAT-057 exists to protect, and the test that guards
it is the one failing. From =docs/testing/FIDELITY_LADDER.md=: a layout assertion
on a layout-less backend must REFUSE, never silently pass. A skip is softer than
a refusal — it produces a GREEN run for a suite whose layout claims were never
evaluated. That is precisely the vacuous-green class the ladder was built to
prevent.
