#+TITLE: Boolean template interpolation emits an empty string
#+STATE: ITEM
#+CUSTOM_ID: BUG-289-boolean-template-interpolation-emits-em

* Symptom

Backtick/template interpolation of a boolean value from a subscribed list
renders "" instead of "true"/"false". The knowledger desk's ledger rows
carried `credited: bool` from the server; interpolating it in the row
template produced empty output. Switching the server projection to the
STRINGS "true"/"false" rendered correctly.

* Repro

#+begin_example
@data subscribe $rows list ;
@each($rows as $r, key: $r.id) {
  &row($r)
}
/* inside &row: */ `credited: $r.credited`
#+end_example

with `%{"credited" => true}` in the server payload → renders "credited: ".

* Workaround (in use)

Project booleans as strings server-side.
