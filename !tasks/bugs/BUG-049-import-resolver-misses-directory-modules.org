* Symptom
=@import "stdlib/text"= failed: "Could not resolve import 'text' ... Searched: []".
Directory-layout modules (the PLAN-024 modular shape) were unresolvable.

* Root cause (two issues)
1. =resolve_stdlib= only tried a flat =stdlib/<name>.st= file; never
   =stdlib/<name>/index.st= (the modular directory layout).
2. =stdlib_path= is derived from the workspace root, which for
   =build path/to/site.st= is the site file's PARENT dir — so stdlib resolved
   relative to the site, not the repo. Worked for =check= (cwd) but not =build=.

* Fix (commit e1076acf, PLAN-024 W3)
=src/lsp/workspace/import_resolver.rs::resolve_stdlib=: try, per root,
=<module>.st= then =<module>/index.st=; roots = configured stdlib_path THEN
=<cwd>/stdlib= fallback. Reports both searched paths on miss.

* Verification
=@import "stdlib/text"= resolves to =stdlib/text/index.st=; text fixture builds.
lib 2090 + integration 162 green.
