error[E0602]: Scope selector 'body' does not match any element

scope check can match. PROVEN pre-existing (2026-08-03): the error persists
with the @effect→@on migration line removed — NOT a BUG-263 regression.
Likely a scope-selector strictness change that this demo predates.
