* Source
Verifying BUG-033 end-to-end. The file-scope reactive binding feature itself works (fsdemo: .tot 0->30, .cnt 0->3 live). But in examples/cart-demo, after add-to-cart, cart ITEMS render (@each, 0->2) yet .total-amount stays "$0" and .cart-count stays empty.

* Evidence
- emitted JS DOES contain the binding: querySelectorAll(".total-amount") + addEventListener("local:cartTotal:updated", render). So the file-scope binding (BUG-033) is correctly emitted.
- A minimal fsdemo with the SAME shape ($cart state + @computed $cartTotal from $cart + .tot { text: $cartTotal }) updates live. So the binding mechanism works.
- Difference in cart-demo: mutation is event-delegated (`.product-grid { @on click [data-add-to-cart] { $cart <- $cart.concat([{ ..., price: +$.closest('product-card').dataset.price, ... }]) } }`) and prices come from dataset string coercion.

* Hypotheses to check
1. @computed $cartTotal does not re-dispatch local:cartTotal:updated when $cart changes in cart-demo (computed-source dispatch chain), OR
2. the concatenated item has NaN price (dataset coercion) so cartTotal=NaN and the binding is skipped (apply() returns NaN -> but textContent would show NaN, not stay $0 -> suggests binding never fires -> points to #1), OR
3. script execution order: binding addEventListener registered after computed's only dispatch.

NOTE [2026-05-30]: FIXED + verified live (commit 01b6baa4). Root cause was hypothesis #1: @computed compute() did ST.set(el,'value') only, never publishing to the global store nor dispatching local:<name>:updated, so file-scope bindings (BUG-033) could not react. Fix in stdlib/primitives/data/computed-source.st: after %yield, write window.SpacetimeLocal[computedName]=value + dispatch CustomEvent(`local:${computedName}:updated`). Also hardened source subscription to register both ST.afterData (remote) and local:<src>:updated (local) listeners unconditionally (the prior single-branch form dropped local mutations at init; also removed a non-existent ST.getData call that threw and broke page init). TDD: test_computed_publishes_global_signal_and_dispatches (RED proven by stdlib revert, GREEN after).
