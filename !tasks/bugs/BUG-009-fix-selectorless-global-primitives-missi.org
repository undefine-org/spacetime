Current code:
#+begin_src rust
let el_init = match primitive.phase {
    Phase::Global => match &primitive.selector {
        Some(sel) if !sel.is_empty() => Some(ElInit::Selector(sel.clone())),
        Some(_) => Some(ElInit::Body),
        None => None,
    },

};
#+end_src

Change the ~None => None~ arm to:
#+begin_src rust
None => {
    // Selectorless global primitives that use %yield or %cleanup
    // need an element reference for ST.set(el, ...) and ST.onCleanup(el, ...)
    if !ir.exports.is_empty() || !ir.cleanup_stmts.is_empty() {
        Some(ElInit::Body)
    } else {
        None
    }
}
#+end_src

This checks ~ir.exports~ (populated from ~%yield~ declarations at codegen time) and ~ir.cleanup_stmts~ (populated from ~%cleanup~ blocks). Using ~document.body~ is safe because signal names across dev primitives are disjoint and ~ST.set~ uses per-name slots in a WeakMap.

- Double-IIFE pattern (hand-written IIFE inside ~%emit js~) — the outer pipeline IIFE injects ~const el = document.body~, inner IIFE captures it via JS closure (verified)
