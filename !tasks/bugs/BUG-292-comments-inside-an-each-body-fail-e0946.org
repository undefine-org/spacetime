#+TITLE: Comments inside an @each body fail E0946
#+STATE: ITEM
#+CUSTOM_ID: BUG-292-comments-inside-an-each-body-fail-e0946

* Symptom

A `/* … */` comment line inside an `@each` body fails compilation with
E0946 ("@each body = template invocations only"). Comments are not
invocations, but they are not content either — stripping them before the
body-shape check is the expected behaviour.

Found porting knowledger's screens to HEAD (FEAT-017, 2026-08-05):
explanatory comments had to move OUT of every `@each` body.

* Repro

#+begin_example
@each($rows as $r, key: $r.id) {
  /* one ledger row per obligation */
  &row($r)
}
#+end_example

* Expectation

Comments are transparent everywhere, including inside directive bodies.
