* Why this matters

`spacetime migrate` SKIPS a file it cannot parse:

#+begin_example
⚠ ./web/index.st does not parse — skipped
#+end_example

A skipped file is invisible to the migration: it is not counted in "N sites
pending", not rewritten, and not `@version`-stamped. When the project's
`@version` reaches a wave date, any retired syntax inside it becomes E0911
with no prior warning — the migration will have reported success while
stepping over it.

So "0 sites pending" is only trustworthy once every file parses. Found during
the AUD-009 sweep.
