* Gap
`render_page_shell` (src/html/page_shell.rs) hard-codes the document shell for `.st`-only routes: `<html lang="en">`, `<title>Spacetime</title>`, NO mechanism to inject `<meta>`, `<link rel="stylesheet">` (Google Fonts), `theme-color`, or OpenGraph tags.

A full-Spacetime page cannot: set `lang` (need `fr`) or `<title>`; declare remote web fonts via `<link>` (only `@font` self-hosted `url()` works); emit SEO/OG `<meta>`.

* Impact
backdesk-hospitality wants `.st`-only (user request) but must keep a hand-authored index.html purely to carry <head> (lang, title, Fraunces/Inter/Noto-Arabic fonts, OG meta).

* Desired
File-scope `@page`/`@head` directive (or hoisted `head{}` markup) → compiler feeds render_page_shell title/lang/head tags instead of hard-coded constants.

* Workaround (current)
Minimal index.html shell carries lang=fr, title, OG meta, Google Fonts link. All body + styles + motion remain .st.

- .st entry sets <title> and <html lang>.
