** DONE Live reload cancelled link navigation in Firefox
Firefox closes the live-reload WebSocket when navigation STARTS, while the old
page is still current; the unguarded =onclose= reload (2s) then reloaded the
old page whenever the next page took longer than 2s to compile: every link
"brought you back home". Reproduced in Firefox 157 via geckodriver
(navigation type =reload=, history length 1); fixed by ignoring the close of a
page being left (=beforeunload= / =pagehide=, reset on bfcache =pageshow=).
Verified: /who, /services, /writing all land, type =navigate=.
Test: =server::tests::live_reload_does_not_reload_a_page_being_left=.

** DONE Derives no longer log while their inputs are unpublished
=__stDerive= reported every throw, so dev widgets (comments, inspect, host)
spammed =[derived-signal …] TypeError= before their first data. A throw
while any input is still =undefined= is now silent; a throw with every input
present is still reported. Verified: 0 derived-signal errors on a fresh load.
