* Context
UNKN is a new Spacetime website under `projects/unkn` based on `projects/unkn/UNKN_Desktop_Home.pdf`, supplied fonts, and supplied logos. Current folder has no `.st` files. The PDF is the authoritative style/content spec: strict black/white editorial home page fidelity, desktop section order preserved, typography/whitespace as close as possible. User-approved scope: build home plus clean placeholder routes for About, Talent, Work, Expertise, Contact. Use latest Spacetime affordances and folder hierarchy, including `@import "stdlib"`, `@template &... {}` reusable parts, `@type`/`@data`/`@each` for repeatable content, stdlib/project macros for motion, no custom JS in HTML.

Settled decisions:
1. Route model: clean dev routes using `talent/index.html` + `talent/index.st` etc.; FUP covers full route content and static export parity if current export misses root route dirs.
2. PDF fidelity: very strict for static layout, section order, typography hierarchy, whitespace, and black/white style.
3. Motion: culture-forward editorial with kinetic words/chars, magnetic CTAs, scroll line-wipes, subtle monochrome parallax blocks, custom difference cursor.
4. Custom code: project-specific macros are allowed; small project-specific primitives under `projects/unkn/primitives/` are allowed only if stdlib cannot express a desired effect and the primitive is documented/tested.
5. Imagery: abstract monochrome typographic/editorial compositions only; no faces, no real people, no fake campaigns.
6. Assets: normalize into `assets/fonts/` and `assets/logos/`, preserving originals.
7. Content: use `The (Un)Known` for agency, `(un)known`/logo for brand mark, `(un)kn` only in footer copyright.
8. CTAs: contact CTAs use `href="#contact"`; no fake backend/form submission.
9. Data: hard-code hero/mission where fidelity requires exact control; use `@type`/`@data`/`@each` for stats/services/reasons/work-card arrays.
10. Verification: `cargo run -- check`, `cargo run -- doctor projects/unkn/ --format pretty`, `cargo run -- inspect`, desktop/mobile screenshots, PDF reference screenshots, route checks, and `Spacetime.review()` report copied into notes.

Key repo evidence:
- `projects/unkn/UNKN_Desktop_Home.pdf` text defines full home content.
- `projects/unkn/Fonts/` contains Oranienbaum, SF Pro Text regular/bold, Adobe Handwriting.
- `projects/unkn/Logos/` contains black/white full wordmark and icon PNGs.
- `stdlib/macros/template.st`, `each.st`, `type-data.st`, `on-event.st`, `timeline.st`, `reveal.st`, `cursor.st`, `magnetic.st`, `responsive.st`, `css-at-rules.st` provide the planned affordances.
- `stdlib/index.st` currently references missing `macros/scroll-timeline.st`; `BUG-023` handles aggregate import repair before project work relies on `@import "stdlib"`.
