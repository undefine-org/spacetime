**Fixed — closing.**

Your exact repro now fails the build:

```
error[E0956]: unknown primitive: stage
  hint: Check the %binds/driver that names it
```

`check` and `build` both exit 1.

**What made this bug possible.** Macro expansion had a catch-all branch that, on encountering a primitive it couldn't resolve, emitted a *comment* into the output — `// Primitive not found: stage` — and carried on. So forgetting `@import "stdlib/3d"` didn't produce an error. It produced a blank page and a note addressed to nobody.

The rule now is that the default branch fails. A catch-all that "handles" the unknown case by writing a note is how a missing import turns into a mystery.

This is also why #22 closed with the same change: `@use` was leaking `Primitive not found: use` into bundles through that identical branch. One catch-all, two symptoms.
