**Fixed — closing.**

`animate-color` now dispatches the way the keyframe path already did: `ST.interpolateColor` for OKLCH, `ST.interpolateColorRgb` for sRGB, plus a guard so an unparseable endpoint skips the tick instead of assigning `null`.

**Why this bug was possible at all**, which is the part worth carrying: in Spacetime, a `%primitive` emits JavaScript as a *string*. Nothing type-checks that string against what the runtime actually exports. So a call to a function that does not exist — `ST.lerpColor` — can sit in stdlib for months and only fail on the first tick of the first page that uses it.

The gate added with the fix is deliberately blunt about that: it asserts `ST.lerpColor` does **not** exist. A primitive naming it again is a failing test rather than a silent `TypeError` in someone's browser.

The deeper fix — interpolation chosen by *type*, from the scalar-type table, so adding a new animatable type doesn't mean writing a new primitive — is tracked as FUP-160 and now has the table it needed.
