That's a bug shape worth internalizing. The error path **existed**, was **correct**, and had **no consumer**. When auditing a diagnostic system, the question "who reads this channel?" catches far more than "is this error implemented?" — because an unimplemented error is an obvious gap, while an unread one looks like working code.

The same question, asked across this backlog, turned out to be the single highest-yield audit available: it also explains #26 (an analysis with no caller) and #32 (diagnostics computed but never published to the editor).
