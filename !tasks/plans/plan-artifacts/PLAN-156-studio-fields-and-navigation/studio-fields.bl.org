* In one breath
#+begin_lede
The studio shouldn't be a special case. It should be what you get when the
language can *look at itself* (reflect) and *edit itself* (rewrite), and when
declarations say enough about themselves (types, docs, examples, facts from
files) that a field picks its own widget. Every one of those capabilities also
serves the LSP, MCP agents, the admin and the migrator.

Measuring the stdlib turned up the debt that stands in the way. Params are
declared twice, and 11 pairs already disagree. 1,319 JSDoc-style tag lines
duplicate what the code declares, and some are now wrong. Light's own documented
example compiles, with no warning, to the wrong light. The fixes are language
changes, applied by the migration engine, and they leave the .st shorter.
#+end_lede

* Why not src/studio
#+begin_note :title "The reasoning"
I put =src/studio/= there because PLAN-154 started it and it was the shortest
path to a working editor. That doesn't make the studio special. Look at what the
module does. *Reading the program with spans* is what the compiler should already
produce for every consumer. *Writing words back safely* is what =spacetime migrate=
already does. *Knowing what a clip is* belongs to the stdlib that defines clips,
by the project's own rule (no Rust for stdlib constructs). A module named after
one consumer is a sign the language is missing two general capabilities.
#+end_note

#+begin_terms
Reflect | One dev-server projection of the program: every form match with its form, registry entries, file and span; each param with its declared type, default, docs, written words (and their spelling), value, and any facts from files. Generic: no macro name appears in Rust.
Rewrite | One way to change source. A transaction is a list of edits (address, expected text, new words). It is guarded, re-parsed before it's written (refused if it doesn't parse), hot-applied or reloaded, and recorded for undo. Studio gestures, admin saves, MCP edits and migration waves all use it.
Registry entry | What a form is *for*, declared in the stdlib next to it with =%registers clip(…) { … }=, so tools ask « all clips » instead of naming =on-driver-body=.
Fact | Something read from a file a param points at: a model's clips, an audio file's length, an image's size.
#+end_terms

* The language changes
Each change makes the .st shorter or makes it say more, and each is applied by a migration (see *Migrations*).

** L0 · Light, before and after
Before: =stdlib/3d/macros/light.st= (80 lines) plus =three-light.st='s header.
The params are written four times: =%form=, =%binds=, =%primitive=, and two =@param= blocks.

#+begin_src st
/// A light on the stage. Name it (`&sun`) to animate it from a score.
%macro light {
  %scope selector
  %form {
    @light $named:part_name? (
      /// how it shines
      type: $type:light_kind = directional,
      color: $color:color = white,
      intensity: $intensity:luminance = 1,
      pos: $pos:vec3 = 3 5 4,
      /// where a directional or spot light points
      target: $target:vec3 = 0 0 0,
      /// how far a point or spot light reaches; 0 is forever
      distance: $distance:meters = 0,
      decay: $decay:number = 2,
      /// the spot's cone, measured from its axis
      angle: $angle:angle = 30deg,
      /// how soft the spot's edge is
      penumbra: $penumbra:unit = 0.3,
      castShadow: $castShadow:bool = false
    ) { $children* }
  }
  %binds { three-light(&self, name: $named, ...) -> { $added } }
  %registers part($named) { kind: light }
  %template { $children }

  %example "a warm lamp the score can switch on" {
    @light &lamp (type: point, color: #ffcf8a, pos: -2.6 2.3 -4, distance: 9)
  }
}

/// how a light shines
%capture_type light_kind {
    /// light from everywhere, without shadows
    "ambient"
    /// parallel rays from far away, like the sun
  | "directional"
  | "point"
  | "spot"
}
#+end_src

In =three-light.st= the signature becomes types only:
=%primitive three-light(&el, name: part_name, type: light_kind, color: color, …)=.
The form owns the defaults. Authors write =@light &lamp1 (type: point, pos: -2.6 2.3 -4)=,
or keep =posX: -2.6=: both mean the same thing.

** L1 · Docs live on what they describe
#+begin_rosetta
| Today (a JSDoc carryover) | Native | Why |
| =/// @param penumbra - spot soft-edge 0..1= above the macro | =/// how soft the spot's edge is= above =penumbra:= in the =%form=; the range moves to the type (=unit=) | the name isn't repeated, so it can't drift; the doc moves with the param |
| =/// @yields $source - Raw source code string= | =/// the raw source= above =%yield … -> $source;= | the =%yield= line already declares it |
| =/// @param type - "ambient" or "directional" …= | =%capture_type light_kind { "ambient" … }= with a =///= per keyword | a choice is a keyword set, as =easing_keyword= already is, and each keyword has its own doc |
| =/// (default 1)=, =/// default 2= | deleted | the signature says the default (91 lines restate one) |
| =/// @example …= prose | =%example "title" { … }=, compiled by =spacetime check= and offered as an insertable snippet in the studio and LSP | 320 examples nothing compiles; light's own is wrong |
#+end_rosetta
Rule: =///= documents the declaration directly below it, wherever that is
(macro, param, =%yield=, type, tag). A load-time lint (W) flags a doc that only
restates the type or the default.

** L2 · Params are declared once
79 of the 105 =%binds= with three or more named args just forward =name: $name=
(401 lines). =...= forwards every captured param by name. A =%primitive= that is
only bound through forms declares types, not defaults. The form is the one
public signature (cell =drift=).

** L3 · Closed sets are keywords, open sets are strings
A set the source declares is a *keyword set*: a =%capture_type= of literal
alternatives, the mechanism =easing_keyword= already uses, with a =///= per
keyword. Values are written bare (=type: point=); the quoted spelling stays
accepted, because the parser already treats them as equal. An unknown word
becomes a compile error with suggestions instead of today's silent =null=.
A set that comes from outside the source (a model's clips, a font file's
families) is a *fact*, and its values stay quoted strings: they can contain
anything. Six 3D params start (=tone=, =shape=, =material=, =type=, =drive=,
=shadows=), then every =string= whose docs list options, and every inline union.

Not =@type=: =@type= sums describe *data* (=Idle | Failed(string)=, PascalCase
tags, payloads). A keyword is grammar, so it lives with the grammar.

** L4 · Ranges and units are scalar rows
New rows in =stdlib/scalars/types.st=: =unit= (0..1), =luminance=, =meters=,
=exposure= (stops); =angle= exists. Each row gets =%range=, =%step=, =%unit=, and
=%widget &w-number=. No new grammar. Inline refinements (=number(0..1)=) can come
later if the rows multiply.

** L5 · Shorthands and longhands (Q1)
A =vec3= param =pos= gets longhands =posX/posY/posZ=. The spelling rule
=<name><Facet>= is declared once on the =vec3= row, so =target=, =cam=, =rotate=,
=scale= and =spin= get it too (16 triple params in the stdlib). As in CSS: a
later longhand overrides the shorthand, a later shorthand resets the longhands,
and one number on a =vec3= means all three (=scale: 0.42=). Channels too:
=posX: 0 -> 6;= animates =pos.x=. The IR holds one =pos= node with per-component
provenance, so an edit to =pos.x= writes back where its words are.

** L6 · Facts from files (Q2)
=src: $src:model= (a scalar row with =%accepts ".glb" ".gltf"= and =%facts clips nodes=).
=clip: $clip:clip($src)= is a choice whose tags are =$src='s clips. The dev server
reads the glTF JSON chunk (a file format, not a language construct). Then:
- =clip: "Walkng"= is a compile error that lists the clips;
- score channels on =&robot clip= get the same check and the same menu;
- three.js reads the same file at runtime.
The file is the only truth. Audio files get =length= the same way, which fixes
the 2000 ms guess for sound lanes.

** L7 · Stops are a capture type
=a -> b at 40% --ease= gets a =%capture_type stop= grammar, retiring the Rust
splitter (=reify_keyframes= / =parse_stops=). Every stop is then a reflected
node with its own span, value, time and easing, and a keyframe widget is the
type of the param its channel animates.

** L9 · Tools find constructs through %registers
No new directive. The score macro registers its timeline, a clip body its clip,
a stage child its part:

#+begin_src st
%macro score-block {
  %form { … }
  %registers timeline($as) { length: $length }
}
%macro on-driver-body {
  %form { … }
  %registers clip($subject) { timeline: $driver channels: $lines }
}
#+end_src

Reflect lists registry entries with their spans (=entries_of("clip")=). The
studio asks for « every clip », and renaming a macro breaks nothing.

** L8 · Every node keeps its span
=@data= values and markup keep lossless spans in the compiler's own parse
(PLAN-155 did this for captures). =literal.rs= and =markup.rs= are deleted.

* Migrations
The engine (=docs/language/migrations.md=) rewrites *project* files from
=%rewrite= rules and never touches =stdlib/=. Two extensions:
- =%scope stdlib=: a wave that rewrites meta-syntax (=%macro=, =%form=, =%primitive=, =///=).
- Rules that reach across a declaration: a =/// @param X - …= line moves above =X:= in the same macro's =%form=.

Both run on *reflect* and *rewrite*, so the migrator dogfoods the facilities the studio uses.

(defn st-files [dir]

  (let [s (String/trim (String/replace s "\"" "")) m (Regex/run #"^(-?[\d.]+)(ms|s|px)?$" s)]

;; What the JSDoc-style tags say, sorted by where each belongs natively,
;; and how many %binds only forward `name: $name`.
(def lines (mapcat (fn [t] (Regex/scan #"/// @(param|yields|example)\b([^\n]*)" t)) texts))
(defn kind [[_ tag rest]]
  (cond (not= tag "param") tag
        (Regex/run #"\"[\w ]*\"\s*\|" rest) "param: choices → a sum type"
        (Regex/run #"\d\s*\.\.\s*\d|0\s*-\s*1\b" rest) "param: a range → a scalar row"
        (Regex/run #"\b(degrees?|radians?|ms|seconds?|px|deg)\b" rest) "param: a unit → a scalar row"
        (Regex/run #"(?i)default" rest) "param: restates the default → deleted"
        :else "param: prose → /// on the param"))
(def binds (mapcat (fn [t] (Regex/scan #"(?s)%binds\s*\{\s*[\w-]+\((.*?)\)\s*(->|\})" t)) texts))
(defn forwards? [[_ args]]
  (let [named (filter (fn [a] (String/contains? a ":")) (map String/trim (String/split args ",")))
        same (filter (fn [a] (let [m (Regex/run #"^(\w+):\s*\$(\w+)$" a)] (and m (= (nth m 1) (nth m 2))))) named)]
    (and (>= (count named) 3) (>= (count same) (- (count named) 1)))))
(def wide (filter (fn [[_ args]] (>= (count (filter (fn [a] (String/contains? a ":")) (String/split args ","))) 3)) binds))

#+begin_src beam-lisp :id facets
;; pos is a shorthand, posX/Y/Z longhands (L5). Params apply in order, as in CSS.
;; The IR keeps, per component, which written words hold it, so an edit writes back there.
(def axis {"X" 0 "Y" 1 "Z" 2})
(defn ir [params]
  (reduce (fn [v [name words]]
            (if (= name "pos")
              (let [ns (String/split words " ") ns (if (= 1 (count ns)) [(first ns) (first ns) (first ns)] ns)]
                (vec (map (fn [i] {:v (nth ns i) :from [name i]}) [0 1 2])))
              (assoc v (get axis (subs name 3)) {:v words :from [name nil]})))
          [{:v "0" :from nil} {:v "0" :from nil} {:v "0" :from nil}] params))
(defn values [params] (map :v (ir params)))
(defn edit [params i words]
  (let [[name k] (:from (nth (ir params) i))]
    (cond (nil? name) {:insert (str "pos" (nth ["X" "Y" "Z"] i) ": " words)}
          (nil? k) {:span name :words words}
          :else {:span name :component k :words words})))

(assert (= ["0.42" "0.42" "0.42"] (values [["pos" "0.42"]])))           ; one number means all three
(assert (= {:span "posZ" :words "0.4"} (edit [["posZ" "-7"]] 2 "0.4")))  ; the robot keeps its spelling

* Fields and navigation
#+begin_terms
Field | One editable fact about a selected thing: a param, a CSS declaration, a stop, a clip's =at=. In reflect, it's a param node.
Widget | An =@template &w-*($f)= that renders a field and emits a =change= with new words. It never knows where it is used.
Behavior | A small =%primitive= for what markup can't say: scrubbing a label, zooming a lane, orbiting a camera. JS lives only there.
Selection | A set of reflected addresses. The inspector shows the fields they share.
View window | The part of the film the timeline shows: =from= and =span= in ms.
Rest value / value now | What the source says vs what the playhead shows. A driven field edits the stop at the playhead.
#+end_terms

#+begin_principles
Types decide, the studio doesn't | The form declares =$x:luminance=; the scalar row says its widget is =&w-number= with a range and unit. Nothing names a widget per param.
A widget is a template | Markup, styles, one =change=. The behaviors it needs (scrub, swatch, curve) are primitives it calls.
Tools read reflect, write rewrite | The studio, the admin, the LSP, MCP agents and the migrator. None has a private parser or a private writer.
Gestures are words | Zoom and pan change only the view. A drag in 3D or on the timeline ends as one rewrite transaction.
The file is the truth | Facts from .glb and audio files, never a second list kept by hand.
#+end_principles
