* In one breath
#+begin_lede
Today every field in the studio is a text box. The studio doesn't know that
=intensity= is a number, =color= a colour, or =type= one of four words, even though
the stdlib forms already say so (=intensity: $intensity:number=). And you work on
one thing at a time: no zoom, no pan, no box selection, no handle in the 3D view.

The proposal is a layer of *widgets*: =@template= blocks in one shared library, picked
by the *type* the form declares, fed by *field descriptors* the compiler projects.
Navigation is a few generic *behaviors* (zoom-pan, an editor camera, a move handle)
that write words, like every other studio gesture. The studio's .st gets shorter,
its JS moves into small named primitives, and the admin drawer reuses the same widgets.
#+end_lede

#+begin_stats

* The words
#+begin_terms
Field | One editable fact about a selected thing: a part's param, a CSS declaration, a keyframe's value, a clip's =at=.
Descriptor | The record the compiler sends for a field: its address, label, type, value, value at the playhead, choices, range, unit, whether a channel drives it.
Widget | An =@template= that renders a descriptor and emits a =change= carrying the new words. It never knows where it is used.
Behavior | A small =%primitive= for what markup can't say: dragging a label to scrub, zooming a lane, orbiting a camera. JS lives only there.
Address | Where a field's words are: file, span, the text expected there. Every edit is still an op on words.
Selection | A set of addresses, not one key. The inspector shows the fields they share.
View window | The part of the film the timeline shows: =from= and =span= in ms. Zoom and pan only change it.
Rest value / value now | What the source says vs what the playhead shows. An animated field edits the stop at the playhead, not the rest value.
#+end_terms

#+begin_honest :title "What « automatic » never means here"
The studio won't guess. A field's widget comes only from a type declared in a
form or the scalar table. If a param has no type worth a widget, it stays a text
field until its form says more. No Rust list of param names, no doc-comment parsing.
#+end_honest

* Principles
#+begin_principles
Types decide, the studio doesn't | The form declares =$x:color=; the scalar table says a colour's widget is =&w-color=. Nothing in the studio or the server names a widget per param.
A widget is a template | Markup, styles and a =change= event. Behaviors it needs (scrub, swatch picker) are primitives it calls, so it stays .st.
One descriptor, one inspector, one commit | Parts, CSS rules, keyframes, clips and sounds all become descriptors; one =@each= renders them; one handler turns any =change= into ops.
Gestures are words | Zoom and pan change only the view. A drag in 3D or on the timeline ends as =span=/=insert= ops, so undo and the code pane stay exact.
Shared, not studio-only | The admin drawer's =&fld-*= templates and the studio's widgets become one =stdlib/widgets/= library.
#+end_principles

* The architecture
#+begin_graph :title "From a form's types to a word in the file"

node scalars | scalar table | %scalar_type color { %widget … } | 0,1 | foreign
node fields | src/studio/fields.rs | descriptors per selection | 1,0 | station
node sel | $stuSel | a set of addresses | 1,1 | you
node insp | inspector | @each &$f.tpl($f) | 2,0 | you
node widgets | stdlib/widgets | &w-number &w-color &w-choice … | 2,1 | door
node beh | behaviors | @scrub @zoom-pan @gizmo @editor-camera | 3,1 | builder
node ops | ops | span · insert · source | 3,0 | station
edge form -> fields | types | solid
edge scalars -> fields | widget names | solid
edge sel -> fields | which fields | solid
edge fields -> insp | descriptors | solid
edge insp -> widgets | one call per field | solid
edge widgets -> beh | uses | dash
edge widgets -> ops | change → words | solid
edge beh -> ops | drag end → words | dash
#+end_graph

#+begin_sequence :title "Scrubbing an animated field at the playhead"
lanes you · label drag | w-number · widget | studio · inspector | server · ops | stage · hot
you -> w-number : drag « intensity » right
w-number -> w-number : @scrub previews value (no write)
w-number -> studio : change {address, words: "1.6", now: true}
studio -> studio : field is driven → stop at 58% (exists? span : insert)
studio => server : POST ops [span …]
server --> studio : ok, new hashes
studio -> stage : hot apply (no reload)
note studio, server : the same path as a code-pane edit
#+end_sequence

** A field descriptor
#+begin_schema :id descriptor :title "What the compiler sends for each field"
field @edit | one editable fact, rendered by its template
  address -> span | file, start, end, expected text
  label text | =intensity=, =stop 3=, =at=
  type text | the declared type: number, color, unit, a union of words, vec3, asset, ref
  tpl text | the widget template, from the scalar table
  value text | the words written, or the default
  now text | the value at the playhead when a channel drives it
  driven -> channel | the channel line that animates it, if any
  choices text | from a union type, or a model's clips
  range text | min, max, step, unit: from the scalar row
  state written, default, mixed | mixed when several selected parts differ
span @link | where the words are
  file text | path, not an index
  start text | byte offset
  expect text | the text that must still be there (STALE otherwise)
#+end_schema

(ns studio.fields)
(def repo "/home/othman/code/undefine/spacetime/")
(defn read-dir [dir]
  (map (fn [f] (File/read! (str repo dir f)))
       (filter (fn [f] (String/ends_with? f ".st")) (File/ls! (str repo dir)))))

#+begin_src beam-lisp :id view
;; The timeline's view window. Zoom keeps the time under the cursor fixed;
;; fit shows the whole film; positions are fractions of the view, not of the film.
(defn x->ms [v x] (+ (:from v) (* x (:span v))))           ; x in 0..1 of the lane
(defn ms->x [v ms] (/ (- ms (:from v)) (:span v)))
(defn clamp [v total]
  (let [span (min (max (:span v) 50) total)]
    {:from (min (max (:from v) 0) (- total span)) :span span}))
(defn zoom [v x factor total]
  (let [at (x->ms v x) span (/ (:span v) factor)]
    (clamp {:from (- at (* x span)) :span span} total)))
(defn fit [total] {:from 0 :span total})
(def total 24000)
(def v (zoom (fit total) 0.6 6 total))                       ; zoom 6× around 14.4 s
(assert (< (abs (- (x->ms v 0.6) 14400)) 1e-6))              ; the cursor's time didn't move
(assert (= (fit total) (zoom v 0.5 (/ 1 100) total)))        ; zooming out stops at the whole film
(assert (= (ms->x (fit total) 24000) 1))                     ; the end is on screen when fitted
{:view v :keys-14.0-14.2-apart-px (* 1100 (- (ms->x v 14200) (ms->x v 14000)))}
#+end_src

#+begin_src beam-lisp :id route
;; One commit path. A change from any widget becomes ops on words:
;; a driven field edits (or adds) the stop at the playhead, others edit their param.
(defn op-for [field words playhead]
  (cond
    (:driven field)
    (let [stop (first (filter (fn [s] (= (:at s) playhead)) (:stops (:driven field))))]
      (if stop
        {:op :span :address (:address stop) :words words}
        {:op :insert :after (:address (last (filter (fn [s] (< (:at s) playhead)) (:stops (:driven field)))))
         :words (str " -> " words " at " playhead "%")}))
    (= (:state field) :default) {:op :insert :after (:last-param field) :words (str ", " (:label field) ": " words)}
    :else {:op :span :address (:address field) :words words}))
(def posZ {:label "posZ" :state :written :address [0 3300 3302]
           :driven {:stops [{:at 0 :address [0 900 902]} {:at 25 :address [0 906 907]} {:at 62 :address [0 915 919]}]}})
(assert (= :span (:op (op-for posZ "7" 25))))                ; on a stop: rewrite that stop
(assert (= :insert (:op (op-for posZ "7" 58))))              ; between stops: a new stop at 58%
(assert (= [0 906 907] (:after (op-for posZ "7" 58))))       ; after the stop before it
(assert (= :insert (:op (op-for {:label "decay" :state :default :last-param [0 10 20]} "3" 58))))
{:between (op-for posZ "7" 58)}
#+end_src
#+RESULTS: route
: {:between {:op :insert, :after [0 906 907], :words " -> 7 at 58%"}}


#+begin_src beam-lisp :id many
;; A selection is a set. The inspector shows fields every selected part has, with
;; the same type; differing values show as mixed and one edit writes them all.
(defn shared [parts]
  (let [keyed (map (fn [p] (into {} (map (fn [f] [[(:label f) (:type f)] f]) (:fields p)))) parts)
        common (reduce (fn [a m] (filter (fn [k] (contains? m k)) a)) (keys (first keyed)) (rest keyed))]
    (map (fn [k] (let [vals (set (map (fn [m] (:value (get m k))) keyed))]
                   {:label (first k) :type (second k)
                    :value (if (= 1 (count vals)) (first vals) :mixed)
                    :writes (count keyed)}))
         (sort common))))
(defn globe [n e] {:fields [{:label "emissiveIntensity" :type "number" :value e}
                            {:label "posX" :type "number" :value n}
                            {:label "color" :type "color" :value "#fff1d0"}]})
(def lamp {:fields [{:label "intensity" :type "number" :value 0} {:label "color" :type "color" :value "#ffcf8a"}]})
(def g (shared [(globe -2.6 0) (globe 2.6 0) (globe -2.6 1.5) (globe 2.6 0)]))
(assert (= :mixed (:value (first (filter (fn [f] (= "emissiveIntensity" (:label f))) g)))))
(assert (= ["color"] (map :label (shared [(globe 1 0) lamp]))))   ; a globe and a lamp share only colour
{:four-globes g}
#+end_src

* Decisions
#+begin_decision :id d1 :title "Widgets are templates in one shared library" :status proposed
- [x] =@template &w-*($f)= in =stdlib/widgets/=, used by the studio and the admin drawer
- [ ] Separate templates per app (the admin's =&fld-*= and the studio's would drift)
- [ ] JS that builds the inputs (what the kits do today)
- [ ] =@form markup= (it binds =noop=; nothing renders it yet)
A widget takes one descriptor and emits one =change=. It doesn't know about ops,
selection or the timeline, so the same =&w-color= works in the admin's brand pane.
#+end_decision

#+begin_decision :id d2 :title "The scalar table picks the widget" :status proposed
- [x] =%widget &w-color= in =stdlib/scalars/types.st=; the descriptor carries =tpl=; markup calls =&$f.tpl($f)=
- [ ] =@match $f.type= in every inspector (the dispatch list repeats per app)
- [ ] A Rust =widget_for= branch per type (today's admin path for non-scalars)
The table already exists for exactly this (=%widget "color"=, FEAT-168: « adding a
scalar should require no Rust change »). It points at a template instead of a string.
#+end_decision

#+begin_decision :id d3 :title "The compiler projects every field" :status proposed
- [x] =src/studio/fields.rs=: descriptors for part params, CSS declarations, clips, stops and sounds
- [ ] Keep =ST.stuFields= / =ST.stuFilmFields= in JS and add types to them
The compiler has the form's =FormClause= (types, defaults) and the scalar table;
the JS has neither. A keyframe's widget is the type of the param its channel animates.
#+end_decision

#+begin_decision :id d4 :title "Choices are union types in the form" :status proposed
- [x] =type: $type:("ambient"|"directional"|"point"|"spot") = "directional"=
- [ ] Read the =/// @param= prose (a parser for comments; the project rules forbid it)
Unions already parse in =%form= captures (=form-syntax.md:129-146=). Six 3D params move (the =coverage= cell finds them).
#+end_decision

#+begin_decision :id d5 :title "Ranges and units are named scalar types" :status proposed
- [x] New rows in the scalar table: =unit= (0..1), =angle= (exists), =intensity=, =distance=, =exposure=
- [ ] Inline refinements =number(0..1)= (new grammar; can come later if rows multiply)
=penumbra: $penumbra:unit= reads better than a bare =number= and needs no new syntax.
#+end_decision

#+begin_decision :id d7 :title "One selection, a set of addresses" :status proposed
- [x] =@type Selection=; page elements, parts, clips, stops and sounds; shift adds, a box adds many
- [ ] Two selections (=$stuSel= object, =$stuFilmSel= key) as today
This fixes « Nothing selected » and the unmarked keyframe at the root, and is what multi-edit needs.
#+end_decision

#+begin_decision :id d8 :title "One commit path" :status proposed
- [x] Every widget emits =change {address, words}=; one handler makes ops; driven fields write the stop at the playhead
- [ ] A commit function per field kind (=stuCommitField=, =stuCommitDecl=, =stuFilmCommit= today)
The =route= cell above is that handler's rule.
#+end_decision

#+begin_decision :id d9 :title "Navigation is generic behaviors" :status proposed

- [ ] Zoom code inside film-kit (it would stay timeline-only)
