Full-arc redesign of Spacetime's test + automation infrastructure. Supersedes the
BUG-053/FEAT-054/FEAT-055 framing (those become W0 here). One engine, tiered
fidelity, CDP substrate (chromiumoxide as a Cargo dep — NOT a vendored .st), a

* North star
A Spacetime program describes behavior. A RUNTIME executes it against a WORLD.
Testing, scripting, and automation differ only in (a) which world and (b) what
you assert. ⇒ ONE vocabulary (@mount/@when/@then/@observe/@wait), many worlds.

* Backends (settled)
- V8 (rustyscript) STAYS — required by %emit build-js (i18n/locale,
  stdlib/primitives/i18n.st:42; called at expand.rs:239). It is the pure/logic rung.
- LinkeDOM = the DOM provider for V8 (logic rung). Not a runner.
- chromiumoxide (pure-Rust CDP) ADDED to Cargo (NOT vendored — it is part of the
  compiler crate's deps). Provides layout/timing/paint rungs + automation.
- Playwright npm-driver crate REMOVED (replaced by chromiumoxide).
- kernel.sh = same CDP endpoint, remote: @drive … via kernel <wsUrl>. Reuses
  kernel-images (warm snapshot/restore Chromium), neko (live view), profiles, replays.

* THE FIDELITY LADDER (anti-rot keystone)
| rung   | world                     | tests                              | backend         |
| pure   | no DOM, no time           | stagger math, take, fold           | V8              |
| logic  | LinkeDOM + fake rAF       | reactivity, signals, event wiring  | V8 + LinkeDOM   |
| layout | real CSSOM, getComputedStyle | @balance, pretext reflow, visible | CDP             |
| timing | real rAF / seekable clock | reveal stagger, easing, transitions | CDP             |
| paint  | pixels                    | visual regression                  | CDP + screenshot|
build-js = pure/logic rung at BUILD time (same V8 embed, different caller).
RULE: an assertion's vocabulary infers its MINIMUM rung; @test … needs <rung>
can only RAISE it. A layout assertion on the logic backend is a COMPILE ERROR,
never a silent pass. This permanently kills the BUG-051/053 false-green class.
