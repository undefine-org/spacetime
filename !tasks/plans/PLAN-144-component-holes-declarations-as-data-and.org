* W1 — a component hole expands; a call in markup refuses (BUG-344)

** Gates FIRST, RED-checked before any fix
- `` `&t("x")` `` in markup EXPANDS the component (behavior, not string).
- `<main>&t("x")</main>` REFUSES, diagnostic in `@each`'s shape: name the
  invocation, state that a directive binds through a selector, show the
  selector-block spelling.
- `&t("x")` at file scope refuses the same way.
- `&no-such("x")` in markup refuses (unknown name, currently silent).
- Bare `&name` with NO parens is untouched: a `_schools.st`-style score subject
  still compiles and still scores. This is the regression that would break the
  motion hero.
- `.slot { &t("x"); }` keeps working (control).

** Implementation
- Teach the hole consumer to expand an `ELEMENT_REF` carrying a call shape.
- Route markup/file-scope `&ident(` to the existing E0402-family refusal.
- Scope strictly to `&ident(`; never to bare `&name`.

** Acceptance
- All four silent spellings are either CORRECT (hole) or REFUSED (markup, file
  scope, unknown) — no spelling both builds green and renders nothing.
- `demos/showcase-gallery` still renders 10/10 (it uses the selector form).
- Full `.st` suite no worse than baseline.

* W2 — declarations as data (BUG-343)

** Gates FIRST
- `@data declarations $p from template ;` yields the 10 showcase templates with
  name / params / doc / source / origin.
- `$p.fields.school` etc. are populated from the `/// key: value` block; all 11
  patterns yield a non-empty `school` (guards the silent-typo risk: a misspelt

  `entity form`, so the brand catalog's 46 rows and 12/34 origin split must be

- An unknown entity name refuses rather than returning an empty list (silent
  empty is the banned class).

** Implementation

  one; audit each of the 8 sites — some legitimately mean "form" and must KEEP
  meaning form. Do not blanket-replace.
- `@data forms` desugars to the general surface.
- Parse `/// key: value` lines into `fields`; leave the full blob in `doc`.
