* Design
The studio is a PROJECTION of the score; every gesture is one source edit (SIP-001b §2).
- F1 seekable transport (a score is a position: pause holds, seek moves, play resumes; =ST._transports[name]=)
- F2 spans for every capture (metasystem; no Rust score reader)
- F3 =GET /__spacetime/studio/score.json= — entries, clip scopes/channels/stops, sounds, instruments, patterns,
  stage parts with typed params, the synth program
- F4 span-guarded =span= / =insert= ops on PLAN-154's =apply=
- F5 hot rescore without reload (keyframes, windows, synth); structural edits reload with the playhead restored
- F6 primitives: =@code-editor=, =@waveform=, =@scrub=, =@timeline-lane=
- UI =stdlib/__studio__/film.st=: viewer, transport bar, timeline (clips, keyframes, sound lanes, step grid),
  inspector, code pane, render button

** DONE P4b instant edits — the page takes an edit in place (asked: "fix everything in the compiler especially instant edits")
- *Compiler — hot binds.* A primitive that declares a =bind= param is handed a STABLE KEY after Resolve
  (=pipeline::assign_hot_keys=: primitive, selector, ordinal). =pipeline::hot_binds= runs the layers of
  =compile_verbose= up to Resolve and returns each keyed call's arguments AS ITS BODY IS GIVEN THEM — through
  codegen's own typed =%param= resolution (=metasystem_codegen::param_values_js=) — plus a FINGERPRINT of every
  other call, the markup, the raw CSS and every rule's declarations (spans left out). =Compiler::hot_only()=;
  =GET /__spacetime/studio/hot.json= (~100–200 ms on Robot Day, release).
- *Runtime.* =ST.hot(key, take)=, =ST.hotApply(binds)= (false on a key set that differs or a call that refuses),
  =ST.patchInPlace=. Hot: =apply-animations= (its keyframe table patched in place), =score-window= (the window map's
  numbers), =score-synth= (a new program re-rendered), =three-object= / =three-light= / =three-gltf= (rest pose,
  material, light numbers; a new shape/kind/file refuses), the stage's =touch=. The time-driver's =refresh= shows
  the current frame again with the new arguments.
- *Studio.* Before the first write it reads the page's baseline; after an edit it asks for =hot.json=: same
  fingerprint and every call takes its arguments → no reload (the panels re-read the source); else reload as
  before. Measured in the page (release): the frame changes ~480 ms after the gesture (apply 65 ms, hot.json
  180 ms, swap 2 ms); slower (~2.4 s) while the dev server is also recompiling the page for the inspector.
