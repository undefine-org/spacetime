* Context

The current =projects/unkn/= home page does not follow =projects/unkn/_references/unkn-home.html= (Figma export) nor the motion-design manifesto at =projects/unkn/_references/Spacetime Movement effect - UNKN website.md=. Critical deviations:
1. Section ordering wrong: scrolling strip is misplaced (between statement and identity instead of directly under hero); =unkn-portraits= text-rectangles invented; =unkn-eyes= and =unkn-talent-grid= conflate.
2. *Three signature motions are completely missing*: scrolling-strip hover-pause + category reveal; hero scroll-driven red wipe with typography cross-fade; roster vertical slide-reveal pair with name unmask.
3. Real photography unused: =projects/unkn/assets/images/= is empty while =_references/Home_Images/= and =_references/images/= contain the full visual vocabulary (named talents Carolina Mendes, Rafaella Maia, Gabbi, Sofi Adams + 14 stock portraits + Figma-exported strip thumbnails + brand logos + work hero + close-up eyes).
4. Brand color is wrong: =--unkn-accent= = =#D43E2B= rust; reference is =#FF0020= scarlet.
5. Typography ceilings too low: h2 clamps to 44.8px desktop, PDF spec is 70px.
6. No =projects/unkn/AGENTS.md= recording brand spec.
7. =modules/_mission.st= mashes 4 sections in one 331-line file; =&unkn-section-portraits()= is invented.

User-confirmed decisions (from `ask` round before drafting):
- *Talent dataset*: real names (4) + Talent #5..9 numbered placeholders for unnamed Pexels stock; structured for future replacement.
- *Scope*: home + light pass on sub-routes (apply theme/typography/footer-copy fixes; no new motion).
- *Hero wipe typography*: cross-fade ink → cream/white between 30% and 85% scroll progress.
- *Roster pair direction*: vertical (image on top, slides DOWN into name slot below).
- *Responsive breakpoints*: Mobile ≤720 / Tablet 721–1100 / Desktop ≥1101.

Pre-decided defaults (recorded for transparency):
- Marquee implementation: pure CSS =@keyframes= + =animation-play-state: paused= on =:hover= (no project-local =%primitive=; native CSS handles pause-resume-at-position seamlessly and degrades naturally with =prefers-reduced-motion=).
- Hero wipe implementation: stdlib =@scroll= macro + =transform: scaleY()= for performance (avoids layout thrash); =@property --unkn-hero-fg { syntax: '<color>' }= for consistent typography color interpolation across browsers.
- Roster pair implementation: pure CSS =:hover= + =transition= + =transform: translateY()= (no Spacetime macro needed; =:focus-visible= for keyboard parity).
- Module split: 4 single-responsibility modules replace =_mission.st=: =_statement.st=, =_identity.st=, =_mission.st= (mission + inline stats), =_resonance.st=.
- Strip data shape: =data/strip.json= 14-row =StripRow { talentId, category }= so =@each= can iterate twice without stretching =@each='s expressiveness.
- 14 strip cells × 2 copies = 28 cells total for seamless =translateX(-50%)= loop.
- Selective rebuild: keep theme tokens, fonts, globals, nav scaffold, footer scaffold, cursor pattern, reduced-motion pattern, route placeholder, =@type=/=@data= architecture; replace sections + add 4 new modules + extend talent data.
