═══════════════════════════════════════════════════════════════
THE CORE INSIGHT
═══════════════════════════════════════════════════════════════
Webflow's layer tree can only show what HTML/CSS expresses: a static box tree. Its @each
equivalent (CMS collection) is ONE opaque "Collection List" node, because HTML has no concept of
"a repeated region bound to data." Spacetime's CST DOES. So we don't walk the DOM like Webflow —
we walk the CST, which is strictly RICHER than the DOM, and render node kinds the DOM can't name.
That is the differentiator: the navigator shows the GENERATIVE RULE (@each source+loopvar+body,
@match all-arms), which is more informative than a flattened runtime list.

Two divergent introspection stacks:

  Stack 1 — MCP bundle path (src/mcp/):
    compile_to_bundle → TemplateBundle{ scope, html, refs, states, spans }
    → stage_structure_from_bundle (live.rs:636) walks bundle.refs (TEMPLATE_REF only)
    → workbench navigator. RESULT: a whole <section><h1><p><button> hero = 1 node ("main").
    (Known limitation: FUP-061 "templates-only v1".)

  Stack 2 — dev-ws host (src/sync/):
    ClientMessage::InspectElement → handle_inspect_element (handlers.rs:1367) re-parses .st from
    disk, returns ElementContext{ CSS property sections, data bindings, state machine },
    CSS-SELECTOR-shaped (a rendered-DOM mental model — the Webflow limitation we want to transcend).
    AND THE DISPATCH IS DEAD: handlers.rs:1591 → Reject("InspectElement not yet implemented").
    170-line handler written, wire cut. It rotted precisely because it was parallel + unowned.

  Write rail (already ahead of the read rail):
    ClientMessage::EditAst{ file, selector, patch, op_id } — patches a .st node BY AD-HOC SELECTOR
    STRING (".hero @scroll"), not by stable node id. Works, but lacks the addressing a read IR
    should mint. The MCP path has its own write rails too (mcp_param frame override — VERIFIED
    working live; mcp_node_param node-level — dead for the common case, see B4).

The CST vocabulary is ALL there (src/syntax/cst/mod.rs, proven by reconstruct_template_body_html):
    HTML_ELEMENT, HTML_HOLE (`$title` binding in markup), VARIABLE_REF, DIRECTIVE (@each/@match/@on),
    SCOPE_BLOCK, TEMPLATE_REF (&card), TERNARY_EXPR — each with byte ranges. The scope object
    (bundle.rs collect_template_bundles) carries scope.html + scope.refs + spans at bundle time.

TARGET ARCHITECTURE
═══════════════════════════════════════════════════════════════
ONE shared producer:  structure_ir(scope/CST) → StructureNode tree
    StructureNode {
      id: stable path id ("0.1.2" — position, survives re-walk),
      kind: element | hole | each | match | arm | template | ternary,
      label: "section.hero" | "@each $items" | "loading →",
      source_span: (start,end),        // the WRITE address — the EditAst hook
      bindings: [$title, $subtitle],   // holes/params this node reads (reactive edges)
      data_source: $items,             // for each/match: the driving signal
      children: [...],                 // walked (templates recursively, cycle-guarded)
    }
  Lives in a shared module (e.g. src/introspect/), NOT in src/mcp/. MCP is just the first consumer.

Consumers (both hosts, zero divergence):
  - MCP workbench: stage_structure_from_bundle → calls structure_ir(); navigator + inspector + B3.
  - dev-ws host:   WIRE the dead InspectElement dispatch → structure_ir() (retire the CSS-section
                   scanner); ADD InspectStructure{file,template} → Structure{nodes} whole-tree query
                   (protocol lacks a whole-tree read today).

One address space: EditAst re-keyed from selector-strings to IR node id + source_span, so
INSPECT (read) + SELECT (B3) + EDIT (write) all speak the same ids. The AST node you inspect IS
the node you edit. This is paper.design's "design↔code and back," richer because the IR carries
generative + reactive nodes.

Beat-Webflow capability table:
  | capability            | Webflow layer tree      | Spacetime Structure IR                     |
  | static elements       | ✓                       | ✓                                          |
  | repeated region       | opaque "Collection List"| @each node: source signal + loop var + rule|
  | conditional           | ✗ (runtime only)        | @match/ternary node: ALL arms visible      |
  | binding on an element | ✗                       | hole chip: ←$title on the node             |
  | composed component    | "Symbol" (flat)         | template node you walk INTO (recursive)    |
  | reactive behavior     | ✗                       | @on/scope-block node attached to element   |
