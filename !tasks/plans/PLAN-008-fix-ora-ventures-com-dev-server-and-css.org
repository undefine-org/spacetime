* Context
=cargo run -- serve ora-ventures.com/= shows a blank "Not found" page because the dev server's locale routing is broken.

** Root Cause
The dev server's =index_handler= (=src/server.rs:1103=) detects locale JSON files in =locales/= and redirects =/= → =/en/=. Then =try_serve_locale= (=src/server.rs:558=) tries to serve the locale-prefixed page using build scripts, but =@locale= doesn't generate any =build_js_stmts=, so =compiled.build_scripts= is empty. The function returns =None=, the fallback handler looks for a physical =en/index.html= file, finds nothing, and returns 404.

The landing page at =/landing/= works because it bypasses =index_handler= (root-only redirect) and gets compiled inline with runtime locale switching.

** Approach
1. Fix the engine: make =try_serve_locale= fall back to inline compilation when build scripts are empty, matching the landing page's behavior
2. Fix two CSS authoring errors in the site
3. Fix noisy "Unknown param 'self'" compiler errors

** Key Decisions
- Engine fix goes in =src/server.rs=, specifically =try_serve_locale= — add a fallback path that compiles and serves the page directly when no build scripts exist
- CSS fixes are simple edits to =ora-ventures.com/modules/_hero.st= and =_overrides.st=
- The "self" param error fix goes in =src/emit/css.rs=

*** Deviations
1. Root cause refinement: The plan identified =build_scripts= being empty as the primary cause of the 404. Investigation revealed the CSS authoring errors (colon typo in =_hero.st=, malformed nesting in =_overrides.st=) were actually causing =compile_from_site= to fail, which returned =None= before the =build_scripts= check was reached. Both fixes were applied: CSS errors corrected and fallback path added for defensive robustness.
2. Pre-existing V8 thread degradation: The locale build-script path spawns a new OS thread with a fresh V8 isolate per request. After ~5-6 requests, the V8 runtime starts failing silently, causing subsequent locale routes to 404. This is a pre-existing issue unrelated to the fixes in this plan and was not addressed (separate scope).
