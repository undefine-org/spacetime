* Context
** Goal
Make it easy to make websites with Spacetime: introduce a single =projects/= directory at the repo root that holds the user's private websites in their own git repository. Build outputs always go to =projects/<name>/dist= and are gitignored everywhere. The product experience and instructions match this convention end-to-end.

** Initial request (verbatim)
"I want you to make it very easy to make websites with spacetime. this means you reorganise the various websites into a projects/ folder that is gitignored, and you move all the websites inside it. i'll move the demo ones back at some point. initialise a new git repository there to keep track of our private websites. on top of that, the projects/ folder has a .gitignore of **/dist which is where the built website is put. make sure the experience of the product and the instructions on how to use it match this"
