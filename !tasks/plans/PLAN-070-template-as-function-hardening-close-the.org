* Goal
Make =@template &name(params) { body }= the blessed encapsulation mechanism:
a template body carries ALL of Spacetime (HTML, holes, state, events,
animations, responsive CSS) with instance-first scope, and a static
invocation is SEO-real (served HTML). Evidence base:
research/spacetime-template-as-function-analysis.org — architecture already
~90% there (stdlib-grammar component_item, instance scope, factory emit);
the remaining 10% is 3 bugs + 1 feature, all filed with root causes.

* Non-goals
- Scoped CSS (FUP-062 owns it; BEM discipline is the interim convention).
- Transitive staticity for derive/query sources (named follow-up in
  docs/language/data-and-rendering.md §6).
- Any Rust fallback parser for stdlib constructs (AGENTS.md discipline).
