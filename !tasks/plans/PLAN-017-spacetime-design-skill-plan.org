* Context

** Origin
Inspired by =alchaincyf/huashu-design= ([[https://github.com/alchaincyf/huashu-design]]). Distilled lessons:
- SKILL.md as enforced procedure with hard rules + decision branches, not API reference.
- Brand-asset protocol: never invent design tokens; extract from authoritative sources.
- Fallback advisor: when ambiguous, generate 3 differentiated variants in parallel; user picks.
- Junior-designer workflow: assumptions + placeholders → show early → iterate.
- N-dimension expert review with score + Keep/Fix/Quick-Wins.
- Showcases: curated, prebuilt patterns indexed for lazy lookup.
- Anti-AI-slop rules made explicit.
- Verification (Playwright) baked in before delivery.

** Spacetime translation
- Brand-asset → project-style protocol (read AGENTS.md, grep CSS vars, freeze tokens.st; never invent brand colors).
- Generic AI slop → custom JS / inline handlers / hardcoded data (already partly in =docs/antipatterns.md=).
- Showcases → new =stdlib/showcases/= tree (8 scenarios × 3 styles = 24 files).
- 5-dim review → =Spacetime.review()=: idiomatic, animation, brand, a11y, compile.
- Junior designer → compile-with-placeholders → =cargo run -- serve= → iterate until =doctor= passes.
- Verification → =cargo run -- doctor= as one-call gate.

3. Showcases live in dedicated =stdlib/showcases/= tree.
4. Snapshot/diff regression baseline is *deferred* (out of scope here; possible future FUP).

*** Deviations

1. *Bypassed compiler.rs runtime entry point*: the plan called for emitting =Spacetime.review= near "compiler.rs:1844 after forcePlay", but =Spacetime.diagnose / forcePlay / inspectTimeline / inspectElement= live in =public/runtime/debug.js= as =ST.debug.*=, NOT in =compiler.rs=. Bypass rationale: the dev-review primitive sets =window.Spacetime.review= directly inside its emit JS. This achieves the same dev-only semantics (production never loads the dev runtime, so =Spacetime.review= is never defined in shipped builds) without touching the compiler crate. Tests T1/T2 (compiler.rs entry point assertions) were not authored due to this deviation.

2. *Brand-audit regex hit a parser/expander quirk*: the original walker used =:root\s*\{[^}]*\}= regex literals which broke the metasystem expander silently (parsed OK, but emitted empty body). Resolved by replacing the brace-bearing regex with line-based filtering of custom-property declarations. Bisection trail logged via =cargo run -- inspect --layer ir=.
