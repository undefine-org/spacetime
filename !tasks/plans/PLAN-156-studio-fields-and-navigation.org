* Design v2 (proposed; dossier decisions D17-D22, D1, D7, D9, D10)
- Two generic dev-server facilities: *reflect* (one typed projection with spans, docs, facts) and *rewrite*
  (one guarded writer with re-parse and undo), shared by the studio, admin, LSP, MCP and migrations.
  =src/studio/= is deleted; domain knowledge moves to the stdlib (=%role=, a =stop= capture type).
- Language: docs on declarations (=///= on params, =%yield=, tags), compiled =%example=, params declared
  once (=...= forwarding), choices as sum types written bare, units/ranges as scalar rows, =vec3=
  shorthand + longhands, file facts (=clip($src)=), lossless spans for =@data= and markup.
- Migrations gain =%scope stdlib= to rewrite meta-syntax; five waves (counts in the dossier's cells).
- Evidence: 249 params declared twice, 11 disagree; 1,319 JSDoc-style tag lines; light.st's own
  =@example= (=@light ambient(...)=) builds a =directional= light with no warning.

* Found on the way (compiling every stdlib example)
Real bugs the compiled examples exposed; not fixed in this plan. Each one's example stays in the
=examples::tests= known-broken list, with its reason, until it is fixed.
- =@cleanup= (stdlib/testing/test.st), =@fn= and =@compute= (stdlib/macros/type-data.st): a ={ $x:expr }= body capture
  keeps the opening ={= and drops the closing one (=push(() => { { … });=, E0952).
- =@test-behavior= (test.st): every transition syntax compiles the enclosing =@test= to nothing, without a diagnostic.
- =@given-data= (test.st): =@given $x = …= always loses to the selector form of =@given= (E0946).
- =@for-range=, =@repeat=, =@conditional= (stdlib/macros/each.st): no =%binds=/=%emit= (E0956; =@conditional= is
  BUG-362).
- =@fade-in-stagger= (stdlib/macros/fade-in.st): its =$_childSelector:selector= body capture never receives tokens.
- =@template-inline= (stdlib/macros/template.st): =&name(…) { … }= at file level is E0925 (body scope not built).
- stdlib/macros/websocket.st names capture types that are never declared (=message_handlers=, =statements=,
  =channel_messages=, =type_fields=, =object=).
- =@localStorage= (stdlib/macros/bindings.st): =$cart string[]: localStorage("k", [])= compiles to the string
  ="localStorage"=; the macro never applies.
- A comma inside an array literal in a declaration fails to parse (=.p { $items number[]: [1, 2]; }=).
- =@light { … }= (responsive light-mode) is taken by the 3D =@light= (E0804); pre-existing: the last commit fails
  =integration::responsive_nested_directives::light_with_nested_loop_emits_guarded_js= too.
- =@each(…, key: …)= with =:entering=/=:exiting= is E0946 (either alone works).
- =@on-mutation= compiles to a "missing required element" error at runtime.
- =@enable_signal_tracking= uses =__ctx.cleanup= before it exists; =@enable_state_tracking= patches a function nothing
  defines.
