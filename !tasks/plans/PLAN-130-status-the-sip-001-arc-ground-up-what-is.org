** The pattern, restated with more evidence

Every defect this wave was a SILENT ACCEPTANCE, and BUG-258 was FOUR of them
stacked: a counter-derived name where an element name was needed, a projection
refused on the element host, a bare `ST.watch` that could not see an ancestor's

The discriminator held again without exception. What caught them: asserting a
NEGATIVE (this element must be STILL), evaluating a VALUE (sample the map in
node), and running the thing in a real browser. What missed them: every gate
asserting that something was produced.

Two lessons worth carrying:

1. MY OWN GATE WAS WRONG and looked exactly like a compiler defect. It scored
   `&early` while the consumer element was `.clip-early`, so it asserted a
   mismatch of its own making. Only building a minimal probe whose subject and
   class agreed, watching it pass, and diffing the two told them apart. A gate
   that fails for its own reasons is indistinguishable from a real bug until
   you check.

   guard matched empty and valid bodies too, displacing the real macro. That is
   a property of the body-form matcher, and it means the "guard every optional
