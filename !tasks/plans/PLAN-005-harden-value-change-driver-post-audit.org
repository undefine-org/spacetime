*Fix 6 (literal emoji) reverted.* The Spacetime parser panics on literal multi-byte UTF-8 characters: =expand.rs:747= performs byte-index slicing that hits a non-char-boundary inside the 4-byte 👋 (U+1F44B) sequence. The original escaped surrogates (=\\ud83d\\udc4b\\ud83c\\udf0d=) are correct for this context — they are ASCII text inside a JS =eval()= string that JavaScript interprets at runtime.
