* Why

Driving `demos/brand-catalog` in a real browser turned up two silent-drop
defects that between them explain the largest failure bucket in the suite AND
block the "switch schools easily" story:

- BUG-322 — an unnamed driver arg binds BY INDEX into the primitive signature,
  so `@on &.visible(800ms)` sets `threshold: 800`. Root cause of 8 of the 27
  headless failures ("Timeline <name> not registered").
- BUG-327 — a `@form style` whose body splices another form emits NOTHING,
  silently, and `check` says ✓. Blocks role-indirection, which is the clean
  way to make design schools swappable.

Measured baseline at clean HEAD `06e0bfa5`: 636 passed / 27 failed / 73 skipped.

* Waves

** W1 — BUG-322: an unnamed driver arg must reach the param the author meant

Registry-declared positional slot (option B in BUG-322): each
`%registers driver(...)` entry names the param an unnamed arg fills, as DATA,
the same shape as `param_map` / `progress_export`. No Rust match-arm per
driver.

TDD: `.test.st` behavior gate FIRST, seen RED under `--cdp`.
Acceptance: `@on &.time(300ms)` animates over 300ms; `@on &.visible(300ms)`
does not set a nonsense threshold; the 8 "Timeline not registered" failures
recover; the 3 tests my BUG-323 guard moved from silent-wrong to loud-fail go
green.

** W2 — BUG-327 + schools as ROLES

Fix nested form splice (a form body may splice a form), then express the
showcase schools as role bindings so a pattern never names a school:

#+begin_src spacetime
.hero__title { --role-title; }                  // pattern splices a ROLE
@form style --role-title { --sc-min-title; }    // school binds it
#+end_src

Switching school becomes one block of rebindings instead of editing every
splice in every pattern.

TDD: RED gate for the nested splice (repro in BUG-327), plus a cycle gate
(`--a { --b; }` / `--b { --a; }` must be a loud diagnostic, never a hang or a
silent empty rule).
