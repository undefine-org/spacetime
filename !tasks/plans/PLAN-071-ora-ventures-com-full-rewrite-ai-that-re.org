** Architecture note (IMPORTANT for future edits)
This project uses a PAIRED index.html + index.st convention (NOT the
"full-Spacetime" no-html convention some stdlib showcases use): index.html
carries the MARKUP + <head> meta/title (E0602 selector-scope validation
checks against it), index.st carries CSS/data/templates/behavior ONLY.
Edit markup in index.html; edit behavior/data/style in index.st. A stray
duplicate <main> block in index.st (from an early draft this session) was
found to cause a confusing cascade of E0602 "selector does not match"
errors when it drifted from index.html \u2014 removed, with a NOTE comment
left in index.st warning against reintroducing it.
