** 1. Composed-subtemplate element stamping (B3.2 extension)
Today only the ENTRY template (main) stamps data-st-node under base "0". A composed &child(…) sub-template's elements are NOT stamped, because each invocation needs a per-call-site base id threaded at RUNTIME (two &card(…) calls must stamp distinct child ids). Oracle path: add an invocation-base channel — region mount passes base "0"; each TemplateRef carries its bundle_walk id; nested factory calls receive {__stInternal:{nodeBase:"0.1"}} (buildTemplateFactory STRIPS it before param binding); emit_builder appends relative suffixes. Until then, composed sub-template elements select at template-node granularity.

** 2. Generative @each/@match iterator-node labelling (B2b extension)
structure_from_bundle shows an @each-driven child as a plain `template` node. To show the GENERATIVE RULE (source signal + loop var + body-once for @each; all arms for @match), the bundle must carry each-scope metadata (nested-scope ScopeKind::Construct("each")/("match") + driving signal). The IR NodeKind already reserves Each/Match/Arm; the walk needs the bundle to expose the generative scopes.

** 3. Static-literal-text editing (B4b)
B4a edits element HOLES (bound to params) via mcp_param. A static <h1>Hello</h1> (no hole) has no upstream source — editing = patching the literal in source. Oracle path: a SEPARATE mcp_node_text action + a body-splice helper that reparses source, locates the element by node_id via html_ids, replaces its direct literal text, splices body_html back, update_source. Expose literal-text inputs ONLY for simple elements with direct literal + no holes. Mirrors handle_content_edit_st; no HtmlExpr spans needed.

** 4. Param-default source persistence
Editing a binding via mcp_param sets a runtime region OVERRIDE, not source. To PERSIST a new default ($title = "Hi" -> "New"), a param-default patcher is needed. Blocked: ParamSpec/TemplateParamDef carry `default` TEXT but NO byte span. Needs a param-list default resolver over the template FormMatch.span + a $name type? = expr replacement/insertion patcher. Tests: quoted strings, no-existing-default, typed/optional/multiple params.

** 5. EditAst revision + stale-span hardening
mcp_node_param uses raw __invoke_span:[start,end]; stale after any source edit. Oracle hardening: send {node_id, revision, span_start, span_end}; server rejects stale/mismatched span (revision + span validation). Keeps span as write address; safety without a full id-rekey.
