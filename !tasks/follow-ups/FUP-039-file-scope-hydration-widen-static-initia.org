FEAT-078 (file-scope HTML reactivity). Two documented later steps, deferred (not blocking; the
core reactive hydration is done + V8-verified).

* 1. Widen the static-initial evaluator
html_hydrate::static_initial only resolves a BARE `$x` to its declared initial. A compound
expr (`$a + $b`, `$x.y`, filtered `$total | currency`) renders EMPTY statically and is filled by
the on-load render (so no-JS shows nothing for those). Widen the compile-time evaluator to
resolve simple compound exprs over known global initials (the ssg_unroll static-array evaluation
is precedent). Document the boundary (what stays hydrate-on-load).

* 2. SSG export path
compiled.html (file-scope markup + hydration markers) is injected only in the DEV SERVER
(synthesize_st_only_shell). The static EXPORT (src/export/emit.rs) reads AUTHORED .html files
from disk and does not inject compiled.html. So `cargo build` of a pure-.st page that relies on
file-scope markup needs the export pipeline to emit compiled.html into the route's index.html
(or synthesize a shell like the dev server). Until then, file-scope reactive markup is
dev-server-correct but not statically exported. Decide: inject compiled.html in process_html, or
synthesize a shell for st-only routes.
