* The gap (verified 2026-06-20)
apply_text_patch (src/sync/handlers.rs:626) patches a param by FINDING "key:" in
the directive's source span and replacing its value. If the param is DEFAULTED but
ABSENT from the source call (e.g. @object(roughness: 0.15) with no metalness:),
the find FAILS and the edit is REJECTED ("Property 'metalness' not found in
directive body"). So a designer cannot set a param the author left to its default.

* The fix
Teach apply_text_patch (or a sibling insert path) an INSERT mode keyed by the
macro's %form param list:
- when "key:" is not found AND key is a valid %form param for this directive,
  INSERT "key: value" into the arg list (paren-arg-list or directive body) at a
  deterministic position (e.g. end of the named-arg list, before the closing ')').
- preserve formatting (leading space/comma) consistent with existing args.
- reject only if key is NOT a valid param (correct-by-design: the %form is the
  allowlist).

* Acceptance
- @object(roughness: 0.15) + patch {metalness: 0.8} INSERTS metalness into the
  call; .st updates; hot-reload renders the new value.
- An invalid key is still rejected.
- Existing replace-in-place behavior unchanged (regression-safe).
- Tests: handler unit (insert into paren-arg-list; insert into directive body;
  invalid key rejected); a live builder gate setting a defaulted param.
