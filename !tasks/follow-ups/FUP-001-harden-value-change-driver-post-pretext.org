** Fix 7: Validate pretext height against DOM after cleanup [accuracy]

~ST.text.layout()~ computes height via canvas arithmetic. This may differ from
actual DOM height due to line-height rounding, border-box, or padding. The
discrepancy only affects the animation transition (final state is always correct
because height is cleared to auto), but a large delta causes a visible snap.

*** Change
After Phase 5 cleanup sets ~%&el.textContent = newText~ (line 940), read the
actual DOM height and log a warning if it differs from pretext's prediction by
more than 2px. This is diagnostic-only for now — a future fix could use the DOM
height instead. Add:
#+begin_src javascript
// Diagnostic: warn if pretext height prediction diverged from DOM truth
if (typeof console !== 'undefined' && console.warn) {
  var actualH = %&el.offsetHeight;
  if (Math.abs(actualH - targetHeight) > 2) {
    console.warn('[value-change] height prediction off by ' + Math.abs(actualH - targetHeight) + 'px (pretext: ' + targetHeight + ', DOM: ' + actualH + ')');
  }
}
#+end_src

Note: this is placed AFTER ~textContent = newText~ and BEFORE ~style.height = ''~
so the DOM is in its final state.

Actually, looking at this more carefully: line 939 sets ~style.height = targetHeight + 'px'~,
then line 940 sets ~textContent = newText~, then line 942 clears ~style.height = ''~.
The diagnostic read should be between lines 940 and 942 (after text is set, before
height is cleared) — but at that point style.height is still explicitly set to
targetHeight. So we need to temporarily clear it, read, then re-clear. Simpler: just
do the read after line 942 clears everything:

#+begin_src javascript
%&el.style.height = '';
%&el.style.overflow = '';
%&el.style.clipPath = '';
// Diagnostic: log pretext height divergence for debugging
if (ST.debug && typeof console !== 'undefined') {
  var actualH = %&el.offsetHeight;
  if (Math.abs(actualH - targetHeight) > 2) {
    console.warn('[value-change] height delta: ' + (actualH - targetHeight) + 'px');
  }
}
#+end_src

Gate behind ~ST.debug~ so it's zero-cost in production.
