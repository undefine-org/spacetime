* Context

PLAN-133 Move 2 (prelude-js owns shared JS) raised the question: what happens
when a helper is needed by TWO DIFFERENT primitives? Prelude dedup is per
primitive name, so cross-primitive sharing has no rail. User ruling
(2026-08-04): solve it with `%uses` — prelude dependencies as registry data —
and file this roster of the genuine application sites + a safe cutover plan.

* Mechanism landscape (what already exists, 2026-08-04 survey)

- Macro→primitive sharing WORKS TODAY via expansion composition: a macro body
  calls the module primitive — `stdlib/dnd/macros/drag.st:52` and
  `drop-zone.st:34` both invoke `dnd-runtime() -> { }`; the callee's prelude
  emits once per page (dedup by name). `stdlib/dnd/runtime.st` (window.__stDnd)
  and `stdlib/3d/primitives/three-pose.st` (window.__stPose, "ONE tested
  implementation instead of N copies") are the exemplars: yield-less
  namespace-installing primitives.
- Primitive→primitive sharing DOES NOT EXIST: a primitive's body is `%emit js`
  (a leaf), not an expansion — it cannot invoke another primitive. `%uses` is
  precisely this edge. It is NOT a second module system; it gives primitives
  the composition macros already have.

* Cutover protocol (per module, in roster order: R3 → R2 → R4 → R1 → R5)

1. Behavior gates FIRST, in a PRIOR commit if missing. Already existing:
   data: 24 integration tests + 8 v8 data_source tests + 3 v8 derived-signal
   tests (BUG-273) + BUG-274 error-path gate. Locale/dev-editable have thinner
   coverage — R3's first step is a v8 test asserting __stResolveLocale's full
   fallback chain BEFORE any migration.
2. ONE module per commit: create the module primitive, add `%uses` to every
   consumer, DELETE every inline copy in the same commit. No transitional dual
   state (cutover, not parallel impls).
3. Deletion-completeness check in the commit: grep the old inline shape →
   zero hits outside the module (e.g. `__st_locale ||` → only i18n.st writer
   + the module).
4. Semantics travel with the code: load-bearing comments (the source.st:133
   microtask-race warning, the __stLocale fallback order) move INTO the module
   verbatim. Byte-compatible behavior — this is a move, not a rewrite.
5. Bundle-shape assertion (complement, not substitute, for behavior gates):
   compiled fixture using two consumers contains exactly ONE copy of the
   shared helper, before both usage fragments (topo order).
6. Revert unit = one commit (no state, no schema).
