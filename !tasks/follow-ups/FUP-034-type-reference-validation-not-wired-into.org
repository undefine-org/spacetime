* Root cause (pre-existing, not introduced by id(T))
=TypeRegistry= has TWO constructors:
- =from_types()= (src/type_system.rs:81) runs =validate_type_references()= +
  =check_circular_dependency()= (the strict path).
- =from_form_matches()= (src/type_system.rs:49) — used by the server/check path —
  registers types but NEVER calls validation. So NO reference is validated on the
  normal compile path, for id(T) OR for plain references.
The id(T) validation arm (validate_type_expr, Apply{ctor:"id"} => validate target)
is correct and WILL fire under from_types; it just isn't reached on the check path.
