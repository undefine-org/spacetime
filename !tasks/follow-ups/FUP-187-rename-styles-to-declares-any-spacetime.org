* The rename

`%styles` is a `properties`-typed PARAMETER, interpolated as `%styles` inside a
primitive's `%emit css`. The name says "CSS properties go here", which
under-describes what the slot should hold: any Spacetime that produces
declarations — a form splice (`--card-surface;`), a nested directive, a
conditional.

Rename to **`%declares`**. It names the ACT (this slot declares things) rather
than the CONTENT TYPE (these are styles), which is what lets the slot widen
without the name becoming a lie. `%sets` was the alternative; `%declares` reads
better against neighbouring clause names (`%binds`, `%registers`, `%exports`),
all of which are verbs in the same third-person form.

* Blast radius (measured, small)

- 18 Rust references to the string `"styles"`, centred on

The parameter NAME and the interpolation TOKEN are the same string, so both move
together.

* Loop safety — ALREADY DONE, and it is good

The requirement "fail hard if there are form loops within" is already met, for
style forms, by `E0966`. Verified:

| case                          | result                                             |
|-------------------------------+----------------------------------------------------|
| `--a` splices `--b` splices `--a` | `E0966: form splice cycle: --b -> --a -> --b`  |
| `--a` splices itself           | `E0966: form splice cycle: --a -> --a`            |
| three-deep `--a -> --b -> --c -> --a` | `E0966: form splice cycle: --b -> --c -> --a -> --b` |
| DIAMOND: `--a` and `--b` both splice `--base` | PASSES, emits `color: red` twice   |

The diamond case is the one that matters for correctness of the CHECK itself: a
shared base is legal and common, and an over-eager cycle detector would refuse
it. This one does not — it distinguishes a cycle from a re-visit.

The diagnostic prints the full path, which is the difference between a usable
cycle error and a frustrating one.
