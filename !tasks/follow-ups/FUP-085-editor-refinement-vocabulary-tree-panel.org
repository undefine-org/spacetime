auto-derived editor. All optional; absence = pure auto-derive.

** tree { } — navigator presentation (subsumes proposed @layers)
icon "cube"; label <param>; slot; hidden; muted; collapsed; badge origin.

** panel { } — inspector refinement (subsumes proposed @inspect)
group "Name" { paramA; paramB }        // groups at Spacetime-level, NO magic names
paramA: slider(0..1)                    // range refinement over :number
paramA: slider(0..64 step 4) unit "px"
spacing: vec3(posX, posY, posZ)         // PARAM FUSION: N scalars -> 1 widget
color: swatch / body: richtext / align: segmented   // force a widget
label/help/hide/order                   // relabel, help text, omit, explicit order
"Finish": preset { matte -> {roughness:0.9,metalness:0}; chrome -> {...} }  // multi-param
"Aspect": compute(w,h) -> ratio         // derived read-only readout
presets from examples                   // /// @example blocks -> one-click presets

** actions { } — node affordances (subsumes proposed @affords)
duplicate (EditJsonArray Insert/clone); delete (Delete); "Reset" -> reset;
"Bind to data" -> bind($source) (EditAst replace value w/ binding); reorderable.

** when { } — conditional disclosure
show <params> when <param> == <value>   // progressive disclosure, panel adapts.

* Constraints (carry from design)
- ONE @editor macro, sigil-typed target (@macro / &template / Type). Registered
  via %registers editor(<ref>); server reads FormMatches (filter macro_name ==
  "editor") + merges with auto-derive. NO Rust per-construct logic.
- Custom controls allowed (owner: full freedom) BUT must declare written params;
  server validates -> correct-by-design EditAst. compute readouts write nothing.
- DOGFOOD: the v1 CaptureType->widget DEFAULTS are themselves expressed as @editor
  defaults over the capture-type registry, not a privileged Rust table. This FUP
  should make that dogfooding real (the default widget set = stdlib @editor data).
