* Initial Message

Please review the full arc and the cross-refs in light of recent changes to the codebase and tell me what is still relevant, what is even more relevant, and what capabilities on the rest of Spacetime this could unlock (be bold and creative)

* Context

PLAN-122 §Unlocks item 9. The Elixir seam (elixir/spacetime_lv) checks declared events against handlers and validates payloads against the contract sidecar. Domain scalars degrade to "string" across that boundary: a `color` field arriving from a LiveView is checked as a string on the server and as a string on the client, so a malformed value is caught by neither.

* Change

Export the %scalar_type entries into the contract sidecar so both languages check the SAME declaration:

- Server-side: a `color`-typed assign is validated on publish (bad value → an Elixir-side error at the source, not a silently dropped CSS declaration in the browser).
- Client-side: a subscribed typed field inherits the scalar's capture grammar for its runtime check, reusing PLAN-119's live validator path (E0502 family) rather than a second checker.
- The sidecar carries the grammar's IDENTITY, not a copy of the grammar (versioned reference) — otherwise the two sides drift, which is the failure this fixes.

* Why now

PLAN-119 W5 (FUP-143) made the seam symmetric for EVENTS (declared events must have literal handlers; the missing-handler case is a compile error). Values are the remaining asymmetric half: types are declared on the .st side and unenforced on the wire. Domain scalars are exactly where that gap bites, because they are the fields whose validity is not expressible as a JSON type.

* Edge

- Grammar evaluation on the BEAM: do not port the PEG engine. Export a checkable projection (regex/format string per scalar, generated FROM the grammar) and keep the grammar single-sourced; document the fidelity limit where a projection is weaker than the grammar.
- Version skew between a deployed server and a built page must fail loudly (sidecar carries a registry version), not silently accept.

* Relation
