* Change

A %capture_type grammar IS a generator. Derive from the same declaration:
- POSITIVE corpus: sample the grammar (each alternation arm, each unit in the %unit_set, each hex length 3/4/6/8, case variants, css_wide keywords, dynamic productions).
- NEGATIVE corpus: near-misses from the same grammar (5-digit hex, unknown unit, missing paren) — the diagnostics fixture set, which is how error QUALITY gets tested rather than just error presence.
- SHRINKING: reduce toward the grammar's simplest form (fewest digits, canonical unit, keyword over function), so a failure reports the minimal literal that breaks.
