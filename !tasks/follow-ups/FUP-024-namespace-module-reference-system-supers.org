* Why
PLAN-027 W3 introduces =@mount @self= (and =@mount @self <selector>=) as a LOCAL,
isolated way to reference "this file's own scopes" from a co-located test. It is
deliberately light — a point solution for the test grammar. It hints at a missing
general capability: a coherent NAMESPACE + MODULE-REFERENCE system across Spacetime.

* The general problem
Today module references are path-string @imports (=@import "stdlib/text"=,
=@import "./modal.st"=). There is no way to:
- name the current module / refer to "self" uniformly (W3 bolts on =@self=);
- reference a named scope/symbol EXPORTED by another module without importing its
  whole surface;
- namespace macros/primitives to avoid collisions (the testing-macro prepend hack
  in test_runner.rs exists precisely because there is no namespaced load path);
- alias a module (=@import "stdlib/text" as text= → =text::@measure=).

* Scope (future)
Design a first-class reference grammar that unifies:
1. self-reference (=@self= / module-local scopes) — generalize the W3 attempt.
2. qualified references (=module::symbol=, =module::.scope=).
3. import aliasing + selective import (=from "x" use {…}=).
4. namespaced macro/primitive resolution (kills the stdlib/testing prepend special-case
   in src/test_runner.rs and the parse-vs-expand registry split surfaced in BUG-053/F3).
