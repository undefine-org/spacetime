* Context
FEAT-147 built `--anchor-frost` (roughness-driven `backdrop-filter: blur()`) as an honest
partial approximation of three.js's real transmission-material shader. The REFRACTION half
(IOR-driven bending of what's seen through the surface) was explicitly scoped OUT as
unachievable with standard CSS filters on real DOM — `backdrop-filter` can blur/tint/
saturate pixels already at a screen position, it cannot warp/displace them.

* Spike question
Is there a cheap CSS-only approximation that gets visually close enough to refraction to be
worth adding? Candidate: an IOR-driven `skew()`/subtle `perspective` distortion on the
label, keyed off the dominant transmissive hit's `ior` (already available on the same
material object `hitInfo()` in three-anchor.st inspects for transmission/roughness — zero
extra raycasts to read it).

* Non-goals
- Do NOT attempt true per-pixel UV displacement (needs a fragment shader / canvas-texture
  mesh, forfeits real/selectable/accessible DOM — the whole point of this mechanism).
- Do NOT build speculatively; this is explicitly a SPIKE (investigate + prototype + report
  back on visual quality vs. complexity), not a committed feature.

* Acceptance (of the spike, not a feature)
A short writeup / prototype demonstrating whether an IOR-keyed skew reads as "refraction-ish"
or just "wrong-looking" — and a go/no-go recommendation for a follow-up FEAT if it looks
promising.
