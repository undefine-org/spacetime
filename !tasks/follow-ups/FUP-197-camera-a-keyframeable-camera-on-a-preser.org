Surfaced by FEAT-175. S2 of the promo needed a crane shot (overhead → eye level); `perspective-origin` + `rotate-x` keyframes on the floor approximate it badly. Proposal: `@camera { position: a -> b; target: a -> b; fov: ... }` on an element with `transform-style: preserve-3d`, lowering to a single inverse-transform on a `.rig` child (pure CSS matrix, no JS beyond the existing keyframe engine). Driver-agnostic: works under `&.scroll` for scrollytelling too (SIP-001b §5 cross-domain payoff).

Acceptance: demos/promo S2 rewritten with `@camera`; a `--cdp` gate asserting the floor's computed matrix changes across the clip window.
