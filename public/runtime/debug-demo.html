Debug Commands

Open your browser console (F12) and try these commands:

  • ST.debug.enable() - Enable all debugging features
  • ST.debug.listTimelines() - List all active timelines
  • ST.debug.inspectTimeline('hero-reveal') - Inspect a specific timeline
  • ST.debug.logDrivers() - Log all driver signal changes
  • ST.debug.snapshot() - Capture current animation state
  • ST.debug.showOverlay('.demo-card') - Show visual debug overlay
  • ST.debug.hideOverlay() - Hide all overlays
