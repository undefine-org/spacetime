inspect Layer Provenance

cargo run -- inspect --layer <layer> [file] exposes views at and around the meta-compiler pipeline. This map shows the input that creates every view and whether it is a compiler artifact or a source projection.

flowchart TD
    CLI["cargo run -- inspect --layer L [file]"] --> Pick{L}
    Stdlib["stdlib/runtime + stdlib/macros + stdlib/primitives"] --> Registry["registry output: macros + primitives"]
    Stdlib --> Dispatch["dispatch output: forms by directive + probe"]
    Pick -->|file-backed layers| Source["source text"] --> Parse["parse(): StFile"]
    Parse --> ParseView["parse output: raw, unmerged summary"]
    Parse --> Imports["resolve_imports()"] --> Rematch["rematch_with_user_macros()"]
    Rematch --> Keyframes["keyframes: timeline body captures"]
    Rematch --> Expansion["expansion: %binds / %derives / %states blueprint"]
    Rematch --> Scopes["scopes: build_scope_tree()"]
    Rematch --> State["state: analyze_state()"]
    Rematch --> IRCompile["compile_verbose(): evaluate → resolve → sort → expand_typed"] --> IR["ir: typed JS/CSS fragments"]
    Rematch --> Compiler["Compiler::from_ast().compile()"] --> Emit["emit: final CSS + JS"]

Layer source of truth

LayerInput → producerOutput / relation
registrystdlib → create_registry_with_stdlib() → MetaRegistryMacros and primitives; fileless bootstrap view.
dispatchMetaRegistry forms → build_dispatch_output()Overloads by directive and optional probe; fileless bootstrap view.
parseentry text → parse() → StFileRaw parse summary, definitions, scopes, matches; before imports.
keyframesassembled scopes + body captures → build_keyframes_output()Timeline names, selectors, properties; source projection.
expansionscope matches + macro definitions → build_expansion_output()Declared %binds, %derives, %states; blueprint, not expanded primitives.
scopesStFile.matches + StFile.scopes → build_scope_tree()Global state and template scopes; compiler-context projection.
stateassembled StFile → analyze_state()Declaration/read/write provenance and const/reactive/dead verdict.
irmatches + definitions → compile_verbose() → expanded primitivesTyped JS/CSS fragments; before emission.
emit (emission)assembled StFile → Compiler::from_ast().compile()Final CSS + JS; full compiler path.

Production stages vs. inspect names

flowchart LR
    A["MetaRegistry bootstrap"] --> B["parse"] --> C["import resolution + macro rematch"] --> D["evaluate"] --> E["resolve"] --> F["sort"] --> G["expand_typed"] --> H["emit_typed"]
    A -. "registry, dispatch" .-> A
    B -. "parse" .-> B
    C -. "keyframes, expansion, scopes, state" .-> C
    G -. "ir" .-> G
    H -. "emit" .-> H

keyframes and expansion are source-level views, not one-for-one production pipeline boundaries. Use ir to see typed per-invocation expansion.

Commands

cargo run -- inspect --layer registry
cargo run -- inspect --layer dispatch --probe '@scroll hero(start: 0, end: 1) { opacity: 0 -> 1; }'
cargo run -- inspect --layer parse path/to/page.st
cargo run -- inspect --layer keyframes path/to/page.st
cargo run -- inspect --layer expansion path/to/page.st
cargo run -- inspect --layer scopes path/to/page.st
cargo run -- inspect --layer state path/to/page.st
cargo run -- inspect --layer ir path/to/page.st
cargo run -- inspect --layer emit path/to/page.st
