#+AUTHOR: Spacetime DSL
#+OPTIONS: toc:3

* Overview

Spacetime provides declarative WebGL support through the =@scene= macro system.
Instead of writing imperative WebGL code, you describe effects and their reactive bindings.

* Current Implementation

** Basic Scene Setup

#+BEGIN_SRC spacetime
canvas.my-canvas {
  @scene(clearColor: #050510, antialias: true) {
    @fill glow(color: cyan, radius: 200px, center: mouse)
  }
}
#+END_SRC

** Available Primitives

| Primitive        | Purpose                                  |
|------------------+------------------------------------------|
| =glContext=      | WebGL context with resize/DPR handling   |
| =glLoop=         | RequestAnimationFrame render loop        |
| =glShader=       | Compile vertex/fragment shaders          |
| =glBuffer=       | VBO/IBO creation                         |
| =glTexture=      | 2D texture loading                       |
| =glFramebuffer=  | Render-to-texture                        |
| =glFullscreenQuad= | Post-processing geometry               |

** Available Effects

*** @fill glow

Radial glow effect with mouse tracking and blend modes:

#+BEGIN_SRC spacetime
@fill glow(
  color: cyan,        // glow color
  radius: 200px,      // effect radius
  intensity: 1.5,     // brightness multiplier
  falloff: 3.0,       // edge softness
  center: mouse,      // "mouse" | "screen"
  blend: add          // "normal" | "add" | "multiply" | "screen"
)
#+END_SRC

Multiple glows can be layered with blend modes:

#+BEGIN_SRC spacetime
@scene(clearColor: #050510) {
  // Background glow (additive)
  @fill glow(color: #2a0060, radius: 800px, intensity: 0.5, center: screen, blend: add)

  // Accent glow (additive)
  @fill glow(color: #ff0066, radius: 400px, intensity: 0.6, center: screen, blend: add)

  // Interactive glow following mouse
  @fill glow(color: #00ffcc, radius: 350px, intensity: 1.5, center: mouse, blend: add)
}
#+END_SRC

*** @fill gradient

Linear or radial gradients:

#+BEGIN_SRC spacetime
@fill gradient(
  from: purple,
  to: cyan,
  type: "linear",     // "linear" | "radial"
  angle: 45deg
)
#+END_SRC

*** @fill noise

Animated noise pattern:

#+BEGIN_SRC spacetime
@fill noise(
  scale: 5,
  speed: 1,
  color: white,
  octaves: 4
)
#+END_SRC

* Vision: Next-Level Features

** Reactive Bindings with @react-to

The core Spacetime pattern—binding visual properties to reactive signals:

#+BEGIN_SRC spacetime
@scene {
  @fill glow(color: cyan, radius: 200px) {
    @react-to $progress from scroll(&window) {
      radius: 200px + $progress * 300px
      intensity: 0.5 + $progress * 1.5
    }
    @react-to $normX, $normY from pointer(&self) {
      center: [$normX * 100%, $normY * 100%]
    }
  }
}
#+END_SRC

** State-Driven Scene Transitions

Scenes should react to interaction states:

#+BEGIN_SRC spacetime
@scene {
  @state_machine(initial: "ambient") {
    ambient { @fill glow(color: cyan, intensity: 0.5) }
    active  { @fill glow(color: magenta, intensity: 2.0) }
    pulse   { @fill glow(color: white, intensity: 3.0) }

    @transition(from: "ambient", to: "active", on: pointerenter)
    @transition(from: "active", to: "ambient", on: pointerleave)
    @transition(from: "active", to: "pulse", on: click)
    @transition(from: "pulse", to: "active", after: 200ms)
  }
}
#+END_SRC

** Layered Effects

Real designs layer multiple effects:

#+BEGIN_SRC spacetime
@scene {
  // Background animated gradient
  @fill gradient(from: #0a0a1a, to: #1a0a2e, angle: $t * 0.01)

  // Noise texture overlay
  @fill noise(scale: 8, speed: 0.5, color: white, opacity: 0.05)

  // Mouse-reactive glow
  @fill glow(color: cyan, radius: 300px, center: mouse)

  // Secondary glow with offset
  @fill glow(color: magenta, radius: 200px, intensity: 0.8) {
    @react-to $x, $y from pointer(&self) {
      center: [$x - 50, $y + 30]
    }
  }
}
#+END_SRC

** Post-Processing Pipeline

#+BEGIN_SRC spacetime
@scene {
  @fill glow(color: cyan, center: mouse)

  @distort chromatic(offset: 3px, angle: 45deg)
  @distort vignette(radius: 0.8, softness: 0.3)
  @distort crt(scanlines: true, curvature: 0.1)
}
#+END_SRC

** Smooth Morphing

=@morph-to= provides smooth interpolation without manual animation code:

#+BEGIN_SRC spacetime
@fill glow(color: cyan) {
  @morph-to $isOver from pointer(&self, events: ["enter", "leave"]) {
    duration: 400ms
    easing: ease-out

    color: cyan -> magenta
    radius: 200px -> 400px
    intensity: 1.0 -> 2.0
  }
}
#+END_SRC

** Time-Based Animations

Autonomous animations that don't require interaction:

#+BEGIN_SRC spacetime
@scene {
  @fill glow(color: cyan) {
    @time loop(duration: 3s) {
      radius: 200px -> 400px -> 200px
      intensity: 1.0 -> 1.5 -> 1.0
    }
  }
}
#+END_SRC

* Implementation Notes

** Element Property Sharing

WebGL primitives share state via element properties:

| Property            | Set By          | Used By                |
|---------------------+-----------------+------------------------|
| =el._stGL=          | glContext       | All WebGL primitives   |
| =el._stWidth/Height= | glContext      | Shaders, resize        |
| =el._stRegisterRender= | glLoop       | Effect render callbacks|
| =el._stMouseX/Y=    | pointer         | glow-render            |
| =el._stCenterMode=  | glow-render     | Render callback        |
| =el._stGlowRadius=  | glow-render     | Reactive radius        |
| =el._stGlowIntensity= | glow-render   | Reactive intensity     |
| =el._stGlowColor=   | glow-render     | Reactive color         |
| =el._stGlowBlend=   | glow-render     | Blend mode             |

*** Known Limitation: Shared Properties Affect All Instances

Currently, all glow instances on the same element share properties like
=el._stGlowRadius=, =el._stGlowIntensity=, etc. This means:

- =@pulse-radius= and =@pulse-intensity= macros affect ALL glows, not just one
- =@react-to= bindings that modify these properties affect all layers

*Workaround:* Use different =center= modes (=screen= vs =mouse=) to differentiate
static vs interactive glows. Static glows use their initial values while the
mouse-following glow responds to reactive updates.

*Future Enhancement:* Implement per-instance properties using an ID-based approach,
e.g., =el._stGlow_layer1_radius=, or use a Map keyed by effect ID.

** Cleanup Pattern

Cleanup is registered inside init functions:

#+BEGIN_SRC javascript
ST.onCleanup(el, () => {
  resizeObserver.disconnect();
  // ... other cleanup
});
#+END_SRC

* Example: Complete Demo

#+BEGIN_SRC spacetime
/// Enhanced WebGL Demo - Spacetime DSL

canvas.demo {
  position: fixed;
  inset: 0;
  cursor: none;

  @scene(clearColor: #050510, antialias: true) {
    // Layer 1: Rotating gradient
    @fill gradient(from: #0a0a1a, to: #1a0a2e) {
      @time loop(duration: 10s) {
        angle: 0deg -> 360deg
      }
    }

    // Layer 2: Noise texture
    @fill noise(scale: 6, speed: 0.3, color: white, opacity: 0.03)

    // Layer 3: Ambient pulsing glow
    @fill glow(color: #4a0080, radius: 600px, intensity: 0.3) {
      @time loop(duration: 4s, easing: ease-in-out) {
        intensity: 0.2 -> 0.4 -> 0.2
        radius: 500px -> 700px -> 500px
      }
    }

    // Layer 4: Mouse glow with morph on click
    @fill glow(color: cyan, radius: 200px, center: mouse) {
      @morph-to $isPressed from pointer(&self, events: ["down", "up"]) {
        duration: 150ms
        easing: ease-out
        color: #00ffcc -> #ff00ff
        radius: 200px -> 350px
        intensity: 1.2 -> 2.5
      }
    }

    // Layer 5: Trailing glow with spring
    @fill glow(color: #ff6b6b, radius: 150px, intensity: 0.6) {
      @react-to $x, $y from pointer(&self) {
        center: spring([$x, $y], stiffness: 0.08, damping: 0.9)
      }
    }

    // Post-processing
    @distort chromatic(offset: 2px)
    @distort vignette(radius: 0.85, softness: 0.4)
  }
}
#+END_SRC
