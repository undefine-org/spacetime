#+title: Standards

The important standards to make sure you follow when writing or reviewing code.

* 1. %* behaviour is defined in Rust, everything else from it
Ideally, the Rust part of the Spacetime code uses ~%~ only, and everything else about Spacetime syntax is derived from the directives used with the ~%~ syntax.
** Spacetime internals are modifiable through the ~%~ behaviour
That means, very cleanly, that while there might be types that are defined from Rust, it is perfectly possible to build first-party-level extensions to types.

* 2. No special treatment in Rust of syntax elements written within %form
** WHAT
~%form~ needs to be the unique reference of the syntax that defines it.
** WHY
Spacetime is a meta-language. Its functional syntax should be written in Spacetime itself.
